# Session Start Skill（开发开工恢复技能）

## 作用

用于 AI 辅助开发项目时，在新开发会话开始阶段自动恢复项目状态。

目标：

- 快速理解昨天进度
- 避免重复阅读大量历史记录
- 确认当前代码状态
- 判断今天最合理的开发顺序


---

# 触发条件

当用户输入：

- 开始开发
- 继续昨天
- 今天继续
- 开工
- 我回来了
- 看看现在项目状态

触发本 Skill。


---

# 执行流程


## Step 1：读取项目上下文

优先读取：

```

DEV_CONTEXT.md

```

关注：

- 当前版本
- 最近提交
- 最近完成内容
- 未完成事项
- 制作人决策记录


如果存在：

读取：

```

任务规划文档
路线图
问题追踪

```

---

## Step 2：检查代码状态


执行：

```

git status
git log --oneline -10

```

确认：

- 当前 HEAD
- 最近提交
- 是否存在未提交修改
- 是否存在其他 Agent 工作内容


不要直接修改。

先确认归属。


---

## Step 3：生成项目恢复报告


输出：

```

# 项目恢复报告

## 当前版本

版本：

Commit：

## 昨日完成

*

## 当前进行中

*

## 未完成事项

*

## 当前风险

*

## 推荐今日顺序

1.

2.

3.

```


---

## Step 4：判断今日任务优先级


遵循：

稳定性 > 玩家体验 > 核心循环 > 新内容 > 优化


优先处理：

1. 阻塞开发的问题
2. 已发现 Bug
3. 玩家明显感知的问题
4. 已设计但未实现的重要系统


避免：

- 一开始添加大型新功能
- 无目标优化
- 重构已有稳定代码


---

## Step 5：进入开发前确认


向用户确认：

```

当前建议：

## A. 继续修复问题：

## B. 推进计划功能：

## C. 先试玩验证：

请选择方向。

```

不要未经确认扩大开发范围。


---

# 开发原则


## 先理解，再修改

禁止：

读取少量代码后立即修改。


## 尊重已有设计

优先遵循：

- DEV_CONTEXT.md
- 制作人决策
- 已有架构


## 小步推进

一次修改：

- 明确目标
- 可验证
- 可回滚


---

# 核心目标

让 AI 从：

“重新认识项目”

变成：

“加入一个已经运行中的开发团队”。

每次启动：

恢复状态。

确认方向。

再开始施工。
