# 任务卡：观星夜演出 v0.1（节奏升级）

> 来源：制作人方案（2026-08-05，最高制作人任务）
> 优先级：P0（Demo 最后记忆点）
> 状态：📋 方案已定，**待制作人确认后施工**
> 关联：任务-剧情Demo收尾观星夜.md（Codex 收尾演出定稿，对白脚本复用 DEMO_ENDING_DIALOGUE）

---

## 1. 任务目标

给现有观星点演出（`MapScene.tryStargaze` → DEMO_ENDING_DIALOGUE → 三选项 → 结算）升级节奏：

让玩家感觉"**我经历了一晚**"，而不是"我打完一个任务"。

## 2. 现状（2026-08-05 代码基线）

`tryStargaze` 触发后**立即**进入对白（含 `play('stargaze')` 音效），对白 → 三选项 → 分支独白 → `DEMO_ENDING_FINALE`（次日清晨）→ 结算面板。**缺前摇与余韵**。

## 3. 方案（制作人原文整理）

### 触发（不变）

观星点按 E，条件满足（主线完成 + 夜晚 + 靠近观星点）。**不要马上对白。**

### 前摇：三阶段

1. **进入**：1 秒黑屏/淡出 → 镜头移动到角色。
2. **第一阶段·静止**（2-3 秒，不说话）：
   - 只播放：夜晚环境音（AmbienceSystem 已有）+ `stargaze` 音效（已接入）。
   - 目的：让玩家感受到"我到了。"
3. **第二阶段·天空变化**：
   - 星星亮度提高 + 简单粒子 + 镜头轻微上移。
   - **不做复杂星空系统，一个 Tween 足够。**

### 对白（第三阶段）

- 夏雅**先生活化**，不要马上讲大道理，例如：
  - "这里的星星，小时候真的很亮。"
- 然后进入现有 `DEMO_ENDING_DIALOGUE`。

### 余韵（三选项后，接在现有分支独白/ finale 之前）

1. 林澈："好像……也没有想象中那么糟。"
2. 天空（静默）。
3. 远处（静默）。
4. 神秘少女一句（不解释、不揭底，沿用现有"异常点"风格）。
5. 黑屏。
6. 次日清晨。
7. 结算（现有 EndingPanel）。

## 4. 技术边界

- ✅ 允许：`MapScene.tryStargaze` 演出流程改造、1 个镜头/星星 Tween、简单粒子（`add.particles` 或 Sprite 淡入，取最小实现）、黑屏遮罩淡入淡出（复用现有 fade 工具）。
- ✅ 复用：`stargaze` 音效（已接入）、夜晚环境音（AmbienceSystem）、`DEMO_ENDING_DIALOGUE`/分支/finale 对白、结算面板、存档路径。
- ❌ 禁止：新增战斗/抽卡/大地图/后端；**不做复杂星空系统、不做天气系统、不新增存档字段、不改 SAVE_VERSION**；不改动剧情状态机（storyStep/endingChoice 维持现状）。
- ⚠️ 对白新增部分（夏雅生活化开场、林澈余韵独白、神秘少女一句）为**剧情文本**，落地前须遵循 Design Authority：顶层设计.md > 剧情规划文档 > 实现需求；以制作人最终确认稿为准。
