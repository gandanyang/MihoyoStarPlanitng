# 任务卡：爷爷人物升级

> 立项：制作人 2026-08-03 ｜ 指派：待定 ｜ 状态：待执行

## 目标

重新审核爷爷的人设，**不要把爷爷写成"任务发布器"**。

## 要求

1. 更像中国家庭里的爷爷
2. 更克制、更温暖
3. 少讲大道理
4. 多通过生活细节表达关心（"别饿着""屋顶漏雨记得修""地荒了怪可惜的"式表达）

## 输出

- 人设修改建议
- 信件修改建议
- 台词修改建议

## 关联

- 《剧情规范》第三条（温暖、克制、留有余地，不说教）
- 《本地化规范》§1③（爷爷说话方式）

## 红线

- 不新增剧情节点 / 存档字段 / 任务链；爷爷身份伏笔（星痕线索）不揭底
