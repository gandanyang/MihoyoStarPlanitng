# 任务卡：爷爷立绘制作

> 立项：制作人 2026-08-04 ｜ 指派：待定（建议美术线/Codex 生图管线）｜ 状态：📋 待立项（形象锚点待拍板）
> 背景：爷爷**目前无立绘**——笔记对话兜底显示首字"爷"，观星夜"信"兜底显示"信"字

---

## 1. 目标

用 gpt-image-2 生成爷爷对话头像（512×512，同村长流程），接线后笔记/信件对话显示爷爷头像。

## 2. 形象锚点（依据《爷爷人物升级方案》+ 核心意象）

- 温暖、克制、留有余地的中国老人
- 喜欢看星星（观星者气质，但不科学家化）
- 普通老人：生活痕迹（旧衣/皱纹/温和），**不是研究员/神秘人**
- 与老宅/星空意象呼应（可加仰望星空/月光的氛围）

## 3. 管线

1. 提示词方案（含形象锚点 + 二游像素/立绘风格）→ 制作人过目
2. 生图走批准门禁（费用估算 + 确认）
3. 后处理：512×512 对话头像（面部居中，方形裁切安全）
4. 接线：PORTRAIT_MAP 增加 `'爷爷的笔记'` / `'爷爷'` / `'信'` → 新头像

## 4. 验收

- [ ] 一眼是"温暖看星星的老人"，非村长/非科学家
- [ ] 与林澈/夏雅/村长新头像风格统一
- [ ] 笔记对话/观星信件头像正确显示，无兜底首字
- [ ] tsc + 相关探针（probe-garden-xiya 等对话显示）通过

## 5. 红线

- 爷爷形象属剧情权限——锚点需制作人确认后生成
- 不揭爷爷秘密（星痕/研究）；不科学家化
- 旧资源保留可回滚
