# 任务卡：未开放区域探索提示

> 状态：📋 待施工（P1，体验反馈）
> 来源：制作人 2026-08-05 ｜ 参考：原神式边界提示"前面的区域，以后再来探索吧！"
> 施工线：MapScene 单写者制登记后施工 ｜ 优先级：P1

---

## 一、需求

玩家走向尚未开放的地图方向时，目前是**无声撞墙**（物理世界边界直接挡住），没有任何反馈。

增加边界提示：当玩家靠近地图边缘（非出口方向）时，显示轻提示：

> **"前面的区域，以后再来探索吧！"**

（制作人参考文案；如施工时希望更本地化，可用"前面还没准备好，以后再来看看吧。"——最终文案由制作人确认）

## 二、现状（已核实）

- 全部地图为矩形世界边界（`setCollideWorldBounds` 防出界），四边外圈基本都是可走地面直达边界，无提示
- 现有轻提示组件：`MapScene.showDialogueText(text)` + `hintText(pc, mobile)`（PC/移动端文案适配），已有大量先例（大门锁定提示、花园清理引导、未解锁工具提示）
- 现有"靠近触发 + 一次性 flag"模式先例：`gardenHintShown`（花园清理引导）、`mineTipShown`（矿洞提示）

## 三、实施方案

### 涉及文件（仅限）

- `src/scenes/MapScene.ts`（update 循环检测 + 提示触发）

不新增存档字段、不动地图数据、不动 StorySystem / StoryDialogue / SaveSystem。

### 触发规则

1. 仅开放地图生效：`farm` / `forest` / `town` / `mine`
2. 教程未完成（`isTutorialDone()` 为 false）时不提示
3. 玩家进入"边界检测带"：离世界边界 ≤ 24px（约 1.5 格），按方向检测（上/下/左/右）
4. **排除出口区域**：玩家位置落在 `MAP_EXITS[mapKey]` 任一出口触发区内时不提示（出口在边界上，防误触/打断切场景）
5. 排除场景：`house`（室内边界=墙，正常）、`gate`（车站剧情场景）

### 表现

- 复用 `showDialogueText` + `hintText`，不新建 UI 组件
- 频率：同场景**首次进入边界带提示一次**；玩家离开边界带（回到地图内部）后重置，再次靠近可再次提示（内存 flag，不写存档）

## 四、验收标准

- ✅ tsc 0 错
- ✅ 手动验证（桌面 + 移动端）：
  - 农场底边/左右边、后山四边、小镇四边、矿洞四边 → 靠近出现提示
  - 走到出口方向（农场顶→森林、农场右→小镇等）→ 正常切场景，不出现边界提示
  - 教程期（大门/农场初始步骤）→ 不出现提示
  - 室内（house）、车站（gate）→ 不出现提示
  - 离开边界再靠近 → 可再次提示

## 五、红线

- ❌ 不新增存档字段（内存 flag 即可）
- ❌ 不改地图数据 / 出口拓扑 / 碰撞
- ❌ 不改 StorySystem（提示走 showDialogueText 轻提示，不占用剧情对白）
