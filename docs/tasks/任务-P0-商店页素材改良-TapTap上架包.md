# 任务卡：P0 商店页素材改良（TapTap 上架素材包）

> 立项：制作人 2026-08-07（依据「商店页素材盘点-2026-08-07」）｜状态：📋 待认领｜优先级：**P0（上架阻塞项）**
> 关联：docs/reports/商店页素材盘点-2026-08-07.md、任务-Alpha玩家流程审查-FirstPlayTest-v0.1.md
> 目标：产出**一套可直接上架 TapTap 的商店页素材包**——合规实机截图 + 首图/宣传图 + 竖图，消除"封面好看、实机穿帮"的转化断层

---

## 一、背景（为什么是 P0）

盘点结论：现有 `public/assets/images/promo/` 32 张图，**按 TapTap 尺寸规范能直接用的为 0 张**：

- promo / gpt / round 系列横竖比例全部踩线出界（横图 1.46 < 8:5 下限、竖图 0.68 > 5:8 上限）
- 实机截图完全缺失——商店页最前列必须有 ≥3 张实机画面
- 现有 AI 图全是插画/概念图，只能当宣传图用且受限 2 张

上架无玩家与商店页素材不达标直接相关：**没有合规实机截图 = 转化差**，这是当前最可控的环节。

---

## 二、交付物清单（6 项）

### 交付物 1：实机截图 ×3~4（P0，最重要）

- 要求：真实游戏画面（dev server 或真机截取），**实机面积 >50%**，不得只含商业内容（充值/商城/抽卡）
- 规格：
  - 横图：宽高比 8:3 ~ 8:5（优先 16:9），分辨率 ≥1280×720，单张 ≤4MB，JPG/PNG
  - 同一套图比例需与第一张一致
- 建议场景（对应 Demo 情绪曲线）：
  1. **开场/车站或归星岛抵达**——第一印象
  2. **种田/收获**——核心玩法
  3. **修复完成（老屋/花园亮灯）**——"世界变化"卖点
  4. **观星夜**——高潮情绪点
- 产出目录：`public/assets/images/screenshots/`

### 交付物 2：首图/宣传图 ×1（P0）

- 规格：16:9，1920×1080，≤4MB，JPG/PNG
- 内容：**包含游戏标题《归星物语》**；不得出现标题以外的宣传性文字；不得出现游戏图标
- 要求：贴近游戏真实美术资产/玩法，**不过度美化**（避免"封面好看实机穿帮"）
- 产出目录：`public/assets/images/promo/store_banner.png`

### 交付物 3：竖图 ×2~3（P1）

- 规格：宽高比 3:8 ~ 5:8，分辨率 ≥720×1280，≤4MB
- 场景复用：观星夜 / 夏雅或角色立绘场景 / 小镇生活
- 产出目录：`public/assets/images/promo/store_vertical_*.png`

### 交付物 4：现有 AI 图合规化处理（P1）

- 1216×832（比例 1.46）横图 → 裁切/补边到 8:5（1280×800 区域）或 16:9
- 832×1216（比例 0.68）竖图 → 裁切到 5:8 内
- 原则：**只裁切/补边，不重新生成**（保留已验收的构图）
- 产出：`promo/` 内新增 `*_store_ready.png` 副本，原文件保留

### 交付物 5：素材规格核对表（P0 交付物附带）

每张交付物附带一行记录：文件 / 尺寸 / 比例 / 大小 / 实机占比 / 是否符合规范

### 交付物 6：商店页文案建议（P1，可选）

- 一句话卖点 + 简短描述（50 字内），供制作人上架填写

## 三、执行方案（按顺序）

### Step 1：确认素材基线（30 分钟）

- 启动 dev server，进入游戏最新版本
- 逐场景确认"可截图的画面"：车站 / 农田 / 老屋 / 观星夜
- 注意：若玩家流程审查报告已出，优先按报告标注的"不穿帮场景"截图

### Step 2：实机截图（半天）

- 方式 A（推荐）：dev server + puppeteer 脚本截图（参照 tests/probes 现有截图能力，可写一次性脚本 `tools/shot_store_scenes.mjs`）
- 方式 B：真机 APK 截屏（画面最真实，建议至少 1 张）
- 验收：实机面积 >50%、比例合规、单张 ≤4MB

### Step 3：首图生成（半天，含批准门禁）

- 方式 A：`tools/gpt_image_gen.mjs --size 1920x1080 --format jpeg --yes`（gpt-image-2，**先 --dry-run 估算费用，制作人批准后执行**）
- 方式 B：`tools/gen_promo_images.py`（ComfyUI / anima turbo，本地零成本，构图由任务提示词控制）
- 提示词要点：归星岛乡村夜景 / 观星 / 温暖灯光；像素 v2 风格或与其协调的二次元风格；含标题文字的排版在出图后由脚本叠加（若管线不支持直接出字）

### Step 4：合规化处理（半天）

- 裁切脚本（一次性）：`tools/normalize_store_assets.mjs` 或 Python 脚本，批量处理交付物 4
- 全部交付物过一遍规格核对表

### Step 5：交付

- 素材包落盘 + 规格核对表 + 文案建议，报告制作人
- 建议与「玩家流程审查」同期：审查确认实机画面不穿帮后，截图才有长期价值

---

## 四、验收标准

- ✅ 实机截图 ≥3 张：比例合规、≥1280×720、实机面积 >50%、与第一张比例一致
- ✅ 首图 1920×1080：含标题、无其他文字、无游戏图标、≤4MB
- ✅ 竖图 ≥2 张：比例 3:8~5:8、≥720×1280、≤4MB
- ✅ 全部图片为 JPG/PNG、单张 ≤4MB
- ✅ 规格核对表逐项通过
- ✅ 原素材未被覆盖/删除（可回滚）

---

## 五、红线

- ❌ 不改游戏代码、不碰存档、不换 Tilemap/美术资源（本任务只产出商店页素材）
- ❌ 宣传图不得过度美化、不得出现图标/多余文字
- ❌ 生图必须走批准门禁（gpt-image-2 每次真实调用前确认费用；ComfyUI 走 gen_promo_images.py）
- ❌ 不删除原 promo 素材（只新增 `*_store_ready` 副本）
- ❌ 截图不得造假（禁止拼接合成实机画面；AI 图必须标注为宣传图）
