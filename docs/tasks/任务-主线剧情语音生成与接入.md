## 三、音高自检（强制，防女声串入）

生成后必须测量中位 F0（16kHz wav 自相关，可参考本项目已验证的脚本思路）：

- 男声（林澈/村长/爷爷）：中位 F0 应 ∈ [70, 180] Hz；>180 判定漂移 → 重跑（最多 3 次）
- 女声（夏雅/神秘少女）：中位 F0 应 ∈ [170, 320] Hz；<170 判定漂移 → 重跑（最多 3 次）
- 每句记录：初测值 / 重跑次数 / 最终值；漂移 >3 次仍未达标 → 标记待人工处理，不硬出
