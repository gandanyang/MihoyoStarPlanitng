## B. 真机听感测试（制作人执行）

### B1. 农场白天（最重要）

**操作**：进入 farm 场景，站定不动，听 30 秒

| 问题 | 期望 | 评分(1-5) |
|------|------|-----------|
| 音量是否舒服？ | 不刺耳、不压过操作音效 | |
| 是否循环太明显？ | 听不出"一首歌在循环" | |
| 是否有机械感？ | 像风/虫鸣，不像机器 | |
| 鸟叫是否自然？ | 4-9s 间隔，随机啁啾，不急促 | |
| 风声是否有起伏？ | 不是恒定嗡鸣，有阵风感（0.15Hz LFO） | |

### B2. 农场夜晚

**操作**：debug.setHour(22) 切到夜晚，或睡觉到夜晚

| 问题 | 期望 |
|------|------|
| 鸟叫消失？ | 夜晚不应有鸟叫 |
| 虫鸣是否自然？ | 高频轻颤，不刺耳（vibrato 6Hz） |
| 风声是否仍存在？ | 风声昼夜都有 |

### B3. 矿洞

**操作**：进入 mine 场景

| 问题 | 期望 |
|------|------|
| 低频低鸣是否可感知？ | 70Hz + 45Hz 叠加，很轻但能感受到"洞穴感" |
| 是否有脉动感？ | LFO 0.2Hz 缓慢起伏，像呼吸 |
| 是否与 farm 混淆？ | 完全不同的氛围 |

### B4. 切图

**操作**：farm→mine→forest→town，每图停留 5 秒

| 问题 | 期望 |
|------|------|
| 切图后旧声音停止？ | 无跨场景声音残留 |
| 新地图音效立即开始？ | 无缝衔接 |
| 切图瞬间有爆音？ | 无（淡入淡出保护） |

### B5. 切后台回来

**操作**：切到手机桌面（5 秒），再切回游戏

| 问题 | 期望 |
|------|------|
| 切后台时声音停止？ | 不在后台播放（省电） |
| 切回后声音恢复？ | 自动恢复当前地图环境音 |
| 切回后掉帧？ | 不掉帧 |
