# 任务卡：FEATURE-039 智能出售系统升级

> 状态：✅ **已完成**（trae 2026-08-06）
> 立项：制作人 2026-08-06 拍板方向 ｜ 方案：[智能出售系统升级方案-v0.1.md](design/智能出售系统升级方案-v0.1.md)
> 一句话：一键出售 → 智能出售（预览 + 关键资源保护 + 锁定），为资源多用途打基础，不改经济数值、不重构背包

---

## 一、实施内容

### Task 1：物品标签（P0）

- `src/data/Inventory.ts` ItemDef 增加 `sellPriority: 'normal' | 'reserve' | 'forbidden'`
- 初始标注：
  - normal：萝卜/番茄/玉米/草莓/铜矿
  - reserve：木材（建设/家具）、石头（建筑）、铁矿（升级）
  - forbidden：星之碎片/钻石/庄园钥匙/旧工具/机器人（与现有 SELLABLE_ITEMS 白名单外的物品一致）
- `Economy.ts` SELLABLE_ITEMS 保留为价格源（不删、不改数值）

### Task 2：智能出售算法（P0）

- `sellAllSellable()` 升级：forbidden 过滤 + locked 过滤 + reserve 跳过（不自动卖）
- 返回结构扩展：`{ sold: [...], skipped: [{item, count, reason}] }`（出售/跳过清单）
- 现有"全部出售"入口改为走新算法（BackpackPanel / ShopPanel）

### Task 3：出售预览 UI（P0）

- 新增 `SmartSellPreviewPanel`（DOM，模块级单例，复用现有面板模式 + dom-anim）
- 内容：预计获得金币 / 将出售列表 / 将保留列表（reserve + forbidden + locked）/[确认出售]
- 确认后执行出售 + toast 反馈

### Task 4：锁定功能（P1）

- 背包物品格加"锁定 🔒"切换（内存 + 存档）
- `SaveData.lockedItems: string[]`（可选字段，save/apply/sanitize，旧档默认空数组，版本号不递增）

## 二、涉及文件

- `src/data/Inventory.ts`（sellPriority + lockedItems 状态）
- `src/data/Economy.ts`（算法扩展，数值不动）
- `src/ui/SmartSellPreviewPanel.ts`（新增）
- `src/ui/BackpackPanel.ts` / `src/ui/ShopPanel.ts`（入口接入 + 锁定按钮）
- `src/systems/SaveSystem.ts`（lockedItems 可选字段）
- `tests/probes/probe-smart-sell.mjs`（新增探针）

## 三、验收标准

- ✅ tsc 0 错
- ✅ 一键出售：forbidden 不卖、reserve 跳过并在预览列出、locked 不卖
- ✅ 预览显示预计金币/出售清单/保留清单，确认后正确执行
- ✅ 锁定后重进保留（存档）
- ✅ 旧档无 lockedItems 正常加载
- ✅ 经济数值不变、背包不重构
- ✅ 回归：普通作物仍可一键出售（每日任务卖作物联动不破坏）

## 四、红线

❌ 不改经济数值 / 价格
❌ 不重构背包系统（增量修改）
❌ 不新增存档结构大改（lockedItems 可选字段）
