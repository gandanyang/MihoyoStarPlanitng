# 任务卡：主角模型升级（林澈 32×32 精灵）

> 立项：制作人 2026-08-04 ｜ 指派：待定 ｜ 状态：📋 待立项（Batch D 美术批次）
> 背景：游戏内 `player.png`（128×128，4 方向×4 帧）为旧形象（像素采样主色：青绿外套 (90,170,138) / 深蓝裤 (42,42,106) / 棕色调 (106,74,42)，非红夹克金发）；林澈圣经 v1.2 已锁定方向 B（深棕短发/细黑框眼镜/蓝格纹衬衫/工牌/手表）

---

## 1. 目标

用方向 B 形象重做林澈 32×32 精灵（替换旧金发红衣），4 方向×4 帧行走动画，16×16 实际显示下"一眼是林澈"。

## 2. 管线（AI 定形象 + 脚本扩帧）

1. **AI 单帧概念**：方向 B 人设锚点 + v2 像素约束（三色调/1px 描边 RGB(18,14,22)/左上光源），生图走批准门禁
2. **调色板量化**：映射到项目 C 类角色色板（P_* 系列按新形象扩展）
3. **32×32 单帧**：与现行精灵 A/B 对比，制作人验收风格基线
4. **脚本扩帧**：4 方向×4 帧动画（复用/扩展既有 gen_sprite_assets.py 帧布局，**不用 AI 出 16 帧防抖动**）

## 3. 验收

- [ ] 16×16 实际显示可读、不糊
- [ ] 一眼是林澈（深棕短发/黑框眼镜/蓝格纹衬衫/工牌/手表）
- [ ] 4 方向×4 帧动画循环不抖、无闪烁
- [ ] 与 NPC（夏雅/村长等）精灵风格协调
- [ ] 移动端真机 farm ≥30fps
- [ ] 旧 `player.png` 保留可回滚；纹理 key 变更探针同步

## 4. 红线

- 不改存档字段 / gid 语义 / 碰撞编号
- 不改林澈身份锚点（方向 B 定稿）；二游男主非乙游
- AI 生图每次批准门禁；控制台"禁止修改美术"当前生效（Batch D 启动后施工）
