# 任务卡：观星夜演出（星空 / 镜头 / 结尾）

> 立项：制作人 2026-08-04（发布清单 A 演出）｜状态：📋 待施工线认领
> 方案：docs/design/观星夜演出方案-v0.1.md（制作人已确认派发）

## 范围（先做 MVP）

1. **星空系统**：程序化星野底（静态，零开销）+ 20~40 星点闪烁 + 2~3 流星/星屑；仅观星夜/夜晚 farm 启用
2. **镜头调度**：进入观星点缓推 → 夏雅对话特写 → 读信平移天空 → 三选项拉远 → 结算缓拉（`camera.pan/zoom` 缓动，不打断对白）
3. **结尾收束**：观星完成星光聚拢 → 晨曦过渡（2s）→ EndingPanel 结算 + 结语字幕 → 回自由模式（白天星空层关闭）

## 技术约束

- Phaser 3 现有场景内实现；不新增系统/插件
- 存档零改动；对白/选项/世界观零改动
- 移动端帧率 ≥30fps（粒子数 ≤50，星空层白天不显示）

## 验证

- 观星夜四拍镜头节奏清晰，无黑屏/跳变
- 夜空有明显星空（星点/银河/流星），移动端不掉帧
- 结算有收束感；白天/非观星场景星空层不显示
- tsc + probe-stargaze 回归

## 红线

- 不动剧情文本/选项/世界观；探针同步；小步提交
