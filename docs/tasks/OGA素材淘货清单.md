# OGA 素材淘货清单（美术资源采购建议 v0.2）

> 制作人 2026-08-07 立项：从 OpenGameArt 淘统一素材，解决"占位感/割裂感"（呼应美术资源审查报告 2026-08-07 的 P1 短板）。
> **v0.2 修订（GPT 顾问意见 + 新增候选验证）**：许可证战略从"LPC 优先"改为"**CC0/商业友好优先，LPC 降级为原型参考**"——GPT 判断 CC-BY-SA 的衍生作品边界不清对闭源商业游戏是长期维护成本，且 CC0 替代素材已被验证存在。
> 项目硬约束：手机横屏（竖屏暂缓）/ Phaser 3 / **16×16 网格** / Ground+Walls 双层 / 温暖治愈 / 类星露谷。
> 许可证红线：**CC0 > CC-BY（需署名） > CC-BY-SA（传染性，慎用）**；商业发布前必须核清每份素材许可。

## 〇、采购总原则（美术总监把关 + GPT 顾问修订）

1. **一套素材定生死**：OGA 素材来自不同作者，风格必然不统一。**核心世界资源优先 CC0 / 明确 commercial use allowed**；同一风格体系内取用，避免跨作者割裂。
2. **CC-BY-SA 不进商业核心**（GPT 核心意见）：不是不能商用，而是**衍生作品边界不清**——改色/拼接/重组/混 AI 素材后"是否构成衍生作品"法律解释空间大。Demo 没问题，但 Steam 上架/找发行/找投资时版权审查是麻烦。**LPC 降级**：仅做原型阶段参考、地图设计验证、色彩参考；最终商业包用原创或 CC0。
3. **16×16 必须严核**：现有地图全部 16px 网格，优先原生素材就是 16px 的。
4. **先小样后全量**：每类素材先下载小样接进游戏竖屏实测，确认风格融合再全量接入。
5. **视觉定调优先于堆素材**（GPT 意见）：《归星物语》最大的商业感缺口不是"素材少"，而是"世界没有形成统一美术语言"。**先做 16×16 归星物语视觉样板场景**（农田+小屋+河边+男主站立），成立后所有地图都能复制。

## 二、许可证风险表（商业发布前必读）

| 许可 | 商用 | 署名 | 传染性 | 结论 |
|---|---|---|---|---|
| **CC0** | ✅ | ❌ 不需要 | ❌ 无 | ✅ **首选** |
| CC-BY | ✅ | ✅ 需署名页 | ❌ 无 | ✅ 可用，需在游戏 credits 列作者 |
| CC-BY-SA | ✅ | ✅ 需署名 | ⚠️ **衍生作品必须同许可开源** | ⚠️ **慎用**：若你的游戏闭源，衍生美术会成为开源义务 |
| GPL3 | ✅ | ✅ | ⚠️ **强传染** | ❌ 尽量避开 |

> ⚠️ **特别提醒**：LPC 体系（农场/村庄最优候选）是 **CC-BY-SA + GPL 双许可**——如果采用，你的游戏美术资产将"必须开源衍生部分"。**这是制作人需要拍板的战略决策**：接受（换取顶级素材）还是规避（选 CC0 替代品）。

## 四、最终决策建议（GPT 顾问 + 美术总监融合）

### GPT 给出的优先级排序（已采纳）

| 优先级 | 动作 |
|---|---|
| **P0** | 找 CC0/商业友好的农场 TileSet，替换主农场（候选：lungucristian1980 Cozy Farm） |
| **P1** | 村庄装饰统一 |
| **P2** | Kenney UI 重做交互框 |
| **P3** | 天气粒子 |
| **P4** | 矿洞（玩家 15 分钟后才看到，最后做） |

### 商业感第一优先（GPT 核心建议，已采纳）

> **不要先做矿洞。玩家判断游戏质量靠前 30 秒：标题画面 → 主角出现 → 第一块农田 → 第一次种植。**
> 先做 16×16 归星物语视觉样板场景：**农田 + 小屋 + 河边 + 男主站立**。这个场景成立，后面所有地图都能复制。

### 视觉统一方案（GPT：淘素材只能解决 30%）

- 立绘（512px 二次元）**不直接当游戏画面** → 用途限定：对话框头像 + 事件 CG（同色背景/统一边框/UI 框架，做成完整系统）
- 像素角色（32px）负责移动/交互——星露谷式"像素身体 + 高清头像"是成熟范式
- 世界统一：暖色调 / 低饱和 / 柔光

### 接入三大坑（GPT 提醒，已记录）

1. **视觉密度不统一**：16px 地砖 + 32px 精细角色 = 人物像贴纸。先统一地砖纹理复杂度/明暗/描边
2. **Tiled GID 映射**：换 tileset 最容易 tile index 改变、collision 错位。**先做 test_map.tmx 10×10 小样验证，再迁移**
3. **颜色体系**：AI 立绘高饱和 vs 像素地图低饱和 = 两个世界
