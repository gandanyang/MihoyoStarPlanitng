# 任务卡：BUG-039 语音播放位置对不上（安卓）

> 登记：制作人 2026-08-04 真机反馈｜级别：P1（沉浸破坏，语音核心体验）｜状态：✅ 代码已修复 v2（trae 2026-08-05，v1 方案真机否定后修订）；⏳ 待安卓真机复验（测试批 3）

## 症状

安卓端车站开场「五年了。」的语音与台词**位置对不上**（听感：声音延迟/错位，在别的台词时才响起）。

## 已核实（Codex）

- 音频文件正确：`public/audio/voice/linche/station_01.wav`（1.44s，男声）
- 映射正确：`voicebank.data.ts` station_01 → 林澈「五年了。」
- 疑因：`src/audio/VoiceBank.ts` `new Audio(url); audio.play()` 未等 `loadeddata` 就播——Android WebView 音频加载慢，声音起播晚于当前台词；内心独白（inner）走 Web Audio 混响链路（`createMediaElementSource`+convolver），可能加剧延迟

## 修复方向

1. VoiceBank 播放前等待音频 `loadeddata`/`canplay`（或对短句预加载缓存）
2. 评估内心独白混响链路在 Android 的稳定性：若延迟/不可用，回退原音播放（不阻塞）
3. 可选：`preload` 下一句/相邻句，减少首次加载

## 修复记录 v1（2026-08-05 trae）——已被真机否定，不采用

- [VoiceBank.ts](../../src/audio/VoiceBank.ts)：`play()` 改等 `loadeddata` 再播（`readyState>=2` 或命中 `readyCache` 立即播）；`readyCache` 缓存已就绪 URL；2.5s 超时兜底；`stop()` 清理 pending 音频与定时器
- 真机结果（制作人 2026-08-05）：**「五年了。」那句没声音，最后一句的声音是「五年了。」的**——`loadeddata` 回调使第一句 play() 离点击手势过远，被 Android WebView autoplay 策略拒绝（第一句无声），且被拒的 play() 在玩家后续点击时自动恢复 → 最后一句响起第一句声音。方案废弃

## 修复记录 v2（2026-08-05 trae，采用）

根因（真机复现）：Android WebView autoplay 策略——`audio.play()` 必须发生在 transient activation 窗口（用户手势后短暂窗口）内，否则被 `NotAllowedError` 拒绝；且被拒的 play() promise 会在玩家后续任意点击时**自动恢复播放** → 串音错位。

- [VoiceBank.ts](../../src/audio/VoiceBank.ts) 三项改动：
  1. `play()` **立即 doPlay()**（保留场景切换后的手势窗口，不再等 loadeddata）；加载未就绪时 HTMLMediaElement 内置等待就绪后起播
  2. 新增 `preload(speaker,text)`：预加载下一句语音（`preloadCache` Set 去重，只加载不播放），消除 WebView 加载慢的起播延迟——[StoryDialogue.ts](../../src/ui/StoryDialogue.ts) `showLine()` 显示当前行后预加载下一句
  3. autoplay 拒绝兜底：`onReject` 捕获 `NotAllowedError` → 记录 `gesturePendingAudio`；全局 `unlockAudio()`（document 上 pointerdown/touchend/keydown 监听）恢复 AudioContext + 重试被拒音频（期间换行则放弃）
- 连带修复：[StoryDialogue.ts](../../src/ui/StoryDialogue.ts) `isOpen()` 从 `=== 'block'` 改为 `!== 'none'`——`panelFadeIn` 强制 display='flex' 覆盖了 play() 的 'block'，导致 isOpen 恒 false、skip/advance 全失效（v2 回归探测暴露，属 A4 动效引入的潜伏缺陷）
- 验证：新探针 `probe-bug039-voice-sync.mjs` **10/10**（预加载下一句 / 快速推进多行 / 播放后立即 stop / 同句重复 / 对话开关链路无 JS 错误 / 语音请求均 200）+ probe-voice 11/11 + probe-skip-debounce 3/3 + probe-bug041 9/9 + probe-stargaze 14/14 + test-ch1-story 24/24 回归全绿
