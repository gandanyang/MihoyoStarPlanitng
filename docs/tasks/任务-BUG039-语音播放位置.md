# 任务卡：BUG-039 语音播放位置对不上（安卓）

> 登记：制作人 2026-08-04 真机反馈｜级别：P1（沉浸破坏，语音核心体验）｜状态：📋 待施工线复现+修复

## 症状

安卓端车站开场「五年了。」的语音与台词**位置对不上**（听感：声音延迟/错位，在别的台词时才响起）。

## 已核实（Codex）

- 音频文件正确：`public/audio/voice/linche/station_01.wav`（1.44s，男声）
- 映射正确：`voicebank.data.ts` station_01 → 林澈「五年了。」
- 疑因：`src/audio/VoiceBank.ts` `new Audio(url); audio.play()` 未等 `loadeddata` 就播——Android WebView 音频加载慢，声音起播晚于当前台词；内心独白（inner）走 Web Audio 混响链路（`createMediaElementSource`+convolver），可能加剧延迟

## 修复方向

1. VoiceBank 播放前等待音频 `loadeddata`/`canplay`（或对短句预加载缓存）
2. 评估内心独白混响链路在 Android 的稳定性：若延迟/不可用，回退原音播放（不阻塞）
3. 可选：`preload` 下一句/相邻句，减少首次加载

## 验证

- 安卓真机：车站开场每句台词响起时语音同步（无延迟、无错位）
- probe-voice 回归；tsc 0 错
