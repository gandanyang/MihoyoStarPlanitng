# 任务卡：BUG-039 语音播放位置对不上（安卓）

> 登记：制作人 2026-08-04 真机反馈｜级别：P1（沉浸破坏，语音核心体验）｜状态：✅ 代码已修复（trae 2026-08-05）；⏳ 待安卓真机复验（测试批 3）

## 症状

安卓端车站开场「五年了。」的语音与台词**位置对不上**（听感：声音延迟/错位，在别的台词时才响起）。

## 已核实（Codex）

- 音频文件正确：`public/audio/voice/linche/station_01.wav`（1.44s，男声）
- 映射正确：`voicebank.data.ts` station_01 → 林澈「五年了。」
- 疑因：`src/audio/VoiceBank.ts` `new Audio(url); audio.play()` 未等 `loadeddata` 就播——Android WebView 音频加载慢，声音起播晚于当前台词；内心独白（inner）走 Web Audio 混响链路（`createMediaElementSource`+convolver），可能加剧延迟

## 修复方向

1. VoiceBank 播放前等待音频 `loadeddata`/`canplay`（或对短句预加载缓存）
2. 评估内心独白混响链路在 Android 的稳定性：若延迟/不可用，回退原音播放（不阻塞）
3. 可选：`preload` 下一句/相邻句，减少首次加载

## 修复记录（2026-08-05 trae）

- [VoiceBank.ts](../../src/audio/VoiceBank.ts)：`play()` 改等 `loadeddata` 再播（`readyState>=2` 或命中 `readyCache` 立即播）；`readyCache` 缓存已就绪 URL（二次播放同句免等，Android 首次加载慢问题被缓存吸收）；2.5s 超时兜底（慢网络不永久沉默）；`stop()` 清理 pending 音频与定时器
- 保留：inner 混响链路（Web Audio convolver），失败仍回退原音
- 验证：新探针 `probe-bug039-voice-sync.mjs` 8/8 全绿（快速推进多行 / 播放后立即 stop / 同句重复命中缓存 / 对话开关链路无 JS 错误）+ probe-voice 11/11 + probe-skip-debounce 3/3 + probe-stargaze 14/14 + test-ch1-story 24/24 回归全绿
