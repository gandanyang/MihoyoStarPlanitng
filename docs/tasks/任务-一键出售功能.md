# 任务卡：一键出售功能（背包 + 商店）

> 立项：制作人 2026-08-03（"把所有可以卖的东西全卖了"）｜ 指派：opencode（商店逻辑线）｜ 优先级：P0（当前窗口，与 E-08 金币循环同一体验包）｜ 状态：✅ 已完成（背包/商店双入口 + 确认弹窗 + 经济逻辑）

---

## 1. 目标

在**背包（BackpackPanel）**和**商店（ShopPanel）**各加一个「一键出售」入口，把玩家所有可售物品一次性卖出（换金币）。

## 2. 设计约束

- **价格来源**：复用 ShopPanel 现有 `SELL_ITEMS` 表（含 CROP/矿石/木材等硬编码价格），**禁止新增第四价格源**（已知遗留：CROP_DEFS / Economy / ShopPanel 三源未收敛）
- **可卖判定**：只卖 SELL_ITEMS 中列出的物品（有 price 的）；**不可卖**：工具（锄头/水壶/斧头）、钥匙、auto_farmer_robot 机器人、钻石
- **防误触**：点击后弹确认（"确认卖出全部可售物品？"），二次确认才执行
- **反馈**：卖出后显示获得金币总额 + 已卖物品清单（浮字/toast）
- **存档**：无新字段（走既有 addGold / removeItem，随常规存档流程）

## 3. 实现位置

- `src/ui/BackpackPanel.ts`：背包面板加「全部出售」按钮
- `src/ui/ShopPanel.ts`：商店面板加「全部出售」按钮
- 公共逻辑建议抽到 `src/data/Economy.ts`（如 `sellAllSellable()`），避免两处重复实现

## 4. 验收

- [x] 背包/商店各有一键出售入口，二次确认后执行
- [x] 全部可售物品卖出、金币正确累加、物品清空
- [x] 不可售物品（工具/钥匙/机器人/钻石）不受影响
- [x] 空背包/无可售物品时按钮禁用或提示
- [x] tsc 0 错误 + 经济相关探针（若有）通过

## 5. 红线

- 不新增存档字段；不触碰机器人自动化逻辑
- 价格三源未收敛前，一键出售必须与 ShopPanel 现有出售同一价格
