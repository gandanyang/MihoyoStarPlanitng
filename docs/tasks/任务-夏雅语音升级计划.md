## 🎯 新声线方向（制作人脑暴 2026-08-05 定稿）

### 定位变化

夏雅不再是"温柔、善良、帮助主角的人"——如果按旧定位，配音很容易走甜妹/软糯/治愈系。现在夏雅 = **灯火**：一个在乡土环境长大、经历过变化、选择留下的人。声音必须跟着变。

### 三个核心关键词

1. **温暖，但不是柔弱**
2. **安静，但不是没有力量**
3. **有生活感，而不是二次元感**

### 声音画像

| 维度 | 方向 |
|---|---|
| 类型 | 年轻女性里带一点成熟感的**自然声线**（非少女音/非甜妹/非夹子音） |
| 年龄感 | 20~25 岁，声音里有"这个人经历过一些事情" |
| 音高 | **不宜太高**（拒绝高甜/元气/夹子音）；不是低沉，而是**胸腔共鸣更多**（"不是小鸟，而是窗边的一盏灯"） |
| 质感 | 真实的人声、自然、不过度表演、有呼吸感、有一点成年感 |

### 细节一：有一点疲惫感（重要）

夏雅不是完美治愈角色，她承担很多东西。声音里应该有**一点点疲惫**——"习惯了"的感觉。
- 例：林澈问"你怎么还没睡？"→ 她答"还有一点事情没弄完。"如果配得太轻快，角色就薄了。

### 细节二：与阿风形成对比

- 阿风：松弛、随意、带笑、不受束缚（"哎呀，别想那么多嘛。"）
- 夏雅：平静、但是熟悉（"你每次都这么说。"）
- 两人一对话，玩家立刻知道：**这两个人认识很久**。

### 细节三：与林澈的关系，声音有阶段变化

- **初见**：稍微客气、有距离（"林澈，好久不见。"——不是恋人，更像多年没见的旧朋友）
- **熟悉以后**：声音放松、会吐槽（"你小时候也是这样，想到什么就跑。"）
- **后期**：不是变甜，而是**更坦诚**，声音里的重量出来（"其实我以前也想离开这里。"）

### 一句话描述（选角基准）

> **像乡村夜晚的一盏灯，灯光不是耀眼的，但你靠近以后，会发现里面有人生活过。**

### 给配音演员/选角的直接话术

> "请不要演一个温柔女主，请演一个在乡村生活多年、外柔内韧的年轻女性。她对别人很体贴，但不是因为讨好别人，而是她已经习惯承担责任。声音里要有温度，也要有一点自己的坚持。"

### 名字意象

夏 = 热度，雅 = 安静 → 声音不是冷、不是甜，应该是 **夏天傍晚的声音**：有一点暖，有一点风吹过树叶的感觉。

### 候选试音句（选角时用于听感比对）

| 句 | 听感要求 |
|---|---|
| 你回来了啊。 | 很平静，但玩家能听出她其实有一点开心（❌ 不配成"你回来啦～"恋爱番） |
| 还有一点事情没弄完。 | "习惯了"的疲惫，不能太轻快 |
| 你每次都这么说。 | 平静，但是熟悉 |
| 林澈，好久不见。 | 初见客气，多年没见的旧朋友 |
| 你小时候也是这样，想到什么就跑。 | 熟悉后放松吐槽 |
| 其实我以前也想离开这里。 | 坦诚，声音里的重量出来 |
