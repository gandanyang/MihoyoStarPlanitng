## 3. 生活事件分层方案

### 3.1 类型 A：视觉生活动作（🟢 零剧情权限，纯技术）

让 NPC 在场景里"做事"，而不是站着发呆。

| NPC | 场景 | 动作 |
|-----|------|------|
| 老张 | mine | 挥镐循环 |
| 小梅 | farm/forest | 蹲下浇水/起身循环 |
| 阿风 | forest | 张望/转身 |
| 村长 | town | 踱步 |
| 商店老板 | town | 整理柜台 |
| 神秘少女 | forest | 静立（神秘感，不动反而对） |

**技术**：NPC.ts 加 `idleAnimation`，按 location 切换。**零台词、零剧情**。
**风险**：复用现有 sprite，可能需要 sprite 多帧；若无多帧则用 tween 模拟（左右摇摆/上下起伏）。

### 3.2 类型 B：NPC 互提关系网（🟡 需制作人定台词）

NPC 对话里提到其他 NPC，建立"村庄人际网"。

示例（仅技术示意，台词待制作人定）：
- 老张提小梅："小梅那丫头又来唠叨我喝酒…"
- 小梅提村长："村长说今天有新鲜事…"
- 阿风提老张："老张昨晚又喝多了…"

**技术**：扩 `NPC_DAILY_LINES`，加 `mention: npcId` 字段。**台词需制作人定**（角色关系属剧情权限）。

### 3.3 类型 C：NPC 主动招呼（🟡 需制作人定台词）

玩家走近时 NPC 主动说一句，而不是玩家按 E 才说话。

- 走进老张 3 格内 → 老张："哟，小伙子来啦"
- 走进小梅 → 小梅："今天花儿开得不错"

**技术**：NPC.ts 加 `playerNearbyTrigger`，距离触发 + 冷却时间。**触发台词需制作人定**。

### 3.4 类型 D：功能性事件（🔴 需制作人立项 + 剧情权限）

NPC 给玩家临时任务/物品，让"找他"有功能价值。

- 老张送矿石样本 → 触发"鉴定"小任务
- 小梅送稀有种子 → 解锁新作物
- 阿风送藏宝图 → 触发探索点

**涉及**：物品系统、任务系统、数值平衡、剧情。**必须制作人立项**。

### 3.5 类型 E：好感度系统（🔴 需制作人立项 + 存档字段）

[QuestPanel](../../src/ui/QuestPanel.ts#L36) 已留 "好感" tab 灰色占位。

- 每日对话 +1 好感
- 任务完成 +5 好感
- 好感解锁新对话/新功能

**涉及**：新增存档字段（`affinity: Record<NpcId, number>`）、版本迁移。**违反 AGENTS.md "未经允许不新增存档字段"，必须制作人批准**。

## 5. 我的建议

**先做阶段 2a（视觉生活动作）**，理由：
1. 零剧情权限 — 不用等制作人定台词
2. 零存档改动 — 不违反 AGENTS.md
3. 零新资源 — 复用现有 sprite（用 tween 模拟动作）
4. 效果立竿见影 — NPC 不再"发呆站着"，村庄感大幅提升
5. 与阶段 1 日程重构形成闭环 — "NPC 在对的时间去对的地方做对的事"

## 6. 风险与边界

### 6.1 技术风险

| 项 | 风险 | 缓解 |
|----|------|------|
| NPC sprite 无多帧 | 阶段 2a 动作可能受限 | 用 tween 模拟（yoyo 缩放/位移），不强制多帧 |
| playerNearbyTrigger 误触 | 阶段 2c 频繁弹对话烦人 | 加冷却时间（30 秒/次）+ 当天只触发 1 次 |
| 关系网台词一致性 | 阶段 2b 可能与人设冲突 | 台词必须制作人定，Agent 不代写 |

### 6.2 剧情权限边界

| 决策项 | 负责人 |
|-------|--------|
| 阶段 2b 关系网台词 | 制作人 |
| 阶段 2c 主动招呼台词 | 制作人 |
| 阶段 2c 功能性事件数值 | 制作人 |
| 阶段 2d 好感度系统立项 | 制作人 |
| 阶段 2d 存档字段新增批准 | 制作人 |

### 6.3 禁止事项

- ❌ 不新增 NPC（阶段 1 已定 6 个）
