# 任务卡：序章信息节奏检查

> 立项：制作人 2026-08-03 ｜ 指派：待定 ｜ 状态：待执行

## 目标

让序章**只负责建立悬念，不负责解释世界**。

## 执行

遍历序章每个剧情节点，统计：

- 玩家**知道了什么**
- 玩家**不知道什么**
- 玩家**产生了什么疑问**

如果某一节点一次性解释太多，给出**拆分到后续章节**的建议。

## 输出

逐节点表格（节点 / 知道 / 不知道 / 疑问 / 是否解释过量 / 拆分建议）。

## 关联

- 《剧情规范》第五条（玩家做了什么）、第六条（每段最多一个新设定）

## 红线

- 只出分析与建议，不改代码；拆分建议涉及后续章节的需制作人拍板
