## 目标

整理《归星物语》**统一称呼规范**，以后所有剧情统一使用。

## 维度

- 老人怎么叫主角（如：小林 / 林家那孩子 / 林爷爷家的孙子）
- 同龄人怎么叫（如：林哥 / 阿澈 / 林澈）
- 孩子怎么叫
- 陌生人怎么叫
- 熟人怎么叫

## 输出

统一称呼表（角色 → 称呼关系 → 称呼词 → 使用场景/语气），写入 `docs/世界观设定/NPC称呼规范.md`。

## 关联

- 《本地化规范》§1②（NPC 称呼）
- 《剧情规范》第二条

## 结果

产出 [NPC称呼规范.md](../世界观设定/NPC称呼规范.md)（2026-08-04，Trae）：

- 主角称呼表：长辈=小林/林家那孩子/小伙子，同龄=阿澈/林澈，妹妹辈=阿澈哥，神秘角色=不称名
- 现状核对：爷爷「小澈」✅ / 夏雅直呼「林澈」✅ / 老张「小伙子」✅ / 村长「孩子」可保留
