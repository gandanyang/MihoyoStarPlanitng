# 任务卡：P2 交互加固 — 教程期无斧头时，树旁按交互不应吞掉该次操作

> 指派对象：Trae
> 发起人：Codex（顶层设计 / 问题追踪）
> 优先级：P2（BUG-006 修复后触发概率≈0，属顺手加固）
> 状态：待执行

---

## 1. 背景（必读）

BUG-006（引导任务教程期投放，`408d8f9`）已修复后，教程期不再有"砍倒 2 棵树"引导，玩家按 E 靠近树被拦截的概率已降至≈0。

但残留一个**交互陷阱**：`MapScene.tryChopTree()` 在玩家无斧头（`getItemCount('old_axe') <= 0`）时，会显示"需要斧头才能砍树！"并 **`return true` 吞掉该次交互**。教程期玩家本就无斧头（教程完成睡觉后才赠送），若其恰好站在树旁按交互，本意是锄地/播种/浇水，却被砍树分支吞掉 → 农田操作无法推进。

评估记录见《问题追踪.md》观察项。

## 2. 目标

教程期（无斧头）在树旁按交互：**不吞交互、不弹提示**，让操作落到农田交互（或自然无响应），保证"按交互推进任务"不被树拦截。

## 3. 修改点（最小改动）

文件：`src/scenes/MapScene.ts` → `tryChopTree()`

现状：

```ts
// 斧头检查
if (getItemCount('old_axe') <= 0) {
  this.showDialogueText('需要斧头才能砍树！');
  return true; // ← 吞掉交互
}
```

改为：

```ts
// 斧头检查：无斧头时不吞交互（教程期玩家本无斧头，让操作落到农田交互）
if (getItemCount('old_axe') <= 0) {
  return false;
}
```

说明：斧头只在教程完成时赠送且不会消耗，因此"无斧头"仅发生在教程期；直接 `return false` 即可，无需提示。
