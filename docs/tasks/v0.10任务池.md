## 任务详解

### BUG-047 BGM 改 Web Audio 播放

**问题**：PC Web 端加载 title.mp3 时 IDM 弹出下载管理器

**方案**：BGM 改 fetch + AudioContext.decodeAudioData + AudioBufferSourceNode 播放

**范围**：
- MusicSystem.ts 重写
- 缓存上限 2 首防内存膨胀
- 保留自动播放补播机制

**任务卡**：`任务-BUG047-BGM播放改造.md`

---

### HUD-01 主线任务 HUD

**设计原则**：
- 不要 MMO 式任务栏
- 简洁一行提示
- 随剧情推进动态更新

**示例**：
```
当前目标：去森林寻找爷爷留下的线索
```
完成后：
```
星之碎片回应了你的到来
```

**实现**：
- StorySystem 新增 `getQuestObjective()` 返回当前目标文案
- MapScene HUD 区域显示
- 完成后自动更新

---

### FX-01 UI/交互动效

**范围**：
- UI 出现动画（淡入 + 缩放）
- 交互反馈（靠近交互物时高亮/微动）
- 收获反馈（作物收获时粒子 + 飘字）
- 碎片发光（星之碎片脉冲光效）

**价值**：玩法不是复杂战斗，卖点是"感觉"

---

### NPC-01 阿风生活化对白

**目标**：从"冒险家 NPC"变成"玩家记住的人"

**内容**：
- 3~5 段日常对白（非任务相关）
- 一个小事件（比如帮阿风找东西）
- 一个核心意象（比如阿风的冒险日志）

**约束**：
- 不扩世界观
- 不加新系统
- 纯文本 + 现有系统

---

### RECORD-01 归星录扩展

**触发**：后山老树

**内容**：
- 第一次触发：林澈「我以前来过这里？」
- 第二次触发：解锁归星录记忆片段

**实现**：复用 GuiXingRecordSystem + MemoryFlashback
