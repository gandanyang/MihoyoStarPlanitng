## 1. 任务目标

让玩家进入每一张地图时，能**听到"这座岛是活的"**：

- 农场：鸟叫 + 微风（白天）/ 虫鸣（夜晚）
- 森林：树叶沙沙 + 虫鸣
- 矿洞：低频矿石低鸣 + 回声感
- 小镇：远处人声底噪 + 风
- 大门/车站：安静的风声（"荒废感"）
- 屋内：静默（只有微弱的暖声底噪，营造安全感）

**核心原则**：环境音是**氛围基底**，不是旋律。要"听到但注意不到"，音量低、循环、避免突兀。操作音效（SfxName）优先级高于环境音（玩家操作时环境音让位/降低）。

## 2. 技术设计

### 2.1 新模块 vs 复用

**复用现有 AudioSystem**（模块级单例 + WebAudio 合成），**不新建独立系统**：
- 在 `AudioSystem.ts` 内扩展（保留 `play()` 不动），新增环境音管理
- 或者新建 `src/systems/AmbienceSystem.ts`，内部复用 AudioSystem 的 `getCtx()`/`tone()`/`noise()`（需导出）

**建议**：新建 `AmbienceSystem.ts`（环境音是长生命周期循环音，与一次性操作音效生命周期完全不同，独立文件更清晰；复用 AudioSystem 的合成原语）。符合 AGENTS.md "不创建重复系统"——这是**同一个 Audio 领域**的分层，不是重复系统。

### 2.2 环境音合成方案（WebAudio，全零资源）

| 环境音 | 合成方式 | 参数建议 |
|--------|---------|---------|
| 鸟叫 | 高频短促啁啾（2-4 个音调随机序列，随机间隔） | 1800-2600Hz，每次 0.05-0.1s，间隔 1.5-4s 随机 |
| 微风 | 低通滤波白噪声，音量缓慢起伏（LFO 调制 gain） | 200Hz 低通，音量 0.02-0.04，LFO 0.1-0.3Hz |
| 虫鸣（夜） | 持续高频正弦叠加（蝉鸣感）+ 轻颤音 | 4000-4500Hz 极低音量 + vibrato |
| 树叶沙沙 | 中频滤波白噪声，随机脉冲 | 1500Hz 带通，音量 0.02-0.05，随机断续 |
| 矿石低鸣 | 低频正弦堆叠（60-90Hz）+ 缓慢脉动 | 音量 0.05，脉动 0.2Hz |
| 人声底噪 | 极低音量中频噪声（无法辨认为语言，纯氛围） | 1000Hz 带通，音量 0.01-0.02 |
| 水声 | 低通噪声 + 随机小水珠音 | 类似现有 `water` 但更长更轻 |
| 屋内暖声 | 极低频暖噪声（安全感） | 200Hz 低通，音量 0.01 |

### 2.3 生命周期管理

```
进入地图 → AmbienceSystem.start(mapKey)
   ↓
  每帧（或低频率轮询）→ 根据 mapKey + gameTime 决定当前音源组合
   ↓
  播放组合（循环音源 + 随机事件音源）
   ↓
退出地图 → AmbienceSystem.stop()（全部停止，防止残留跨场景）
```

**关键**：
- **停止必须可靠**：场景切换（`scene.start` / `SHUTDOWN`）时调用 `AmbienceSystem.stop()`，防止上一场景环境音残留到下一场景（黑屏/切图 bug 风险，P0 优先级）
- **音源数封顶**：全局同时播放 ≤ 8 个音源（含操作音效），超限时优先保操作音效、砍环境音
- **昼夜差异**：`getTime()`（hour）判断 —— 白天(6-18)鸟叫+风，夜晚(18-6)虫鸣
- **静音/降级**：若 AudioContext 不可用或页面隐藏（visibilitychange）→ stop 环境音（省电 + 不破帧）

### 2.4 调用点

| 位置 | 动作 |
|------|------|
| `MapScene.createScene()`（或场景切换处） | `AmbienceSystem.start(this.mapKey)` |
| 场景切换 / 场景 shutdown | `AmbienceSystem.stop()` |
| （可选）对话/剧情全屏时 | 环境音降低音量（不停止） |

## 7. 风险与缓解

| 风险 | 等级 | 缓解 |
|------|------|------|
| 环境音残留跨场景（切图后旧声音不停） | 高 | stop() 挂场景 shutdown + 探针校验 |
| 低端安卓掉帧/爆音 | 中 | 音源数封顶（≤8）+ 纯合成低开销 + 真机验证 |
| 与 trae 在途 MapScene 冲突 | 中 | 4.3 前 git status 避让；探针先独立 |
| 环境音太吵/太突兀破坏沉浸 | 中 | 音量极低（0.01-0.05）+ "听到但注意不到"原则 + 真机/桌面试听 |
