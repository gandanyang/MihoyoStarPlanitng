# 任务卡：BUG-044 庄园大门教程卡死

> 登记：2026-08-05｜状态：✅ 已修复
> 关联：StationScene.ts / MapScene.ts / BackpackPanel.ts

## 问题描述

玩家在序章庄园大门（gate map）无法打开大门。表现为：背包中有钥匙，点击"使用"后无任何反应。

## 根因分析

### 直接原因
`useManorKey()` 在 `getStoryStep() !== 'get_key'` 时静默返回 `false`，无任何反馈。

### 深层原因：storyStep 错位
1. **对话中断**：玩家与夏雅对话（step = `xiya_talk`）时，对话被场景重建打断，callback 未触发，step 卡在 `xiya_talk`
2. **自愈缺口**：StationScene 坏档自愈只处理 `scene === 'farm'`，不处理 `scene === 'gate'` 的坏档
3. **无兜底重置**：`setupGateTutorial` 不处理 `xiya_talk` 中间态，导致 step 永久卡死

### 状态机问题
```
arrive_manor → (对话) → xiya_talk → (callback) → get_key → (使用钥匙) → gate_opened
                     ↑
              对话中断时卡死在此
```

## 修复方案

### 修复 1：StationScene 坏档自愈（gate 地图）
**文件**：`src/scenes/StationScene.ts`
```typescript
// 新增：gate 地图存档中 step 卡在 xiya_talk → 回退到 arrive_manor
if (saveData.player.scene === 'gate' && getStoryStep() === 'xiya_talk') {
    setStoryStep('arrive_manor');
}
```

### 修复 2：MapScene setupGateTutorial 兜底
**文件**：`src/scenes/MapScene.ts`
```typescript
// 新增：xiya_talk 是对话中间态，scene 重建时卡在此步 → 回退到 arrive_manor
if (step === 'xiya_talk') {
    setStoryStep('arrive_manor');
    step = 'arrive_manor';
}
```

### 修复 3：useManorKey 失败反馈
**文件**：`src/scenes/MapScene.ts`
```typescript
// 新增：key 使用失败时给玩家提示
if (getStoryStep() !== 'get_key') {
    this.showDialogueText('大门锁着，需要先拿到钥匙。');
    return false;
}
```

## 防范规则（防止类似 bug）

### 规则 1：对话中间态必须有兜底
**问题模式**：对话 callback 未触发时，step 卡在中间态（如 `xiya_talk`）

**防范措施**：
- `setupXxxTutorial()` 函数开头检查中间态，自动重置到上一个稳定态
- StationScene 自愈逻辑覆盖所有场景（farm/gate/town 等）

**代码规范**：
```typescript
// ✅ 正确：检查中间态并重置
if (step === 'xiya_talk') {
    setStoryStep('arrive_manor');
    step = 'arrive_manor';
}

// ❌ 错误：忽略中间态
if (step === 'arrive_manor') { ... }
```

### 规则 2：关键操作必须有反馈
**问题模式**：操作失败时静默返回，玩家无感知

**防范措施**：
- 所有 `return false` 的失败路径必须有 `showDialogueText` 或 UI 反馈
- 关键道具使用（钥匙、任务物品）必须有成功/失败两种反馈

**代码规范**：
```typescript
// ✅ 正确：失败时给反馈
if (condition !== expected) {
    this.showOperationExceptionText('操作失败原因');
    return false;
}

// ❌ 错误：静默失败
if (condition !== expected) return false;
```

### 规则 3：坏档自愈覆盖所有场景
**问题模式**：自愈逻辑只覆盖部分场景，其他场景的坏档无法恢复

**防范措施**：
- StationScene 自愈逻辑按场景分类处理
- 新增场景时必须同步更新自愈逻辑

**代码规范**：
```typescript
// ✅ 正确：按场景分类自愈
if (saveData.player.scene === 'farm') { /* farm 自愈 */ }
if (saveData.player.scene === 'gate') { /* gate 自愈 */ }
if (saveData.player.scene === 'town') { /* town 自愈 */ }

// ❌ 错误：只处理部分场景
if (saveData.player.scene === 'farm') { /* farm 自愈 */ }
// 忽略其他场景
```

### 规则 4：状态机中间态必须文档化
**问题模式**：状态机有中间态（如 `xiya_talk`），但未在文档中说明，导致遗漏

**防范措施**：
- StorySystem 状态机文档必须标注所有中间态
- 中间态必须有对应的兜底逻辑

**文档规范**：
```
## 状态机：庄园大门教程

| 状态 | 类型 | 说明 | 兜底 |
|------|------|------|------|
| arrive_manor | 稳定态 | 玩家到达大门 | - |
| xiya_talk | 中间态 | 对话进行中 | setupGateTutorial 重置 |
| get_key | 稳定态 | 已获得钥匙 | - |
| gate_opened | 稳定态 | 大门已开 | - |
```

## 影响范围

- StationScene：坏档自愈逻辑扩展
- MapScene：大门教程兜底 + key 使用反馈
- BackpackPanel：无改动（反馈通过 showDialogueText 实现）
