## 1. 任务目标

为 Demo 补齐第三幕情绪收尾：玩家交付星之碎片后，触发一次**小而有余韵**的夜晚演出，让林澈第一次主动选择，并以"归星镇，欢迎你"进入自由模式。同步给 3 个 NPC 各加一句话小故事、给神秘少女补 2 个"异常点"台词。

## 2. 设计定稿（必须先读，实现以此为准）

- **主题**：失去人的技术 vs 服务于人的技术。林澈不是逃离技术，而是重新找到技术与人的关系。
- **爷爷三件套**：Demo 只放"爷爷的信"（星图/日记留给第二、三章），回答"为什么爷爷留下这个地方"。
- **神秘少女**：身份是星轨守护者（作者知道、玩家不知道），Demo 只给异常点，**不解释、不揭底**。
- **收尾原则**：不做大事件、不做结算画面；做夜晚、信、选择、余韵。

## 3. 实现范围（最小改动点）

### 3.1 StorySystem.ts（剧情状态）

- StoryStep 扩展 `'observatory_complete'`（收尾演出完成标记）——**不新增 `demoEndingDone` 字段**：Demo 结束不是世界状态，复用现有 storyStep 模式
- 注意：`isTutorialDone()` 需兼容 `'done'` 与 `'observatory_complete'` 两种终态，避免教程相关判断失效
- `endingChoice: 'try_stay' | 'unknown' | 'tonight' | null`：仅模块内存态，**暂不入档**（第三章再决定是否持久化）

### 3.2 StoryDialogue.ts（对话选项支持，最小扩展）

- `DialogueLine` 增加可选字段 `options?: string[]`（选项行）
- 渲染：该行不自动推进，改为显示选项按钮（复用现有弹窗样式）
- 交互：鼠标/触屏点击选择；键盘支持（1/2/3 或 ↑↓ + E，实现者自定最小方案）
- 新增选择回调（如 `onChoice?: (index: number) => void`），选择后按分支播放后续行
- 要求：不破坏现有对话的推进逻辑；Skip 仍可用（跳过选项行视为选 A 或直接跳过）

### 3.3 MapScene.ts（触发点）

- 村长交付碎片（`SHARD_DELIVER_DIALOGUE` onComplete）后，检测 `getStoryStep() !== 'observatory_complete'`：

  - 演出结束：存档（沿用现有保存路径，不新增字段）、遮罩淡出、恢复自由操作
- 森林碎片交互（编剧审查修订）：首次按 E 先播放"程序员展示"对话（见 §5.1），对话结束后自动完成采集（含少女旁白、物品、任务进度），无需二次按键

## 4. 收尾演出脚本（可直接翻译成 DialogueLine）

```
（系统）夜幕降临。庄园外，今天的星空格外明亮。
（夏雅，从旁出现）你爷爷以前每天都会坐在这里。
（林澈）他也喜欢看星星？
（夏雅）嗯。他说，总有一天，会有人回来继续看。
（系统）夏雅看向石头边。那里压着一封信，被月光晒得发白。
（信）如果看到这封信，说明你终于回来了。
（信）我不知道你为什么回来。可能是累了，可能是迷茫了。
（信）但这里，永远有一个属于你的地方。
（系统）林澈握着信，抬头看向星空。
（系统）他没有说话。
（系统）远处传来虫鸣。星光落在庄园旧墙上。
（选择）
  A. 爷爷，我会试着留下。
  B. 我还不知道答案。
  C. 至少今晚，我想待在这里。
（分支独白，各一句，随后汇聚）
  A →（系统）林澈把信收好。也许这一次，可以试试看。
  B →（系统）林澈把信收好。有些答案，也许要在这里住很久才能找到。
  C →（系统）林澈把信收好。至少今晚，他想待在这里。
（系统）那一夜，他没有再说话。只有风穿过田野。
（系统）第二天清晨，新的早晨开始了。
（夏雅）归星镇，欢迎你。
（系统）已存档。现在开始，这座岛都是你的了。
```

演出风格要求：

- 信件 speaker 用「信」，颜色取米黄色（可复用 `COLORS.elder`），制造"爷爷的笔迹"感
- 台词克制、短句、不解释设定；玩家记住的是"爷爷是个人"和"我选择了留下"
- 选项只影响一句独白 + `endingChoice` 内存值（第三章再定是否入档），不分叉剧情
- 静默镜头（第 9-11、16 句）是情绪核心，实现时给足停顿时间，不要快速跳过

### 5.1 森林采集对话（编剧审查修订：程序员能力展示）

```text
（系统）森林深处，一块泛着幽蓝光芒的碎片静静躺在树根旁。
夏雅：我们试过很多办法，可它一直没有反应。
林澈：不是没有反应。
林澈：它像是在等待一个条件。
夏雅：你怎么看出来的？
林澈：以前调程序的时候，经常遇到类似的问题。
（神秘少女旁白）……它沉睡太久了。
（系统）采集到「星之碎片」！返回镇长处交付任务。
```

> 夏雅在森林时段（12:00-18:00）本就在场，对话可自然发生；若玩家在其他时段到达，以"她恰好在附近"处理即可，不做额外寻路。
