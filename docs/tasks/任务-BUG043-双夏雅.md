# 任务卡：BUG-043 花园清理时出现两个夏雅

> 登记：制作人 2026-08-04 安卓真机反馈｜级别：P1（重复 NPC，出戏，概率复现）｜状态：✅ 已完成

## 症状

安卓端收拾花园杂物（花园恢复清理）有概率出现**两个夏雅**，其中一个对话后消失，另一个还在场。

## 已核实（Codex）

- MapScene 有多个夏雅生成路径：`dawnXiya`（清晨浇水位 ~L938）/ `eveningXiya`（傍晚 ~L990）/ `xiyaSprite`（引导 ~L1308）/ `gardenXiya`（花园见证 ~L2499/2504）
- 疑因：`spawnGardenXiya()`（L2487 触发）未先销毁/隐藏同屏其他夏雅实例；当花园清理时刻与清晨/傍晚夏雅时段重叠时，两个实例同时在场；gardenXiya 对话后销毁，另一个残留 → 玩家看到"两个夏雅，一个对话后消失"

## 修复方向

1. `spawnGardenXiya()` 触发时，先统一清理/隐藏同屏其他夏雅（dawnXiya/eveningXiya/xiyaSprite）
2. 或建立"同屏仅一个夏雅实例"约束：新实例生成前销毁旧实例
3. 场景切换清理保持现有逻辑

## 验证

- 安卓/网页：花园清理各时段（清晨/傍晚/白天）均只出现一个夏雅；见证对话后消失，无残留
- tsc + 相关探针（npc/花园见证）回归
