# 任务卡：增加"清理杂物"引导（需求）

> 登记：制作人 2026-08-04 真机反馈｜级别：P1（新手引导）｜状态：📋 待施工（范围待确认）

## 需求

玩家进入庄园后**不知道要清理杂物**（荒废角落/倒木/破花架等可交互清理物无指引），需增加引导。

## 现状（已核实）

- 已有清理机制：教程 `clear_land`（锄地 3 块）｜`FarmRestore` 荒废角落（交互清理持久化）｜旧花园三阶段（倒木→破花架→恢复）
- 缺口：锄地教学之外，**没有提示玩家"庄园里还有可清理的杂物"**

## 范围（二选一，制作人确认）

- A：**开场引导**——进入庄园后夏雅对白/HUD 提示「先把院子里的杂物清一清」，指向可清理物（荒废角落/倒木）
- B：**旧花园清理引导**——花园恢复点倒木/花架清理时给明确指引
- 可 A+B（推荐先 A，覆盖面更大）

## 要求

1. 引导形式：夏雅生活化对白 + HUD/飘字提示（复用现有提示机制），不新增系统
2. 文案走叙事版本 L1（称呼/提示措辞），与现有台词风格一致
3. 探针同步；不改存档结构

## 验证

- 新玩家进入庄园能自然发现并清理第一处杂物；tsc + 相关探针回归
