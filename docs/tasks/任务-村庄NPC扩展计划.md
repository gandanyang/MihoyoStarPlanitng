## 3. 村庄感缺失的核心原因

### 3.1 NPC 日程同质化（最严重）

[NPCSystem.ts buildSchedule L107-113](../../src/systems/NPCSystem.ts#L107-L113) 默认日程：**4 个 NPC（村长/商店老板/神秘少女/老张兜底）共用同一时间表**，导致：
- 06-08 大家都在农场（挤一起）
- 08-12 大家都涌到小镇（小镇突然满人）
- 12-18 大家都去森林（森林突然满人）
- 18-22 全回农场

→ **不像有自己生活的村民，像跟团旅游**。

### 3.2 缺失"村庄生态职业"

参考真实村庄/星露谷，**核心基础设施职业**缺失：

| 缺口 | 影响 |
|------|------|
| 铁匠 | 没有工具升级入口（后续工坊系统可对接） |
| 医生/药师 | 没有恢复体力/治疗的接口（与睡觉恢复解耦） |
| 厨师/酒馆老板 | 没有料理系统入口（食物 buff） |
| 老师 | 没有孩童 NPC 的来源（村庄感断层） |
| 渔民 | 钓鱼系统 v0.7 已规划，没有 NPC 入口 |
| 神职/祭司 | 观星夜/星之碎片世界观没有 NPC 载体（v0.6 神秘少女可承担） |

### 3.3 缺失"村庄人口结构"

| 缺口 | 影响 |
|------|------|
| **孩童 NPC** | 村庄活力断层，看上去全是成年人 |
| **老人群体** | 只有村长 1 个老人，村庄感单薄 |
| **家庭单元** | 都是单身，没有夫妻/亲子关系，村庄不像生活社区 |
| **过客/流浪者** | 都是常驻，没有"今天来明天走"的活力 |

### 3.4 场景空旷

- **house（林澈家）**：0 NPC，纯过场场景
- **town**：NPC 只在 08-12 短暂停留，下午晚上完全空城
- **farm**：只有 06-08 和 18-22 有 NPC，白天是空的

## 4. 新增 NPC 建议方案（功能定位，不涉及身份）

### 4.1 优先级 P0：补齐村庄基础设施 NPC（建议 2-3 个）

> 这些 NPC 服务后续已规划系统，是"功能前置"。

| 功能定位 | 服务系统 | 日程建议 | 是否需新地图 |
|---------|---------|---------|------------|
| **料理 NPC**（厨师/酒馆老板） | v0.7 料理系统（未立项但顶层设计允许） | 全天 town，傍晚 house | town 增加酒馆建筑（不需新地图，加 tile 即可） |
| **钓鱼 NPC**（渔民/老渔夫） | v0.7 钓鱼系统（D3 已定） | 06-12 海边（v0.7 新地图）/ 12-18 town | v0.7 海滩地图上线后接入 |
| **工具/装备 NPC**（铁匠/机械师） | v0.7 工坊系统（D5 已定） | 全天 town 铁匠铺 | town 增加铁匠铺 |

**复用夏雅**：夏雅已是"机械维修师"，工具升级可**复用夏雅**而不新增 NPC，符合 [AGENTS.md](../../AGENTS.md) "不创建重复系统"。

### 4.2 优先级 P1：补齐村庄人口结构（建议 2-3 个）

> 这些 NPC 不服务系统，**只服务"村庄感"**，符合 v0.5.3 剧情密度增强的方向。

| 功能定位 | 服务目标 | 日程建议 |
|---------|---------|---------|
| **孩童 NPC**（1-2 个） | 村庄活力，与花匠小梅/老张等建立家庭关系 | 全天 town 广场玩 / 傍晚回 house |
| **老人 NPC**（1 个） | 与村长形成老人群体，世界观传达分散化 | 上午 town 晒太阳 / 下午 house |
| **夫妻 NPC 一对**（已有 NPC 配对） | 家庭单元感 | 错开日程（一人白天 town，一人 farm） |

### 4.3 优先级 P2：扩展村庄活力（建议 1-2 个，长期）

| 功能定位 | 服务目标 |
|---------|---------|
| **过客 NPC**（流浪商人/旅人） | 随机天数出现，卖稀有物品/讲外面世界 |
| **祭司/星象师 NPC** | 观星夜 / 星之碎片世界观载体（v0.6 神秘少女升级后可承担） |

## 5. 配套地图扩展建议

### 5.1 town 地图（最优先扩展）

**理由**：town 是"村庄感"的核心载体，但当前只是 NPC 短暂停留地。

建议增加（**不新建地图**，扩 tileset + 修 Tiled）：

| 建筑 | 服务 NPC | 备注 |
|------|---------|------|
| 酒馆 / 料理店 | 料理 NPC | 1 个 2×2 建筑 tile |
| 铁匠铺 | 工具 NPC（或复用夏雅） | 1 个 2×2 建筑 tile |
| 教堂 / 神庙 | 神职 NPC / 观星夜前置 | 2×3 建筑 tile |
| 广场长椅 | 老人 NPC / 孩童 NPC 玩耍 | 装饰 tile |
| 居民住宅 ×2 | 夫妻 NPC / 家庭 | 2×2 建筑 tile |

### 5.2 house 地图（林澈家）

**建议**：增加 1-2 个 NPC（如邻居老人串门），让 house 不再是纯过场。

### 5.3 farm 地图

**不建议**：farm 是主角私人空间，加 NPC 会破坏"归星庄园"的独处感（核心情绪）。

### 5.4 新地图（v0.7 范围）

- **海滩**：钓鱼 NPC + 渔民村落（v0.7 D3 已定）
- **矿洞深处**：深层矿工 NPC（已有老张，不必再加）

## 6. 日程重构建议（最小改动，效果最大）

不动 NPC 数量，仅改 [NPCSystem.ts buildSchedule](../../src/systems/NPCSystem.ts#L80-L113) 即可让村庄感大幅提升：

### 6.1 错峰日程

| NPC | 06-08 | 08-12 | 12-18 | 18-22 |
|-----|-------|-------|-------|-------|
| 村长 | house（家中晨起） | town（办公） | town（办公） | house |
| 商店老板 | house | town（开店） | town（开店） | house |
| 老张 | house | mine | mine | town（傍晚喝酒） |
| 小梅 | farm（照料花圃） | farm | forest | house |
| 阿风 | house | forest（早起探险） | town（讲述见闻） | house |
| 神秘少女 | forest | forest | forest | forest |

**关键改动**：
- 把"所有 NPC 06-08 在 farm"改成"06-08 在 house"（house 不再空）
- 把"所有 NPC 12-18 在 forest"改成"按职业分流"
- 老张傍晚去 town（村庄酒馆感）
- 小梅白天常驻 farm（与林澈邻居感）

### 6.2 SPOTS 扩展

[NPCSystem.ts SPOTS](../../src/systems/NPCSystem.ts#L44-L77) 目前只有 farm/town/forest/mine 四组。需新增 `house` 一组。

## 7. 风险与边界

### 7.1 剧情权限（必须制作人决策）

| 决策项 | 原因 |
|-------|------|
| 新 NPC 的具体身份 | 角色身份属剧情权限 |
| 新 NPC 的名字 / 性别 / 性格 | 角色设定属剧情权限 |
| 新 NPC 与现有 NPC 的关系（夫妻/亲子/师徒） | 角色关系属剧情权限 |
| 孩童 NPC 是否涉及未成年人保护审查 | TRAE 内容安全规则 |
| 神职 NPC 是否触及世界观真相 | 世界观真相属剧情权限 |

### 7.2 技术边界

| 项 | 影响 |
|----|------|
| NPCSystem.ts 当前 `NpcId` 类型是字面量联合（[L42](../../src/systems/NPCSystem.ts#L42-L42)） | 加 NPC 需改类型定义 |
| 每日任务池 [DailyQuestSystem.ts#L82-86](../../src/systems/DailyQuestSystem.ts#L82-L86) | 加 NPC 需同步加 `talk_xxx` 任务 |
| NPC sprite 资源 | 每个新 NPC 需 1 张 32×32 PNG，由 `tools/gen_npc_extras.py` 生成 |
| MapScene preload [L230-236](../../src/scenes/MapScene.ts#L230-L236) | 加 NPC 需加 load.image |
| SaveSystem | NPC 数量变化不影响存档（NPC 不进存档，仅位置由日程算） |

### 7.3 禁止事项

- ❌ 不新增战斗 / 抽卡 / 大地图 / 复杂养成（[AGENTS.md](../../AGENTS.md)）
- ❌ 不为单个 NPC 新建系统（复用 NPCSystem）
- ❌ 不重构 NPCSystem 架构（先提方案不直接重构）
- ❌ 不自扩剧情 / 角色设定

## 8. 推荐执行顺序（待批准后启动）

```
阶段 1：日程重构（零新资源，效果最大）
  ├─ 改 NPCSystem.ts buildSchedule（错峰日程）
  ├─ 新增 house SPOTS
  ├─ 修复"阿飞/阿风"不一致 bug
  └─ 探针验证：全时段 NPC 分布合理

阶段 2：补齐基础设施 NPC（P0，2-3 个）
  ├─ 制作人决策身份 → 写角色圣经
  ├─ tools/gen_npc_extras.py 生成 sprite
  ├─ NPCSystem.ts 加 NpcId + 数据 + 日程
  ├─ MapScene.ts preload 加载
  ├─ DailyQuestSystem 加 talk_xxx 任务
  └─ town 地图扩建筑（酒馆/铁匠铺）

阶段 3：补齐人口结构 NPC（P1，2-3 个）
  ├─ 制作人决策家庭关系
  ├─ 同上接入流程
  └─ town 地图扩住宅

阶段 4：v0.7 海滩扩展（已规划范围）
  ├─ 海滩新地图 + 渔民 NPC
  └─ 钓鱼系统接入
```

## 9. 需制作人决策的问题

1. **新 NPC 数量目标**：v0.6 阶段加几个？建议 2-3 个（避免膨胀）
2. **优先补哪类缺口**：
   - A. 基础设施（料理/铁匠/钓鱼）— 服务后续系统
   - B. 人口结构（孩童/老人/夫妻）— 服务村庄氛围
   - C. 日程重构优先（零资源成本，效果最大）
3. **新 NPC 身份是否需先写圣经**：按 [剧情开发规划.md §2](../../剧情开发规划.md) 规则，新角色必须先写圣经再写对话。请确认是否进圣经流程。
4. **house 场景是否接受 NPC 串门**：影响林澈独处感的核心情绪。
5. **日程重构是否进入 v0.5.4**：零资源成本，可与 BUG-021~026 修复并行。
