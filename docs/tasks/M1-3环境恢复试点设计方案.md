## 2. 技术可行性预研（四大问题）

实施前必须回答的四个问题，结论如下（详见 §4 候选点成本表）：

### 2.1 问题一："荒废感"用什么表达？

当前 farm_tileset 仅 **8 格**（gid 1-8，128×16px，M1-1 未扩展），**没有**荒草/倒木/破花架瓦片。

**结论**：不用新瓦片。复用 M1-2 已验证的"零资源纯代码"路线：
- 恢复前：Ground 层 `setTileAt` 铺 gid 2 泥土（荒土）+ Graphics 画倒木/破花架/荒草（歪斜色块）
- 恢复后：Walls 层 `setTileAt` 铺 gid 8 花 + Ground 铺 gid 7 小路 + 动态花/蝴蝶（复用 `tiles_fs` 切帧技巧 + tween）

### 2.2 问题二：地图瓦片怎么在运行时替换？

Phaser Tilemap 支持 `setTileAt(gid, col, row)` 运行时改瓦片（仅影响当前场景实例，不改 farm.json 文件）。

**结论**：farm.json **零改动**。恢复点状态由代码在 create 时读存档字段决定，用 setTileAt + sprite/Graphics 重建。切换场景/跨天重进时重新按状态还原。

### 2.3 问题三：状态存哪里？

制作人示例接受 `farmRestore.garden = true`。当前 [SaveSystem.ts](../../src/systems/SaveSystem.ts) 的 `SaveData.farm` 下加**可选字段**：

```typescript
farm: {
  tiles: [string, TileState][];
  crops: [string, CropData][];
  trees: [string, TreeState][];
  restore?: Record<string, boolean>;   // M1-3 新增，可选，向后兼容
}
```

- 版本号 **不变**（保持 '0.5'）：可选字段缺失 → 视为全部未恢复，旧档直接可用
- sanitize() 无需改动（可选字段，非法值无影响）
- DEV_CONTEXT §6"默认不增加存档字段"的例外：制作人 D3 明确批准

### 2.4 问题四：交互怎么做？

复用 [MapScene.ts](../../src/scenes/MapScene.ts) 现有模式：`tryInteract()` 已有大量"靠近按 E / 点击 → 分支处理"的先例（爷爷笔记 E5 L1645、星之碎片 L1691、矿脉 L1708）。恢复点加一个分支即可，**不动**现有分支。

## 5. 试点 A 详细设计（爷爷的旧花园）

### 5.1 交互流程

```
玩家靠近花园区域（2 格内）
   ↓ 按 E / 点击
提示（showDialogueText）："这里乱糟糟的……像是很久没人打理了。"
   ↓ 按 E（3 段推进，每段 1 次交互）
第 1 段：清理倒木  → 倒木 Graphics 消失 + "噼啪"清理反馈
第 2 段：拔掉荒草  → 荒草 Graphics 消失 + 荒土 gid 2 变浅
第 3 段：重新翻土  → 铺 gid 7 小路 + gid 8 花丛 + 蝴蝶飞出
   ↓ 完成后
存档 restore.garden = true + save()（里程碑入档）
蝴蝶停留 + 一次旁白（夏雅）
```

> 3 段推进 vs 一次完成：3 段推进成本仅 +20 行（状态机复用），反馈感强得多，推荐保留。

### 5.2 视觉规格（纯代码）

| 元素 | 实现 | 恢复前 | 恢复后 |
|------|------|--------|--------|
| 地面 | `setTileAt`（Ground 层） | gid 2 泥土×若干 | gid 1 草地 + gid 7 小路 |
| 花丛 | `setTileAt`（Walls 层） | 无 | gid 8 花×6-8 |
| 倒木 | Graphics（棕色横条，歪斜 15°） | 显示 | destroy |
| 破花架 | Graphics（木色两竖 + 横梁） | 显示 | destroy |
| 荒草 | Graphics（绿色短线×n） | 显示 | destroy |
| 蝴蝶 | Graphics 双翼 + 正弦 tween（复用 M1-2 花摆动模式） | 无 | 2 只，绕花丛飞 |
| 对白 | showDialogueText / StoryDialogue | - | 完成后 1 句 |

### 5.3 夏雅路过对白（⚠️ 待剧情确认，不外扩）

建议文案（供制作人确认，涉及爷爷记忆，遵循[剧情权限规则](../../AGENTS.md)）：

> 夏雅："这里以前也是爷爷最喜欢来的地方。他总说，花开的时候，心情也会跟着亮起来。"

实现方式：复用现有 E1/E9 夏雅精灵机制（清晨/傍晚 farm 出现），恢复完成后，夏雅出现位置改为花园旁，靠近对话触发此句（StorySystem 新增一条轻量对白数组，不入主线状态机）。

### 5.4 存档设计

