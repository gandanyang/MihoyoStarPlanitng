## 二、T2 修改计划（三块，全部复用现有系统）

### 改动 1：Day1 引导链（串起"为什么"）

**目标**：玩家第一天理解"清理→播种→等待→收获→出售→获得资源→修复青禾镇"是一条链。

**实现**（复用 `DailyQuestSystem` 的 guide 注入机制，不加新任务系统）：
- 在现有每日引导 quest 里，**补链式文案**（不是新任务，是现有引导文案强化）：
  - 播种后 → 提示"等它长大，收成能换钱修镇上的旧东西"
  - 收获后 → 提示"这些收成，是镇上老房子的建材费"
- 复用 `QuestPanel` / HUD 现有引导提示位，零新 UI。

### 改动 2：两个关键对白（村长 / 夏雅）

**目标**：村长解释"为什么种田"，夏雅解释"为什么小事会改变这里"。

**实现**（在 `src/systems/StorySystem.ts` 新增 2 个 `DialogueLine[]`，触发挂现有节点）：
- **村长对白**（挂 `ELDER_QUEST_DIALOGUE` 交付后 或 首次到镇触发）：解释这座岛靠作物养活过一镇人、田是岛的心跳——种田不是攒钱，是让地方活过来
- **夏雅对白**（挂 `GARDEN_RESTORED_XIYA_DIALOGUE` 或首次收获后）：解释爷爷怎么用一把锄头把荒地变成家——每一件小事都在让这里"有人气"

**接入方式**：只加数据 + 在 MapScene 现有触发点追加 `play()` 调用（复用 `storyDialogue`），零新系统。
