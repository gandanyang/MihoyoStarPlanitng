# 任务卡：序章本地化审核（最高优先级）

> 立项：制作人 2026-08-03 ｜ 执行：Codex ｜ 状态：✅ 已完成（审核基线 = v0.7 已落地工作区）

## 目标

审核《归星物语》**序章全部剧情**，逐处给出：原文 → 问题 → 修改建议 → 修改后文本。

## 检查重点

1. 是否存在翻译腔
2. 是否存在日式轻小说表达
3. 是否存在欧美生活方式表达
4. 是否符合中国乡村语境

## 要求

- 保留二游风格，但人物说话方式符合中国人的表达习惯
- **不要为了本地化而刻意使用方言**
- 输出完整审核报告（每处：原文 / 问题 / 修改建议 / 修改后文本）
