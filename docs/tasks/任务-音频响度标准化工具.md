# 任务卡：音频响度标准化工具

> 立项：制作人 2026-08-05（体验债务：主线剧情配音音量不一致）｜状态：📋 设计方案

## 问题描述

主线剧情配音音量不一致，部分音频过大刺耳，部分过小听不清，影响玩家体验。

## 目标

1. **标准化音量**：所有音频文件统一到目标响度水平（-16 LUFS 推荐值）
2. **批量处理**：支持一次性处理整个 audio/voice/ 目录
3. **非破坏性**：保留原始文件，输出到新目录
4. **可视化报告**：生成处理报告，显示每个文件的原始响度和调整后响度

## 技术方案

### 方案 A：离线预处理工具（推荐）

使用 Python + pydub/ffmpeg 实现：

```python
# 核心逻辑
1. 扫描 audio/voice/*.wav 文件
2. 使用 ffmpeg 计算每个文件的响度（LUFS）
3. 计算目标响度与实际响度的差值
4. 使用 ffmpeg-normalize 调整音量
5. 输出到 audio/voice_normalized/
6. 生成处理报告
```

**优点**：
- 一次性处理，无运行时开销
- 可精确控制响度标准
- 不影响游戏性能

**缺点**：
- 需要手动运行工具
- 新增音频需重新运行

### 方案 B：运行时标准化

在 VoiceBank 播放时动态调整：

```typescript
// 核心逻辑
1. 音频加载时分析响度（Web Audio API AnalyserNode）
2. 计算增益补偿值
3. 使用 GainNode 调整播放音量
```

**优点**：
- 自动处理新音频
- 无需手动工具

**缺点**：
- 运行时性能开销
- 分析精度有限
- 首次播放可能有延迟

## 推荐方案

**方案 A（离线预处理工具）**，原因：
1. 游戏音频文件固定，不需要动态处理
2. 离线处理精度更高
3. 无运行时性能影响

## 实现细节

### 工具脚本：`tools/normalize_audio.py`

```python
#!/usr/bin/env python3
"""
音频响度标准化工具
用法：python tools/normalize_audio.py --input audio/voice/ --output audio/voice_normalized/
"""

import argparse
import os
import subprocess
import json
from pathlib import Path

# 目标响度（LUFS）
TARGET_LUFS = -16.0
# 响度容差（±1 LUFS）
TOLERANCE = 1.0

def get_loudness(file_path: str) -> float:
    """使用 ffmpeg 计算文件响度（LUFS）"""
    cmd = [
        'ffmpeg', '-i', file_path,
        '-af', 'loudnorm=I=-16:TP=-1.5:LRA=11:print_format=json',
        '-f', 'null', '-'
    ]
    result = subprocess.run(cmd, capture_output=True, text=True)
    # 解析输出获取响度值
    for line in result.stderr.split('\n'):
        if '"input_i"' in line:
            return float(line.split(':')[1].strip().replace('"', '').replace(',', ''))
    return 0.0

def normalize_file(input_path: str, output_path: str, target_lufs: float):
    """标准化单个文件"""
    cmd = [
        'ffmpeg', '-i', input_path,
        '-af', f'loudnorm=I={target_lufs}:TP=-1.5:LRA=11',
        '-y', output_path
    ]
    subprocess.run(cmd, capture_output=True)

def main():
    parser = argparse.ArgumentParser(description='音频响度标准化工具')
    parser.add_argument('--input', required=True, help='输入目录')
    parser.add_argument('--output', required=True, help='输出目录')
    parser.add_argument('--target', type=float, default=TARGET_LUFS, help='目标响度 (LUFS)')
    args = parser.parse_args()
    
    # 创建输出目录
    os.makedirs(args.output, exist_ok=True)
    
    # 扫描 wav 文件
    wav_files = list(Path(args.input).glob('*.wav'))
    report = []
    
    for wav in wav_files:
        print(f'处理: {wav.name}')
        loudness = get_loudness(str(wav))
        output_path = os.path.join(args.output, wav.name)
        normalize_file(str(wav), output_path, args.target)
        new_loudness = get_loudness(output_path)
        
        report.append({
            'file': wav.name,
            'original_loudness': loudness,
            'normalized_loudness': new_loudness,
            'adjustment': new_loudness - loudness
        })
    
    # 生成报告
    report_path = os.path.join(args.output, 'normalization_report.json')
    with open(report_path, 'w', encoding='utf-8') as f:
        json.dump(report, f, indent=2, ensure_ascii=False)
    
    print(f'\n处理完成！报告已保存到: {report_path}')
    print(f'共处理 {len(wav_files)} 个文件')

if __name__ == '__main__':
    main()
```

### 集成到构建流程

在 `tools/build_apk.py` 中添加标准化步骤：

```python
def normalize_voice():
    """构建前自动标准化语音文件"""
    voice_dir = ROOT / 'public' / 'audio' / 'voice'
    normalized_dir = ROOT / 'public' / 'audio' / 'voice_normalized'
    
    if normalized_dir.exists():
        # 使用已标准化的文件
        shutil.copytree(normalized_dir, voice_dir / 'normalized', dirs_exist_ok=True)
    else:
        # 首次运行标准化
        subprocess.run([
            sys.executable, str(ROOT / 'tools' / 'normalize_audio.py'),
            '--input', str(voice_dir),
            '--output', str(normalized_dir)
        ])
```
