# 任务卡：P1 青禾镇生活化升级

> 状态：✅ **已完成**（Codex 2026-08-06，probe-town-life 12/12）
> 立项：制作人 2026-08-06（视觉升级方案 v0.10+，P1 最推荐）
> 一句话：青禾镇从"有特效"升级为"有生活"——杂物、小动物、晨雾/萤火虫，全部零资源代码叠加，不碰 Tilemap 与玩法。

---

## 一、背景

玩家第一眼看到的是青禾镇；现在镇上有炊烟/窗灯/落叶，但缺生活痕迹（木柴、晾衣、花盆、小动物）。方向文档见 [视觉升级方案-v0.10-生活感方向.md](../design/视觉升级方案-v0.10-生活感方向.md)。

---

## 二、现状（施工前复核）

- `MapScene.setupTownAmbience()`（`src/scenes/MapScene.ts` ~2011）：已实现炊烟 ×4、窗灯 ×8（≥18 时/<6 时）、行道树落叶 ×2。
- 可复用模式：`tiles_fs` spritesheet（tiles 图切帧，frame 7 花）、`__WHITE` 粒子、Graphics 纯绘制（见 `setupForestAmbience` 野花）、蝴蝶 `createButterfly`（~line 3900）。
- 地图：`public/assets/maps/town.json`（Tile 16px，Walls/Ground 两层）。

---

## 三、实施内容

### Task 1：生活杂物装饰层（P0）

新增 `setupTownDecorations()`（或并入 `setupTownAmbience`），纯 Graphics / tiles_fs 帧，物件建议：

- 木柴堆（房屋旁）×2
- 晾衣架（含衣物，可加轻摆 tween）×1
- 花盆 ×3~4（门前/窗下）
- 水桶 ×1~2、木箱 ×1~2、小推车 ×1
- 扫帚/石凳（村长家门前附近）
- 路边石头 ×3~5、草丛 ×6~8（散落空地）

要求：
- 位置与 Walls/Ground 层核对，**避开**：NPC 站位、商店/村长家/出口、现有交互点（参照 forest 注释惯例写清"已核对避开 xxx"）。
- 视觉风格贴合现有 16px 像素（Graphics 用 1~2px 描边、低饱和色）。
- 物件深度按层（装饰 ≤3，角色 4+，避免盖住 NPC）。

### Task 2：小动物活动点（P1）

- 复用蝴蝶模式；新增 1~2 只小鸟/猫：固定小范围往返（tween），不穿墙、不挡路、不与 NPC 站位重叠。
- 低频动作（小动物不是主角，别抢戏）。

### Task 3：昼夜氛围补齐（P1）

- 清晨薄雾：6~9 时低透明度雾带/粒子（淡白，`blendMode:NORMAL`，缓慢横移）。
- 夜间萤火虫：18 时后镇上出现 2~3 处微光（复用 forest 萤火虫参数，绿色系）。
- 窗灯已存在，**不重复实现**。

### Task 4：清理与性能（P0）

- 粒子发射器数量 ≤ 现有风格上限（预计新增 ≤6 个发射器/轻量 tween）。
- 场景 shutdown 自动销毁（现有模式天然满足，不额外写清理，除非发现泄漏）。
- 移动端同帧率：低透明度 + 小数量，手机 WebView 无卡顿。

### Task 5：验收探针（P1）

`tests/probes/probe-town-life.mjs`（puppeteer）：

- 进入青禾镇 → 控制台零报错；
- 断言装饰组已创建（可通过暴露 debug 统计或截图对比）；
- 分别验证 6:00 / 12:00 / 20:00 时段：晨雾仅清晨、萤火虫仅夜间；
- 截图存档（昼/夜各 1 张）供制作人目测。

## 五、验收标准

- ✅ 进镇第一眼可见生活杂物（≥8 类物件），不遮挡 NPC/交互
- ✅ 清晨出现薄雾，白天消失；夜间出现萤火虫，白天消失
- ✅ 小动物固定范围活动，不穿墙、不挡路
- ✅ 所有装饰避开 NPC 站位 / 商店 / 村长家 / 出口 / 现有交互点
- ✅ `tsc` 0 错 + 探针通过 + 移动端帧率稳定
- ✅ 存档/剧情/碰撞零改动
