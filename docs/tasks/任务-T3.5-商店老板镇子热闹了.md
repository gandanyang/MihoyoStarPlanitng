## 一、事件定义（制作人已拍板）

| 项 | 内容 |
|---|---|
| 事件名 | 商店老板「镇子热闹了」 |
| 触发 | 首次在商店卖出作物后，白天与商店老板对话 |
| 流程 | 老板请林澈送一篮作物给村长 → 村长收下并说镇上好久没这么热闹 → 回商店复命 |
| 交付物 | 作物 ×N（数值制作人定，Demo 建议 3~5，用现有作物不新增物品） |
| 奖励 | 无物质奖励；记忆卡 + 回响对白 |
| 记忆卡 | 「你来了之后，感觉不一样了。」 |
| 回响 | 老板之后说："店里的货，越来越有人买了。" |
| 设计目的 | 连接两个 NPC；证明"卖出作物"不只是经济行为，而是让小镇重新有人气 |

---

## 二、技术方案（复用，零新系统）

完全复用支线试点（夏雅藤架 / 村长星空）已验证的模式：

- **一次性标记**：`MapSceneFlags` 新增 `side_shop_crop`（可选字段，旧档默认 false）
- **交付判定**：复用 `DailyQuestSystem` 的 collect 判定写法（物品扣除）
- **记忆卡**：`data/MemoryFlashbacks.ts` 新增一条闪回数据（文案锚定拍板台词）
- **回响**：商店老板普通对话池追加一句（按 flag 存在切换）
- **触发时机**：商店首次卖出作物后置位"可触发"标记（`shop_first_sale`），白天与老板对话时检查
