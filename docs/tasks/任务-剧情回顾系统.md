# 任务卡：FEATURE-040 剧情回顾（Dialogue History）

> 状态：✅ 已完成（2026-08-06，probe-dialogue-history 13/13）
> 立项：制作人 2026-08-06 拍板（P1 体验增强）
> 一句话：剧情对话期间右上角「剧情回顾」入口，半透明只读面板回看最近 50 条对话；不存档、不重播、不跳转

---

## 一、背景与动机

- 项目剧情占比高、配音多、NPC 关系重，玩家可能断续游玩；没有回顾会出现"等等，刚才发生什么了"。
- 不做传统二游"剧情档案馆"，只做轻量版：对话期间可随时回看当前上下文。
- 隐藏收益：提升"二游感"——错过一句话还能回看，且本作是慢节奏体验，天然匹配。
- 优先级 P1（体验增强），高于天气/季节/羁绊：先让玩家舒服地吃下故事。

## 三、实施内容

### Task 1：DialogueHistoryManager（新增，内存环形缓冲）

`src/systems/DialogueHistoryManager.ts`，模块级单例：

```ts
interface DialogueHistoryEntry {
  speaker: string;
  text: string;
  inner?: boolean;   // 内心独白（面板内斜体灰字）
  color?: string;    // 说话人颜色（沿用 DialogueLine.color）
  ts: number;        // 记录时间戳
}

addEntry(entry): void   // 超 MAX 时挤出最旧
getHistory(): DialogueHistoryEntry[]  // 按时间正序返回
clear(): void
MAX = 50
```

- **不写存档**（SaveData 零改动）；模块级状态随页面刷新自然重置，服务"一次游戏体验"。
- 会话级累计：不随 `play()` 自动清空（可回看本局之前几段对话）；`clear()` 留给后续章节切换/新游戏（v1 可无调用点）。

### Task 2：StoryDialogue 接入

- 每次 `showLine()` 显示新行时调用 `history.addEntry({ speaker, text, inner, color, ts })`（选项行 `options` 不记录）。
- 右上角新增「📖 剧情回顾」按钮（放 Skip 左侧，同款样式家族）；**pointerdown + click 双绑定 + stopPropagation**（防 Android click 不触发、防误触推进）。
- 面板打开期间：面板本身 `pointerEvents:auto` 拦截点击；当前行冻结（不继续打字机、不响应 `advance()`）；关闭后恢复原状态继续。

### Task 3：DialogueHistoryPanel（新增）

`src/ui/DialogueHistoryPanel.ts`（DOM，半透明覆盖层，只读）：

- 半透明深色背景 + 居中滚动列表（`overflow-y:auto`），顶部标题「剧情回顾」+ 关闭按钮；点空白或关闭按钮均可关闭。
- 每条：说话人名（沿用角色色）+ 文本；内心独白斜体灰字；最多展示最近 50 条，最新在最下（或最上，施工自选并保证滚动到底/顶）。
- 移动端：`max-width`、可触摸滚动、按钮可点（参考 Skip 的触屏兼容写法）。
- 复用 `panelFadeIn/panelFadeOut`。

### Task 4：验收探针（新增）

`tests/probes/probe-dialogue-history.mjs`：

- 打开一段对话 → 右上角按钮可见；
- 点击按钮 → 面板打开，条目数与已播放行数一致，最近一条 = 当前行；
- 关闭面板 → `advance()` 仍可继续推进，剧情不丢行；
- 播放 ≥51 行（可用短循环剧本模拟）→ 最旧条目被挤出，总数 ≤50；
- 移动端布局下按钮/面板可点击。
