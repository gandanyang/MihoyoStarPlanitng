## 一、本任务目标（制作人定稿）

#28 像《原神》角色**第一次见面任务的第一阶段**——不是传说任务：

> "玩家第一次遇见这个角色，觉得这个人有魅力。"

林澈回岛 → 遇到阿风 → 聊几句 → 知道他正在旅行 → 产生后续期待。

完成后玩家应得到**四个认知**：

### 1. 他是林澈的旧朋友
- 知道：两人小时候认识

### 2. 他现在是一个旅行中的冒险者
- 知道：阿风一直/正在旅行（冒险者身份**保留并强化**）

### 3. 他性格轻松、有探索欲
- 感受到：轻松 / 随性 / 好奇 / 喜欢观察世界

### 4. 他和归星岛有特殊联系
- 点到为止：他对这个岛不只是路过（不解释原因）

**结束。**不承诺深度、不挖掘内心。

### 不应该放进 #28（全部留给《追风的人》）

- ❌ 为什么阿风一直旅行
- ❌ 他害怕停下来
- ❌ 他和故乡的关系
- ❌ 观测台 / 风向标 / 旧相机背后的故事
- ❌ "自由"的主题讨论

> 因为这些属于**角色成长**，不属于**首次认识**。

### 阿风"冒险者"身份的意义（制作人确认，保留并强化）

冒险者身份与林澈形成对比：

| | 状态 | 动机 |
|---|---|---|
| 林澈 | 曾经离开 | 为了寻找未来 |
| 阿风 | 一直离开 | 为了寻找世界 |

> 两个人都在向外走，但是**原因不同**。这个对比是 #28 可以轻轻立住的，不用解释。

**不要：**

- ❌ 讲完背景（家庭/过去/内心矛盾全部不透露）
- ❌ 提前解释自由主题（"追风的人"内核属 Beta）
- ❌ 强行煽情

> 一句话验收标准：玩家看完后觉得"这个 NPC 挺有意思，以后想多聊聊"，且不知道他为什么。

## 三、现有台词 vs 新目标差距（施工重点）

现有 6 句：

```
（刚走进庄园，就看见阿风靠在木屋前的栅栏上，远远地朝你挥手。）
阿风：嘿！你回来了！
林澈：阿风？你怎么跑庄园来了？
阿风：路过，顺便看看。听说你把这儿拾掇得挺像样，我来长长见识。
林澈：（笑）就是刚开荒，还乱着呢。
阿风：乱不怕，有人气就行。你忙你的，我先走啦——回头找你玩。
```

| 目标（新定位） | 现状 | 差距 |
|---|---|---|
| 旧朋友（小时候认识） | 🟡 "熟识的旧友"感有，但未点出童年 | **需补**（一句即可，点到为止） |
| 旅行中的冒险者（认知2） | 🟡 有"路过/到处跑"暗示，身份不够清晰 | **需强化**（让他自述"在路上"） |
| 性格：轻松/有探索欲（认知3） | ✅ "长长见识""乱不怕"有 | — |
| 与归星岛有特殊联系（认知4） | ❌ 未体现 | **需补**（半句即可，不解释原因） |
| 留下期待 | 🟡 "回头找你玩"有弱期待 | 可留（不承诺深度） |

## 四、施工要求

### 1. 台词修改（制作人已定稿建议，**新增 1 句 + 修改 1 句**，不膨胀）

**控制对白数量：只做「新增 1 句 + 修改 1 句」，不要增加大量对白。**

**语言风格（沿用《追风的人》全局原则，制作人 2026-08-07 定稿）**：
> 生活化的对白里藏一点诗意——日常 70% / 文学 30%；关键句子只能偶尔出现，平时像朋友聊天。阿风气质：轻盈、有远方感。

- **保留**：「嘿！你回来了！」（这句很好：体现熟悉感 + 老朋友关系。adv_07 已配音，复用）

- **新增**：「没想到这么多年过去，你还是回来了。」
  - 作用：直接建立「林澈离开 → 多年后回来」的事实，点出"小时候认识"（认知1）

- **修改**（替换普通寒暄）：
  - 不要：「这些年我去了好多地方。」（只报行程，未立身份）
  - 改成：「我这些年也一直在外面跑，有时候走着走着，会想起小时候我们在这里吹风的日子。」
  - 作用：一句同时立住 认知2（在旅行）+ 认知4（对岛有特殊联系）
  - 注意：这里**触碰了"旅行/故乡"的边缘，但不要继续展开**，说完即止——不解释为什么跑、不解释和岛的关系

**注意**：改台词 = 改配音。改过的句子必须同步重录（MiniMax 温润青年 C，流程见 `docs/VoxCPM语音生成一键调用手册.md`）并更新 voicebank 映射文本；未改的句子（adv_07「嘿！你回来了！」）保留现有音频。

### 2. 触发条件（保持现状，不扩展）

- 保持 `ch1TownIntroDone` 门槛：玩家去过镇上（第一章）→ 对"小时候认识"有铺垫，且错开 day2 清晨演出
- 保持一次性 `triggerOnce`
- **不新增**任何新系统/新变量（木匠回归、旧屋修复等与 #28 无关，勿绑定）

### 3. 红线

- 不透露：家庭 / 过去经历 / 内心矛盾 / "追风的人"主题
- 不解释：为什么旅行 / 害怕停下来 / 故乡关系 / "自由"主题（角色成长内容全部留给 Beta）
- 不写"神秘第三人"；童年照片类内容属 Beta 篇章
- **不出现**：风向标 / 相机 / 观测台 / 第三位朋友 / 为什么离开——全部留给 Beta
- 不改世界观真相、不改其他 NPC
- 保持 5 分钟内体量：对话句数不膨胀（≤6 句），无新场景、无新地图

### 4. 配音

- 沿用 MiniMax 温润青年 C（`speech-2.8-turbo`，制作人 08-07 选型）
- 只重录改动的句子；流程：MiniMax 生成 → 16k mono wav → `normalize_audio.py`（-16 LUFS）→ `convert_voice_ogg.py` → 更新 `voicebank.data.ts` 文本映射
- 交付前试听（语音交付流程：先试听再打包，制作人确认后再打包）

## 六、验收 Checklist（制作人定稿）

### 剧情
- [ ] 玩家知道阿风和林澈**小时候认识**
- [ ] 玩家知道阿风**喜欢旅行**
- [ ] 玩家感受到阿风和林澈**关系自然**
- [ ] **没有透露 Beta 剧情**（风向标/相机/观测台/第三位朋友/为什么离开）

### 情绪
- [ ] 完成后玩家感受是 **"这个 NPC 挺有意思，以后想多聊聊。"**
- [ ] **不是** "我已经知道他所有过去了。"

### 技术
- [ ] 触发条件不变（`ch1TownIntroDone` + 一次性）
- [ ] StorySystem **不新增状态**
- [ ] voicebank **只替换必要音频**（其余不动）
- [ ] **不新增资源依赖**
