# 任务卡：Alpha 玩家流程审查（First Play Test）

> 立项：制作人 2026-08-07（依据 GPT 请示桥评估 + 上架 TapTap 无玩家现状）｜状态：📋 待认领｜执行人：待定
> 关联：v0.10 Demo、商店页上架素材、美术升级规范-v1.0（Batch D 储备）
> 性质：**纯审查任务，不改任何代码、不新增系统、不改存档结构**

---

## 一、为什么做这个任务

《归星物语》已具备 Demo 骨架（种田→建设→世界变化、复兴系统、记忆卡→相簿、EventManager、worldRestore 存档），且宣传物料充足（30+ 张 AI 图），但上架 TapTap 后没有玩家。

核心怀疑：**宣传图展示的是"完成品幻想"，实机暴露的是"开发中 Demo"**——玩家前几分钟看到农田色块、几何车站、风格不统一的立绘，产生"这游戏是不是没做完"的判断，导致转化与留存失败。

本任务不修任何东西，只回答两个问题：

1. 第一次玩的玩家，会不会自然理解这款游戏、并愿意玩下去？
2. 玩家前 15 分钟看到的画面，是否配得上商店页宣传图？

---

## 二、执行方式

### 执行人要求

- 以"第一次玩的陌生玩家"身份完整跑通：**从打开游戏 → 到达归星岛 → 第一次种田 → 第一次修复 → 观星夜结束**
- 全程**不 debug、不看代码、不跳流程**；遇到困惑/出戏/卡住，如实记录
- 建议真机（安卓 APK）跑一遍 + 浏览器跑一遍，两遍结论合并
- 允许录像/截图，作为证据附在报告里

### 时长与工具

- 建议总耗时：1 次完整试玩（15~30 分钟）+ 1 次复查（针对疑问点）
- 工具：手机或浏览器 + 计时器 + 记录表（本任务卡第三节即记录模板）

## 三、分段检查清单（记录模板）

按时间分段逐项检查，每一项记录：**通过 ✅ / 不通过 ❌ / 存疑 ⚠️ + 一句话原因**

### 第一段：0~3 分钟 开场与第一印象

流程检查：
- [ ] 打开游戏后，玩家是否知道"我是谁、为什么回到这里"？
- [ ] 开场是否有吸引力（30 秒内有没有"继续玩下去"的理由）？
- [ ] 车站场景是否让人感到"这是一个真实的乡村车站"？
- [ ] 爷爷留下的东西是否有情感重量（而不是"一个任务道具"）？
- [ ] 玩家是否理解"这里需要被修复"？

美术出戏检查：
- [ ] 车站场景是否有明显占位视觉（纯几何图形、色块、未完成区域）？
- [ ] 标题画面/开场图与游戏内实际画风是否一致？
- [ ] 第一眼看到的场景，截图发到商店页是否说得过去？

### 第二段：3~8 分钟 第一次种田与核心循环

流程检查：
- [ ] 玩家是否理解"种田不是赚钱，而是让这个地方恢复"？
- [ ] 第一次播种/收获的反馈是否明确（画面变化、对白、提示）？
- [ ] 首次出售时，玩家看到的是"获得金币"还是"青禾镇修复基金 +X"？
- [ ] 村长/夏雅"为什么种田"对白是否在正确时机出现？
- [ ] 背包/商店/任务界面是否好用，有没有卡住或不知道下一步做什么？

美术出戏检查：
- [ ] 农田土地是否还是纯色矩形占位（#6b4423 色块）？
- [ ] 作物生长是否有明显阶段变化（发芽→生长→成熟一眼可辨）？
- [ ] NPC（村长、夏雅）立绘/精灵风格是否统一，会不会像"三个游戏拼起来"？
- [ ] 场景是否"空"——农田/小镇是否缺少土壤纹理、杂草、小石头、水渍、作物阴影等生活细节？

### 第三段：8~15 分钟 第一次修复与观星夜

流程检查：
- [ ] 老屋修复是否构成"高潮"体验？
- [ ] 修复完成后，玩家是否**立刻看到**变化（屋子外观/光照/音乐/NPC 反应）？
- [ ] 修复反馈是否只改了变量（`worldRestore.oldHouse=true`）而玩家无感？
- [ ] 三条支线（夏雅记忆卡/老张铜矿/小梅环境变化）是否形成"发现→互动→变化→记录"闭环？
- [ ] 观星夜是否值得期待，是否成为 Demo 的情绪收束点？
- [ ] 到达观星夜后，是否有一个明确的"结束点"（而不是流程戛然而止）？

美术出戏检查：
- [ ] 修复前后对比是否肉眼可见？
- [ ] 机器人/商店等系统是否还是几何占位（emoji 🤖、几何柜台）？
- [ ] 星之碎片/观星点是否还是紫色椭圆/双圈占位？
- [ ] 相簿记忆卡图片与游戏内画风是否协调？

## 四、商店页一致性检查（截图审查）

模拟陌生玩家浏览 TapTap 商店页，回答：

- [ ] 商店页首图/宣传图看起来完成度 80% 以上？
- [ ] 游戏实机截图（农田、车站、对话）看起来完成度多少？与宣传图差距是否超过 2 级（如宣传⭐⭐⭐⭐ vs 实机⭐⭐）？
- [ ] 如果只凭商店页，玩家能否看懂"这是一个什么游戏、好玩在哪"？
- [ ] 是否有至少 3 张合格的实机截图可以上架（尺寸/比例合规、实机面积 >50%）？
