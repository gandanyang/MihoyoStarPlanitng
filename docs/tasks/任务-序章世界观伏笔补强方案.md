## 2. P0 修订批（新增，待执行）：开场通知——从裁员到选择

> 背景（制作人与 GPT 讨论定调，2026-08-03）：游戏不是论文，不需要把现实矛盾推到最尖锐。AI **不是反派**，林澈**不是失败者**，而是"AI 改变了时代，人需要重新寻找自己的位置"。
> 目的：玩家读完开场不觉得"这游戏在批判 AI"，而是"他在选择另一种生活"。

### 2.1 文案改动（4 处，全部纯文本）

**① 开场通知改为「两页」**（`StationScene.ts`，制作人 2026-08-03 定稿）

第 1 页（裁员通知——先打"被裁"的冲击）：

```
人事通知

因业务流程智能化调整，您的岗位职责将进行重新分配。
感谢您过去五年的贡献，相关工作成果已被纳入智能系统训练库。

          （点击翻页）
```

第 2 页（职业转换支持计划——给选择）：

```
人事通知 · 职业转换支持计划

随着智能化系统升级，公司将对部分岗位进行调整。
根据员工意愿，您可以选择：

1. 转入 AI 协作相关岗位（智能生态部门），继续参与公司业务
2. 接受职业转换支持计划（含离职补偿），自行安排后续

请您于 7 个工作日内回复意向。

          （点击关闭）
```

**② 翻页后车站独白承接"选择"**（`StorySystem.ts` STATION_DIALOGUE，塑造角色不真分支）：

```
（手机屏幕还亮着。HR 的话停在最后一句：）
"林先生，根据评估，你完全可以加入智能生态部门。"

（留在城市？还是……去看看爷爷留下的地方？）

我不是讨厌AI，只是突然发现，我好像很久没有认真看过一次天空了。

……至少这次，是我自己选的离开。
```

- "当牛马发光发热"不直写，用 HR 公文腔自然带出（玩家自己品）
- 林澈收尾句与观星夜"城市里的天空，已经很久没有这么清晰了"形成序章→结尾闭环

**③ 原科技快讯 / AI 助手卡移出开场**（"减"）：

- 科技快讯（蓝鲸智能）→ 移到**农场第一天**手机新闻
- AI 助手对话（效率 vs 满意度）→ 移到**归星记录 / 农场清晨**（人机共生日常）

### 2.2 交互边界（硬约束）

- 通知改为**两页翻页**：点击第 1 页 → 翻到第 2 页；点击第 2 页 → 关闭
- 不渲染可点击选项、不真分支、不加选择 UI；不新增剧情节点 / 存档字段 / 任务链
- 不新增剧情节点 / 存档字段 / 任务链
