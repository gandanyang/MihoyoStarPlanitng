## 二、协作规则

### 1. 一个功能一个负责人

- 开工前在任务卡 / 群聊声明"这条我做"；
- 同一文件同时只允许一个 Agent 修改；如必须碰他人文件，先声明并错开时间。

### 2. 修改前声明

动代码前先输出：

```text
修改文件:
目标:
是否涉及存档:
```

涉及存档字段的改动必须说明"旧档是否兼容"。

### 3. 提交前检查

提交前必须列出：

```text
git status
git diff --stat
```

- 只允许提交自己改的文件（`git add <指定文件>`）；
- **禁止** `git add -A` / `git add .` / 目录级宽泛暂存；
- 发现暂存区混入他人文件 → **中止提交**，只清空不属于自己的暂存项，再提交。

### 4. 提交者唯一（2026-08-06 制作人拍板）

- **提交统一由 opencode 或制作人执行**；
- 其余 Agent（含 Codex）完成任务后**只报告「修改文件列表」**，禁止自行 `git add` / `git commit`；
- 文件列表格式：`修改文件: <路径1> / <路径2> / …` + 一句改动说明，供提交者核对。

## 三、工具层提醒（AGENTS.md 约束不到工具）

AGENTS.md 约束的是 AI 行为；如果 Trae / opencode 自身开启了 **Auto commit / Auto stage / 自动修复后提交**，它可能根本不读规则。

需要在各自工具设置里手动关闭：

- **Trae**：设置 → 搜索 "自动提交 / auto commit / auto stage" → 关闭；改回"Git 操作人工确认"。
- **opencode**：设置或配置中关闭自动 git 操作（如有）；确认没有 `git add -A && git commit` 之类的自动化钩子。

> 效果目标：AI 改代码、提方案、写文档都自动做；**git 提交必须人工确认**。
