## 1. 测试目标（三个问题）

1. **新玩家能不能从标题一路玩到 Demo 结局**（15-30 分钟完整闭环，不靠任何提示就自然走完）
2. **每段剧情后玩家是否知道"下一步去哪"**（迷惑点 = 本次测试最重要的收集对象）
3. **P1 观星引导是否生效**：交付任务后，玩家是否被引导发现夜晚的观星点（本次新增验证点）

## 2. 测试环境

- **电脑**：任意桌面浏览器（Chrome 优先），打开 `http://localhost:5173/?reset=1`（`?reset=1` = 全新档，防旧档干扰）
- **记录**：浏览器 / 系统 / 屏幕分辨率
- **时长**：一局约 15-30 分钟（含第一章 + 观星收尾）
- **建议**：测试者**全程不跳过对白、不使用快捷键查帮助**，模拟真实新玩家；另测一次"乱按探索"路径观察容错

## 3. 测试流程（按顺序，每场景记录：通过 / 问题 / 截图）

| # | 场景 | 操作 | 重点验证 |
|---|------|------|---------|
| D1 | 标题 | 加载 → 看副标题 → Enter 开始 | 副标题与"检测到存档"提示不重叠（有档时）；Enter 提示可见 |
| D2 | 车站序章 | 看列车动画 → 手机通知两页 → 车站对白 9 行 → 移动 | **开场等待段流失观察**：从进游戏到能移动约 35-40s 纯阅读，玩家是否不耐烦/想点跳过；移动提示出现时机 |
| D3 | 大门教程 | 与夏雅对话 → 背包用钥匙开门 | 目标是否明确（"打开大门"）；钥匙获得反馈 |

| D5 | 第一章·接任务 | 首次进小镇 → 开场 5 行 → 找镇长对话 | 小镇开场是否把玩家引向镇长；任务目标是否清晰 |

## 4. 重点观察项（迷惑点清单：玩家此刻该知道什么）

| 时刻 | 玩家应该知道 | 观察点 |
|------|------------|--------|
| 车站对白结束 | 用 WASD 走向庄园 | 第 9 行提示是否被看到；前 8 行纯剧情是否让玩家失去耐心 |
| 大门前 | 打开背包 → 用钥匙 | 是否卡在"怎么用钥匙" |
| 锄地结束 | 切种子播种 | 播种提示是否够醒目 |
| 播种结束 | 浇水 | 浇水提示是否够醒目 |
| 晚间 | 回屋睡觉 | 是否能找到床 |
| 小镇开场 | 靠近镇长对话 | 是否知道镇长在哪、要对话 |
| 接任务后 | 去森林 | HUD 目标「去爷爷以前常去的森林看看」是否被注意到 |
| 森林采集后 | 回小镇交付 | 浮动提示「返回村长交付任务」+ HUD 是否被注意到 |
| 交付后 | 晚上回庄园观星（P1） | 「夜晚的庄园，似乎有什么在等着你。」是否形成引导；玩家会不会当晚回去 |
| 观星选项 | 选一个留下 | 三个选项是否都读懂 |

**额外观察**（QA 基线待拍板项，借玩家测试取证）：
- D2 开场等待段：玩家是否流失/皱眉/点跳过（对应 P1「开场等待段偏长」）
- 交付后：若玩家没被观星引导到，记录"玩家下一步做了什么"（验证 P1 修复是否足够）

## 7. 避坑清单（测试前必读）

1. **`?reset=1` 保证新档**；中途不要刷新（会存档恢复，跳过教程状态）
2. **玩家操作期间不提示**：测试者记录"玩家卡在哪、想了多久、按了什么"，不要主动告诉答案
3. **第一次玩的人**：找没玩过本项目的人测（同事/朋友皆可）；让玩家边玩边"出声思考"（说出现在在想什么），这是迷惑点的最佳证据
4. **别把"不习惯"当 bug**：主观偏好记 P2；不知道去哪/做不了下一步才算 P0/P1
5. **每步截图**：迷惑时刻和解决时刻各截一张，比文字有用
6. **卡住时**：记"卡在哪一步、提示是什么、我按了什么"，不用勉强走完——这就是最有价值的 bug 信息
