## 2. 关键体验点

### ⭐ 正面体验（亮点）

1. **E1 清晨偶遇**（★★★★★）
   - 时间触发机制自然，06:00-08:00 进入农场看到夏雅
   - "太阳一出来，就想醒着"——生活化台词让林澈从"数据劳动者"转变开始

2. **E2 首次收获反馈**（★★★★★）
   - 夏雅"比屏幕里的，要实在一点吧"——精准点题
   - 林澈"确实"——简短但有力

3. **E9 傍晚关心**（★★★★☆）
   - 傍晚金色光线+夏雅看海的视觉氛围
   - "你做的事情，土地都会记得"——主题升华

4. **E5 爷爷笔记**（★★★★☆）
   - 碎片化叙事，不解释，让玩家自己拼凑
   - "星星……是不是也想回家？"——悬念设置

5. **NPC每日随机句**（★★★★☆）
   - 5个NPC各有6句生活化台词
   - 每天搭话有新鲜感，NPC从"功能点"变成"有过去的人"

### ⚠️ 负面体验（问题）

1. **P1-01 标题版本号过时**
   - 位置：`TitleScene.ts:62` 写死 `'v0.3'`
   - 影响：玩家看到过时版本号，怀疑游戏是否更新
   - 修复：改为动态读取或更新为 `v0.5.3`

2. **P1-02 车站移动提示未适配移动端**
   - 位置：`StorySystem.ts` 车站对话
   - 影响：移动端玩家看到"按WASD"，不知如何操作
   - 修复：使用 `hint()` 函数区分 PC/移动端提示

3. **P1-03 NPC首次对话偏长**
   - 位置：矿工老张首次对话12句
   - 影响：新玩家首次接触NPC时对话过长，可能跳过
   - 修复：拆分为2段，中间插入玩家操作

4. **P1-04 播种引导误提示"按R键"**
   - 位置：`StorySystem.ts` SOW_SEEDS_DIALOGUE
   - 影响：移动端玩家困惑
   - 修复：使用 `hint()` 函数区分

5. **P1-05 每日任务面板与HUD可能重叠**
   - 位置：任务面板左上角，HUD右上角
   - 影响：小屏设备上可能重叠
   - 修复：调整面板位置或添加防重叠检测

6. **P1-06 观星夜选项差异化不足**
   - 位置：DEMO_ENDING_BRANCHES
   - 影响：玩家感觉选项无意义
   - 修复：增加选项后果差异

## 4. P2 优化建议

1. **P2-01 教程晚间文案时间脱戏**
   - 问题：晚间对话提到"明天"，但玩家可能当天就完成教程
   - 建议：改为模糊时间词（"以后"、"接下来"）

2. **P2-02 Day 2 作物成熟无提示**
   - 问题：玩家睡觉后作物成熟，但无视觉/文字提示
   - 建议：起床时添加"你的作物已经成熟了"提示

3. **P2-03 矿洞引导无"再按E"提示**
   - 问题：矿洞引导对话后，玩家不知如何继续
   - 建议：对话结束后显示"靠近矿脉，按E挖掘"

4. **P2-04 观星点仅限农场**
   - 问题：观星夜仅在农场触发，玩家可能错过
   - 建议：扩展到其他场景（如山顶、海边）

5. **P2-05 打字速度偏慢**
   - 问题：对话打字效果偏慢，急性子玩家可能跳过
   - 建议：添加"点击跳过"功能或加快打字速度
