# BUG-026 种植体验专项排查报告

> 制作人 2026-08-02 定稿：**先反馈，再精度**（"操作有回应" > 判定精确 3 像素）
> 本报告只排查不改码。实现阶段依据本报告的分级建议推进。

## 一、问题背景

安卓真机体验反馈：**操作 1/5**（与音效并列最低）。种植是玩家最高频操作面，操作不好则地图/美术/剧情收益全打折。

制作人拍板原则：
1. **先反馈**：每次操作必须有即时、明确、愉悦的回应（音效 + 视觉 + 手感）
2. **再精度**：触控判定放宽（手指落点容差 + 就近吸附），避免"点偏一格"失败感

## 二、种植交互现状梳理（数据流）

### 交互入口（两条路径）
| 路径 | 触发 | 判定目标 | 适用设备 |
|------|------|---------|---------|
| A. 点击农田格 | `MapScene` `this.input.on('pointerdown')` → `handleFarmTap` (MapScene.ts:483, 2098) | 点击落点的格子（`getWorldPoint` 换算） | 触屏 |
| B. 交互按钮/键盘 | 右下角「使用工具」按钮 / E 键 → `queueAction` → `tryInteract` → `tryFarmInteract` (MapScene.ts:2070) | 玩家**面前一格**（facing 偏移） | 触屏+桌面 |

### 操作判定（tryFarmInteractAt，MapScene.ts:2127）
| 当前格子状态 | 操作 | 触发函数 |
|------------|------|---------|
| empty | 锄地 | setTileState('tilled') + play('hoe') |
| tilled | 播种（种子不足弹选择器） | doPlant + play('plant') |
| planted | 浇水 | setTileState('watered') + play('water') |
| grown | 收获 | addItem + play('harvest') + 首次收获剧情 |
| watered | **无操作**（次日才成熟） | 静默 return |

### 现状反馈清单
| 反馈类型 | 现状 | 位置 |
|---------|------|------|
| 点击落点高亮 | `tapFlashKey/Until` 目标格高亮 500ms + `navigator.vibrate(15)` | MapScene.ts:2116-2120 |
| 面向格高亮 | `targetHighlight` 跟随玩家面向格，可操作时呼吸脉动 | MapScene.ts:1888 |
| 音效 | `AudioSystem.play` WebAudio 合成（hoe/plant/water/harvest 已有） | AudioSystem.ts:77 |
| 文字反馈 | 收获/锄地/浇水**均无飘字**；仅 HUD 金币/种子数变化 | — |
| 体力 | 种植**不耗体力**（仅挖矿耗），无体力反馈需求 | — |

## 三、排查发现（按"先反馈，再精度"分级）

### 🔴 P0-A 反馈缺失：无响应的操作 = 玩家以为坏了

**A1. 点击无效格无任何反馈**
- 场景：点 `watered`（已浇水未成熟）格、或 tilled 但无种子、或点击农田范围外
- 现状：`handleFarmTap` 走 `isTileActionable` → false → 静默 return（MapScene.ts:2113）；`tryFarmInteractAt` watered 分支直接 return（MapScene.ts:2188-2190）
- 问题：手机玩家点下去"没动静"，分不清是"点偏了"还是"操作无效"，挫败感强
- 建议：所有不可操作格点击 → 给轻量"无效"反馈（短促低音 + 格子淡红闪烁），区别于成功反馈

**A2. 成功操作后无"获得感"文字反馈**
- 场景：收获到萝卜/锄地/浇水成功
- 现状：仅 tile 视觉变化（泥土变色/作物图像）+ HUD 顶部数字变化
- 问题：收获成功无飘字（"+1 🥕"），奖励感弱；真机视线在格子处，HUD 在顶部，反馈脱节
- 建议：格子处飘字反馈（收获作物名、播种成功、浇水水滴动画）

**A3. 音效存在但可能不愉悦/不明显**
- 现状：`AudioSystem.ts` 已有 hoe/plant/water/harvest 合成音效，音量 0.04~0.2
- 问题：无音量控制/静音开关；合成音较机械；真机外放可能偏轻
- 建议：加大音量分层（成功 > 无效），锄地/收获可加更"手感"的合成（参考 §7 音效升级方向）

**A4. 播种流程割裂：种子选择器打断节奏**
- 场景：tilled 格子点击 → 若默认选中种子（radish）库存为 0 → 弹 `showSeedSelector` 全屏选择器（MapScene.ts:2216）
- 问题：玩家"点一下格子"突然被全屏选择器打断，交互心智模型断裂；触屏无 R 键快捷切换种子（seedSwitchBtn 需额外点击）
- 建议：种子不足时给即时反馈（飘字"萝卜种子不足"）而非弹全屏选择器；触屏常用种子自动续种

### 🟡 P1-B 精度/容差问题

**B1. 点击判定过严：落点不在格中心即算错格**
- 现状：`Math.floor(world.x / TILE_SIZE)` 精确取格（MapScene.ts:2110-2111），TILE_SIZE=16px，相机 zoom=2 → 屏幕每格 32px
- 问题：手指落点容差极窄，点偏一点就作用到邻格（尤其收获/浇水），"明明点了收获却没反应"高发
- 建议：点击判定加"就近吸附"（最近可操作格半径放宽），或落点容差 ≥ 半格

**B2. 触摸与交互按钮双通道不一致**
- 点击路径（A）：点哪个格操作哪个格
- 按钮路径（B）：只操作"面前一格"，需先走位
- 问题：手机上玩家可能点击远方格→操作该格（A），也可能误以为按钮作用于点击格（B），两套心智冲突
- 建议：触屏设备弱化"面前一格"逻辑，交互按钮与点击种田统一；或按钮改为"使用工具：作用于点击的格子"

### 🟢 P2-C 体验增强建议

- 种植成功后格子动画（土块溅起/水花/作物弹跳）
- 触屏连锄/连种流畅度（快速连点时不被防抖/选择器打断）
- 收获音效区分不同作物
- 播种/浇水后 HUD 种子数即时变化已具备（updateHUD），但可加高亮

## 四、修复建议（分级落地，先反馈再精度）

### 第一批（反馈放大，小改动高风险低）
1. **无效格点击反馈**：不可操作格点击 → 淡红闪烁 + 低音（区分成功）
2. **成功飘字**：格子处 +1 作物/播种/浇水/锄地文字反馈
3. **音效增强**：音量分层、收获/锄地合成优化
4. **种子不足即时提示**：tilled 无种子 → 飘字提示，不弹全屏选择器（保留手动选择器入口）

### 第二批（精度放宽）
1. 点击落点容差 + 最近可操作格吸附
2. 触屏交互按钮与点击种田统一语义
