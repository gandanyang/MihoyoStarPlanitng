# v0.6 玩家认知障碍审查清单（trae 预扫描）

> 制作人 2026-08-03 定稿方向：**不是缺功能，而是功能存在但玩家无法确认**。
> UX 原则：**玩家不是在检查数据，他们是在判断"我的行为有没有成功"**。
> 本清单为 trae 线预扫描结果，供 opencode/UI 线输出正式《v0.6 玩家认知障碍审查报告》使用。本阶段只扫描、不改码。

## 一、审查方法

- 范围：商店 / 农业 / 任务 / NPC / 存档 / 移动端 UI 的"反馈可见性"
- 判定标准：**功能存在，但玩家没有途径确认它存在 / 存在但已发生 / 自己操作成功**
- 证据：代码位置 + 玩家视角 + 制作人已反馈条目

## 二、认知障碍点清单（按影响分级）

### 🔴 P1-1 网页端任务/背包入口完全不可见（制作人已反馈）

| 项 | 内容 |
|----|------|
| 问题描述 | 桌面端（非触屏）无任务图标、无背包按钮；J/B 键逻辑存在但无任何提示文案 |
| 证据 | `TouchControls.ts:242-248` questBtn/backpackBtn 仅 `isTouchDevice()` 显示；`MapScene.ts:678-683` J 键打开任务面板无提示 |
| 玩家视角 | 新玩家不知道有任务列表 / 背包快捷键，引导任务"去哪看"不可达 |
| 建议修复 | ① 桌面端 HUD 增加任务/背包小图标（点击等价 J/B）；② 或开场一次性提示「按 J 查看任务 / 按 B 打开背包」 |
| 归属 | opencode（UI 线，TouchControls 领地） |
| 状态 | ✅ 已修复（方案②落地）：`setupShortcutHint()` [MapScene.ts:1316](src/scenes/MapScene.ts#L1316) 非触屏首次进入显示「按 J 打开任务 · 按 B 打开背包」，使用一次后本局关闭（L715/723）。PC 无任务图标但 J/B 提示兜底，满足"或"方案。验证：tsc + 网页探针全绿（2026-08-03 trae 确认） |

### 🟠 P1-2 开场手机通知标题「系统通知」出戏（制作人已反馈）

| 项 | 内容 |
|----|------|

| 归属 | opencode / trae 均可 |

### 🟠 P2-1 未浇水作物无主动提醒，且点格子文案有歧义

| 项 | 内容 |
|----|------|
| 问题描述 | 播种后忘浇水，跨天后作物不长；玩家点格子只看到「还没成熟」，分不清是"时间未到"还是"缺浇水" |
| 证据 | `MapScene.ts:2838` `showFloatText('还没成熟')`；`:2740` `state==='watered'?'还没成熟':'没有种子'` |
| 玩家视角 | "我明明播种了为什么不长？是不是 bug？"——教程教过浇水但玩家会遗忘，且无任何主动提醒 |
| 建议修复 | ① 点未浇水格文案区分：「作物需要浇水」；② 睡觉/跨天时若有 planted 未 watered 作物 → 提醒「有 N 块作物需要浇水」（可复用成熟提醒模式 MapScene.ts:1868） |
| 归属 | opencode（种植体验线） |
| 状态 | 扫描确认，待修 |

### 🟡 P2-2 NPC 生活化"无人告知"——世界有生活，但玩家不知道去哪看

| 项 | 内容 |
|----|------|
| 问题描述 | NPC 时段行为（夏雅上午花园浇水 / 老张整理 / 村长巡查）已上线，但无任何入口告知玩家"NPC 有自己的时间节奏" |
| 证据 | NPC 生活化 P0 已验收（DEV_CONTEXT）；`NPCSystem.ts` hint() 已有差异化文本，未覆盖日程可见性 |

| 建议修复 | 强化 NPC 对话 hint 提及日程（如夏雅"我每天上午都来照看花园"）；不新增系统 |
| 归属 | opencode（NPC 生活化线） |
| 状态 | 待评估（低成本，可并入 P1 批次） |

### 🟡 P2-3 自动化设备"未来为什么解锁"不可见（前瞻提示）
