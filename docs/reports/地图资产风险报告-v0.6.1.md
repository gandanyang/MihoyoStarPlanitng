## 三、风险项清单

### 🔴 高风险（无）

### 🟡 信息项（架构性，不影响运行）

1. **tileset image 引用指向 `placeholder_tileset.png`（5/6 张图）**
   - 现象：farm/town/gate/forest/mine 的 JSON `image` 均为 `../tiles/placeholder_tileset.png`
   - 原因：**设计架构**——运行时 `load.image('tiles', {key}_tileset.png)` + `addTilesetImage('placeholder','tiles')` 用各图专属 png 替换占位引用；`placeholder_tileset.png`(14 格) 仅作 fallback
   - house.json 例外：直接引用 `house_tileset.png`（12 格，元数据一致）
   - **建议**：在 [地图资产管线规范-v0.6.md](../reports/地图资产管线规范-v0.6.md) 中补充说明此约定，避免后续检查误判

2. **JSON 元数据 `columns=14/tilecount=14` 与各图实际 png 格数不符**
   - 现象：farm/town/gate/mine=8 格、forest=12 格，但 JSON 元数据均为 14
   - 影响：运行时以 `addTilesetImage` 后的 png 实际尺寸计算格数，**无黑瓦片**；但直接读 JSON 元数据做校验会误判
   - **建议**：管线规范注明"tileset 格数以 png 实际尺寸为准，JSON 元数据仅占位"

3. **gate 的 gid 3 色调 (96,96,96) 与其他地图 (112,112,120) 不一致**
   - 影响：仅视觉色调差异，碰撞行为一致（同为 gid 3）
   - **建议**：后续美术统一时对齐 gate_tileset 的 gid 3 像素

### 🟢 良好项

- ✅ 无黑瓦片（6 图全部 gid ≤ png 格数）
- ✅ 无阻塞出口（14/14 出口开口正常）
- ✅ gid 语义全局一致（除 gate gid 3 色调微差）
- ✅ 无 object layer 依赖（出口/出生点由 exits.ts 代码定义，架构干净）
- ✅ M1-1 新增 farm 水塘（gid 4）落入既有碰撞规则，无需额外处理
