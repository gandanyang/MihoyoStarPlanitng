## 一、显示策略说明

### 基准分辨率

- **逻辑高度恒 600**，逻辑宽度随屏幕宽高比动态扩展（`applyAdaptiveLogicalSize`）
- 4:3 及更窄屏回落到 800×600；超宽屏（16:9 / 19.5:9 / 20:9）按比例扩展逻辑宽度
- 地图坐标/碰撞/NPC 位置均基于世界坐标，本次未改动

### 缩放模式（核心：动态逻辑宽度 + FIT）

- **`Phaser.Scale.FIT` + `CENTER_BOTH`**，配合 `game.scale.setGameSize(logicalW, 600)`
- 逻辑高度恒 600、宽度 = 600 × (视口宽/视口高)（最小 800）→ 画布比例 = 屏幕比例 → FIT 等比缩放后**正好铺满整个视口**（无黑边、不裁剪）
- **相机 zoom=2 保持整数倍** → 像素清晰、垂直视野恒定 300 世界像素（玩家/地图永不超出镜头）
- 超宽屏（20:9）水平方向显示更多地图内容（不压缩游戏内容、不拉宽地图）
- 此方案解决了 ENVELOP 全屏填满导致上下内容被裁、玩家走出屏幕的问题（ENVELOP 会裁剪，动态逻辑宽度 + FIT 不裁剪）

### 像素渲染

- `Game Config` 新增 **`pixelArt: true`** + **`roundPixels: true`**（src/main.ts）
  - pixelArt 禁用纹理抗锯齿 → 像素素材不发虚
  - roundPixels 相机/精灵渲染取整 → 地图边缘不抖动
- AI 高清封面（`title_bg` / `logo_mark`）在 TitleScene 中**单独恢复 LINEAR 过滤**，避免全局 pixelArt 导致高清图锯齿

### 安全区域（Safe Area）

新增/补全 `env(safe-area-inset-*)` 适配：

| 位置 | 改动 |
|---|---|
| 虚拟摇杆（左下） | bottom 增加 `env(safe-area-inset-bottom)`（TouchControls） |
| 主交互按钮（右下） | bottom 增加 `env(safe-area-inset-bottom)`（TouchControls） |
| 背包按钮 | bottom 增加 `env(safe-area-inset-bottom)`（TouchControls） |
| 等待按钮 | bottom 增加 `env(safe-area-inset-bottom)`（TouchControls） |
| 对话 Skip/剧情回顾按钮（右上） | top 增加 `env(safe-area-inset-top)`（StoryDialogue） |

既有适配保留：任务按钮顶部 safe-area（TouchControls）、右上角按钮 safe-area（MapScene BUG-031 修复）、`viewport-fit=cover`（index.html）、全屏面板（背包/相簿/商店等）居中布局天然不贴边。

### Camera 适配

- 地图 Camera：`setBounds` + `startFollow` + `setZoom(2)` 负责世界坐标（既有，未改）
- UI：DOM HUD 固定屏幕坐标 + `scrollFactor=0`（既有）；`syncGameContainer()` 改为容器 = 视口尺寸（全屏铺满后 DOM UI 与画布天然对齐；不可设为 displaySize，否则 FIT 缩放基准随容器循环缩小）
- 验证：全视口下画布铺满、`game-container` 与画布对齐，UI 不跟随地图移动
