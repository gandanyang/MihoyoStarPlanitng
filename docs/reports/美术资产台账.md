### 贯穿暗线修复（2026-08-07 21:50，制作人反馈"后山有黑线"）

**根因**：GPT 网格图经 normalizer 后，部分**底色/地面类 tile 内部残留一条贯穿暗线**（GPT 网格线残留），单一 tile 平铺时每 16px 重复出现 → 规则黑线网格。用户先后反馈"矿洞黑线""后山黑线"。

**修复工具**：`tools/fix_tile_piercing_lines.py`（检测贯穿暗线 >70% 像素暗于内部中位-25 → 暗像素用相邻像素平均填充；边缘列/行 0/15 不动保无缝；装饰类 tile 不处理）

**已修复**（public 直接覆盖，备份在 `tmp/backup_blackline/`）：

| tileset | 修复项 | 验证 |
|---|---|---|
| forest | grass x=7、dirt x=8 | 贯穿线 100%→12%，实机网格检测 0 规律暗线 |
| farm | stone y=5、wood y=3/14、path x=12+y=1/14 | tile 级 ✅ |
| town | dirt x=8+y=8、stone x=6、wood y=9 | tile 级 ✅ |
| mine | dirt x=10 | tile 级 ✅ |

> ⚠️ 教训：normalizer 的网格清洗只清全局 32px 网格线，**未检测 tile 内部贯穿线**。v1.2 候选：normalizer 内置"贯穿暗线检测清除"步骤，避免每次手动 --fix。
