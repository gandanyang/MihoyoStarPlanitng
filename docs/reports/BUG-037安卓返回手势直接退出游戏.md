# BUG-037 安卓返回手势（左滑）直接退出游戏，无确认

> 状态：✅ **代码已修复 + 新包已安装；真机手动复测 ⏳ 冻结中**
> 登记：2026-08-03 ｜ 来源：制作人试玩反馈（第 4 轮）
> 级别：P0（操作体验）——制作人明确"对玩家体验很糟糕，高优先级处理"

---

## 一、问题描述

安卓端玩家**左滑（返回手势）直接退出游戏**，无任何确认提示。

制作人原话：

> "玩家在往左滑的时候，我们得有一个让他回到主菜单，或者是至少弹出来个提示框，提醒玩家是不是要关掉程序……而不是现在一左滑游戏直接关掉了。"

**影响**：误滑即丢游戏进程，与 BUG-036（左滑黑屏）不同但同源——都是返回键处理链路的体验缺陷。

---

## 二、根因

[AndroidBackHandler.ts](file:///c:/Users/Gdy/Documents/trae_projects/mihoyoStarPlanting/src/systems/AndroidBackHandler.ts) 中两处直接 `App.exitApp()`：

1. **MapScene 且无回退目标**（`farm` / `gate` 不在 `BACK_TARGET` 表）→ 直接退 App；
2. **非 MapScene**（Title / Station）→ 直接退 App。

注册 `backButton` 监听后 Capacitor 抑制默认退出行为，必须显式 `exitApp()` 才退——本应做层级控制，但"层级关完"后的兜底直接退 App，没有给玩家任何确认机会。

---

## 三、修复方案

`showExitConfirm(game, scene)` DOM 弹窗（样式与 TitleScene 清除存档按钮一致：pointerup 主处理 + click 兜底去重）：

| 按钮 | 行为 |
|------|------|
| **继续游戏** | 关闭弹窗，留在当前画面 |
| **回到主菜单** | `game.scene.start('title')`（**仅地图场景显示**） |
| **退出游戏** | 才真正 `App.exitApp()` |

附加细节：

- 弹窗打开时再按返回键 = 关闭弹窗（最高优先级，等价"继续游戏"），不会误退；
- 点击弹窗外遮罩空白处 = 继续游戏；
- "回到主菜单"安全性已核实：`MapScene.cleanupSceneDom`（SHUTDOWN 事件）自动清理全部 DOM UI + NPC/机器人精灵；`StationScene.create` 对已有存档自动恢复场景，回标题再进游戏安全。
