## 三、误判修正说明（重要：测试体系可信度的第一课）

探针健康报告原判定 2 条 P0"崩溃/必然失败"，**经实测均被推翻**：

1. **"probe-npc-life-acceptance#L97 会崩溃"** ❌ → 实测修复前 8/8 全绿。
   根因：报告假定 Phaser 3.80 TilemapLayer.data 是一维扁平数组，但源码 [GetTileAt.js#L26](file:///c:/Users/Gdy/Documents/trae_projects/mihoyoStarPlanting/node_modules/phaser/src/tilemaps/components/GetTileAt.js#L26) 明确 `layer.data[tileY][tileX]` 是二维数组。
2. **"test-ch1-story#L295 三选项断言必然失败"** ❌ → 实测修复前 24/24 全绿。
   根因：报告按"每行严格 2 次 advance"推算，但 [StoryDialogue.ts#L219-235](file:///c:/Users/Gdy/Documents/trae_projects/mihoyoStarPlanting/src/ui/StoryDialogue.ts#L219-L235) 短行打字自动完成后 advance 直接翻行，实际推进更快；且选项行拦截多余 advance，多按无害。

**教训**：纸面推断 ≠ 实测。探针是否可信，只能靠真实跑一遍判定——这正是本轮修复的动机。

## 四、本次核对基准（修复引用）

- skipDialogue 语义：每行最多 2 次（打字机+翻行）；短行打字自动完成后 advance 直接翻行，实际可更快；`skipDialogue(N)`=N*2+1 次；选项行 advance 被拦截
- 行数基准：XIYA=13、GATE_OPENED=7、SOW=7、WATER_CROPS=6、EVENING=7、TOWN_INTRO=5、ELDER_QUEST=11、DEMO_ENDING=15（含选项行 index=14）、BRANCHES 各 4、FINALE=5
- NPC 对白：**MINER=16、GARDENER=12**、ADVENTURER=8、SHOPKEEPER=4、MYSTERY=7、MYSTERY_AFTER=3
- talk 任务：title='拜访村长' / desc='与村长对话'；QuestPanel 渲染 desc
- Phaser ^3.80：`layer.data[tileY][tileX]` **二维数组**；公开取瓦片 API `getTileAt(x, y)`
