## 1. 审查范围

任务系统（主线 / 每日任务 / 引导任务）与以下系统的耦合边界：

- 教程进度（StorySystem.storyStep）
- 物品前置（Inventory：old_axe 等）
- 地图/场景可达性（exits / NPC 日程可达窗口）
- 时间系统（TimeSystem：时段 / 跨天刷新）
- 自动化（AutomationSystem：机器人是否触碰任务边界）

## 3. 各任务类型边界明细

### 3.1 引导任务（教程完成后投放）

| 任务 | 前置 | 当前状态 |
|------|------|---------|
| `mine_1` 初入矿洞 | 教程完成（`storyStep=done`） | ✅ 矿洞从小镇/森林始终可进入，无独立解锁；教程后玩家已具挖矿能力 |
| `woodcut_2` 伐木初体验 | 教程完成 + 斧头 | ✅ 教程完成即赠 `old_axe`（`MapScene:1413`）；`MapScene:472` 还有旧存档兜底补斧头 |

**结论**：引导任务边界当前正确。旧档兼容有兜底（`injectGuideQuests` 跨天保留补发，`MapScene:1889`）。

### 3.2 对话任务（`talk_*`）— ⚠️ B-1 风险

NPC 日程存在 `home` 时段（06:00-08:00 及 18:00 后），此时 NPC **不渲染**：

| NPC | 可被找到时段 |
|-----|------------|
| 村长 elder | 08:00-18:00 town |
| 商店老板 shopkeeper | 08:00-18:00 town |
| 矿工老张 miner | 08:00-18:00 mine |
| 花匠小梅 gardener | 07:00-14:00 farm → 14:00-18:00 forest |
| 冒险家阿风 adventurer | 08:00-14:00 forest → 14:00-18:00 town |

每日任务 `pickRandom` **无时段过滤**（`DailyQuestSystem:101-110`）。若晚间（18:00 后）玩家打开任务面板，可能看到 `talk_*` 任务但对应 NPC 已回家 → "接了任务发现做不了"。

**影响**：不阻断（次日 NPC 回来可完成，任务未完成会保留跨天——但注意 `keepGuide` 只保留引导+已完成任务，**普通 talk 任务隔天会被刷新替换**，玩家损失机会）。真实风险中等。

**建议方案（待制作人确认再实施）**：
- 方案 A（轻）：任务面板 `daily` 标签在 18:00 后对 `talk_*` 任务显示"NPC 已回家，明早可找"灰字备注。
- 方案 B（中）：`pickRandom` 按当前时段过滤不可达的 talk 任务。
- 方案 C（重）：保持现状，接受"晚上不做对话任务"作为设计意图（村庄夜晚安静，与 NPC 生活化主题一致）。

### 3.3 收获类任务（`harvest_*`）— B-2 观察

`harvest_corn_2` / `harvest_tomato_2` / `harvest_strawberry_2` 需玩家先买种子→种→等成熟。新玩家若抽到且无金币买种子，会暂时卡住。但：
- 种子商店全部可买（萝卜 10 / 玉米 15 / 番茄 20 / 草莓 50 金币）
- 每日任务非主线，不阻断流程
- 玩家可选择不做，等次日刷新

**结论**：P2，暂缓，观察阶段记录。若未来反馈"新玩家抽到高价作物任务困扰"，再考虑"任务池按已解锁作物过滤"。

### 3.4 采集/商店类任务

| 任务 | 边界 |
|------|------|
| `collect_star` 星之碎片 | ✅ 主线碎片的每日版本，主线进行中可达 |
| `buy_shop` / `sell_shop` | ✅ 商店全天可用（shopkeeper 08:00-18:00 在 town，商店实体摊位在 farm 旁），无前置 |

### 3.5 主线任务（QuestSystem）

主线由剧情驱动，各节点有明确前置（钥匙→清理→睡觉），边界经既有探针验证（ch1-story / tutorial 全绿）。本次未发现新风险。

## 4. 跨系统耦合红线（防再犯）

1. **新增每日任务时**必须声明前置（解锁条件 / 前置物品 / 可达时段），未声明的任务不进任务池。
2. **NPC 日程变化**必须同步检查 `talk_*` 任务可达性（本次 B-1 即由此类变更引入）。
3. **自动化系统**（机器人）永久不得触发 `onDQ*` / `addXp` ——已由顶层设计 §6.4 原则固化，代码层已遵守。
