- 完整 Demo 主流程（开场 → 种田 → 修复 → 观星夜 → 结局）**可完整跑通**，全程 **0 运行时错误**，主线任务链（接受→采集→交付）状态流转正确。

## 二、执行说明与取证方法

本模型无法直接阅读图片，故采用程序化取证（可量化、可复现）：

1. **完整流程走查**：Puppeteer 控制真实 Chrome 实例，从新档开始依次经历：标题 → 车站开场（列车动画/音量提示/手机通知/序章对白）→ 庄园大门（夏雅对白/钥匙/开门）→ 农场（锄地/播种/浇水/晚间对白/睡觉）→ 小镇（进镇/村长接任务）→ 森林（碎片采集+闪回）→ 小镇（交付）→ 农场（观星夜/结局/分支）。
2. **像素采样**：对关键场景整页截图 → 离屏 canvas 网格采样，统计唯一色数/主色（检测纯色占位）。
3. **DOM 文本/元素枚举**：对白逐行读取（speaker+text）、场景对象统计（texts/sprites/graphics）、**emoji 检测（含可见性/坐标）**。
4. **证据**：32 张截图存于 `tests/probes/test-screenshots/first-playtest/`，数据 `audit-log.json`。

> 走查使用脚本驱动（等价于玩家按键操作），仅推进剧情阶段（storyStep/时间/道具）以模拟"玩家已到达该阶段"；对白均为真实触发内容，非伪造。
