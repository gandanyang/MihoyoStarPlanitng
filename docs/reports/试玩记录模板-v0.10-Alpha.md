# 《归星物语 v0.10 Alpha 制作人试玩记录模板》

> 用途：**真机 30 分钟完整体验**的记录工具（先出模板，试玩时逐段填写）。
> 原则：观察玩家**实际行为**，不替玩家解释；记录事实，不记评价。
> 场景：PC 桌面 + Android 真机各一次；试玩者可为制作人或邀请 1 名新玩家（推荐两者各一次）。
> 前置：APK 打包完成、音频合入验证通过后再测。

## 0-5 分钟：序章 + 返程动机

**测试目标**：

- 玩家知道自己为什么回来吗？（AI 辞退 → 归乡）
- 首次操作是否顺畅（触屏：摇杆 / 交互按钮）

**观察点**：

| 观察点 | 记录 |
|--------|------|
| 是否跳过对白（跳过几段？位置？） | |
| 序章独白是否有共鸣反应（停顿 / 笑 / 摇头） | |
| 首次有效操作耗时（打开游戏 → 第一次移动） | |
| 触屏摇杆灵敏度 / 交互按钮大小 | |
| 玩家能否复述「林澈为什么回来」 | |

---

## 5-15 分钟：第一次种田 + 上手

**测试目标**：

- 种田循环（锄地 → 播种 → 浇水）是否无需提示
- 是否有第一次「爽点」/「挫败点」

**观察点**：

| 观察点 | 记录 |
|--------|------|
| 第一次锄地 / 播种 / 浇水各自需要提示吗 | |
| 停顿时长（在哪停顿超过 5 秒） | |
| 夏雅作为引导者：讨喜 / 啰嗦？ | |
| 第一次收获反应（惊喜 / 无感） | |
| 新手教程是否打断体验 | |
| 触屏操作：交互按钮位置是否顺手 | |

---

## 15-25 分钟：小镇 + 主线 + 复兴项目

**测试目标**：

- 主线（星之碎片）是否清楚
- **复兴项目（FEATURE-037）是否被玩家自然发现**（本次新特性）
- 智能出售 / 一键出售是否有保护意识

**观察点**：

| 观察点 | 记录 |
|--------|------|
| 是否主动前往小镇 / 森林（非被引导） | |
| 主线目标是否清晰（HUD 任务引导） | |
| 复兴项目（老屋 / 花园 / 后山道路）是否被发现 | |
| 玩家是否理解「资源不只是卖钱」（建设价值） | |
| 一键出售后是否后悔（卖错材料） | |
| 背包整理是否顺畅 | |

---

## 25-30 分钟：观星夜收尾

**测试目标**：

- 情绪最高点是否出现（观星夜 / 静默镜头）
- 完整感 / 意犹未尽

**观察点**：

| 观察点 | 记录 |
|--------|------|
| 是否完整看完观星演出（跳过？在哪跳） | |
| 三选项选择耗时与所选 | |
| 结算面板是否停留阅读 | |
| 观星后是否想继续玩（还是关机） | |

## 判定参考

| 维度 | 达标迹象 | 风险迹象 |
|------|---------|---------|
| 动机理解 | 能说出「被辞退 / 回来看看」 | 跳过序章且说「不知道」 |
| 复兴循环 | 主动留下资源不卖 / 问「怎么修」 | 全程只卖钱、无建设概念 |
| 夏雅亲和力 | 主动找夏雅 / 提到她 | 觉得啰嗦、跳过其台词 |
| 观星情绪 | 愿意完整看完、有停顿 | 快速跳过、无反应 |
| 稳定性 | 无崩溃 / 坏档 / 黑屏 | 任何一次异常即 P0 |
