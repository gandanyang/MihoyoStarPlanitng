## 2. 检查步骤（约 5 分钟）

### 2.1 横竖屏与摇杆避让

1. 手机横屏打开游戏（无痕模式，`?reset=1` 新档）
2. 进入农场（可快速 `debug.gotoScene('farm')` 或走教程）
3. **观察**：摇杆中心是否距左边缘 ≥48px（目测或截图测量）
4. **操作**：拖动摇杆移动，是否跟手、是否误触返回手势（左滑触发确认弹窗属正常）

### 2.2 任务面板安全区

1. 打开任务面板（触屏右侧「任务」按钮）
2. **观察**：面板顶部是否避开状态栏/挖孔屏（至少 90px 以上）
3. **操作**：点击面板内条目、关闭按钮，是否正常

### 2.3 返回键层级（BUG-037 复测）

**三条路径**（制作人真机左滑验证）：

| 路径 | 场景 | 预期行为 |
|---|---|---|
| **① MapScene（farm/gate/town/forest/mine）** | 玩家在可移动地图中 | 左滑弹出确认弹窗（继续游戏 / 回到主菜单 / 退出游戏） |
| **② 非 MapScene（Title/Station）** | 标题画面 / 车站序章 | 左滑直接退出游戏（无确认，设计如此） |
| **③ 弹窗打开时** | 确认弹窗显示中 | 左滑关闭弹窗（返回键消费） |

**验证方法**：每条路径左滑一次，记录实际行为（截图弹窗）。

### 2.4 存档恢复抽查（减负版）

**前置**：已有 probe-save-restore 全链路验证，真机仅抽查一次。

1. **新档快速到教程完成**（可借助 `debug.setStoryStep('done')` + `debug.setTime(6)` + `debug.gotoScene('farm')`）
2. **睡觉保存**：进木屋 → 床上按 E 睡觉（跨天，day+1）
3. **杀进程**：切后台 → 杀掉浏览器进程（或关闭标签）
4. **重开恢复**：重新打开游戏（无痕模式会清档，需用普通模式或保留 localStorage）
5. **验证**：
   - 恢复进游戏（非 station/title 重开）
   - storyStep 保持 done（教程不重开）
   - 存档 day 不变（day+1 后值）
   - 背包物品不丢

> **注意**：真机 localStorage 持久性可能因浏览器/设备而异，若恢复失败请记录浏览器型号/系统。

## 4. 已知风险与备注

- **浏览器差异**：iOS Safari 对 localStorage/pagehide 限制较严，若恢复失败请标注浏览器
- **无痕模式**：会清空 localStorage，测试存档恢复时请用普通模式（或睡觉后立即杀进程，避免浏览器自动清理）
- **减负依据**：probe-save-restore 已覆盖真实游玩路径（车站→大门→钥匙→锄/种/浇→教程完成→睡觉→reload→恢复），真机抽查仅为验证浏览器与真机环境一致性
- **若抽查失败**：记录浏览器/系统版本，回退到完整教程路径复验
