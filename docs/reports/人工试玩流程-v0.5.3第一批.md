## 2. 试玩顺序（先 PC 完整流程，再移动端重点场景）

### 第一轮：PC 完整流程（约 15-20 分钟）

按顺序走，每段对照下方"重点验证"记录。

| 段 | 路径 | 重点验证（v0.5.3 新事件用 ★ 标） |
|----|------|--------------------------------|
| A | 标题 → 车站 → 序章 | 四感受①林澈回来原因；对白是否自然 |
| B | 大门 → 夏雅 → 钥匙 → 锄地播种浇水 | 四感受②夏雅亲和力；引导是否顺 |
| C | 睡觉 → Day2 → **清晨 06:00 左右进农场** | ★ E1 清晨偶遇：夏雅在田边吗？"这么早？我睡不着…"自然吗？陪伴感有没有？ |
| D | 上午去小镇 → 与居民对话 | ★ E4 每日随机句：老张/小梅/阿风说了生活化台词吗？每天都不一样吗？ |
| E | 去矿洞 → 与老张对话 | ★ E3 林澈过去："以前工作的时候，经常处理这些" 是否让人"哦他以前很厉害"？ |
| F | 接任务 → 森林采集 → 交付 | 四感受③爷爷线索；程序员能力展示 |
| G | 夜晚观星 → 三选项 → 结算 | 四感受④星星悬念；选项/结算面板 |

> **体验探针已知结论（避免误判，`probe-density-v053` 断言 9/9 + `probe-density-experience-v053` 慢速核读已确认）**：
> - E1 清晨偶遇：仅 06:00-08:00 且教程完成后出现，同一天只触发一次——若试玩时没见到，先确认时间与是否完成教程，不是 bug。
> - E3 老张追加：接在矿洞首次对话"这矿里老旧的机器，镇上没人会弄"之后，一次播放完。
> - E4 每日随机句：接在固定对话末尾；同一 NPC 同一天固定同一句，次日换句（seed=天数，读档不跳变）。判断"每天不一样"需跨天看。
> - **E4 阿风验证注意**：首次进入小镇会先播放小镇开场对白（`TOWN_INTRO_DIALOGUE`），需先跳完开场再靠近阿风按 E，否则按 E 在推进开场文案（不是游戏 bug）。阿风小镇站位 (200,200)；老张矿洞站位 (200,168)；小梅森林站位 (296,136)。
> - 第二批（E2 首次收获反馈 / E5 爷爷笔记 / E6 观星后少女追加）已实现并验证（`probe-density-v053-batch2` 10/10），试玩时可顺带体验。
> - **引导剧情增强（`b259bc2`+`659030e`，`probe-guide-dialogue` 6/6 + `probe-note-vs-woodcut` 2/2 已确认）**：
>   - 砍树引导：教程完成后第一次在树旁按交互，弹夏雅参与的 7 句剧情（"你倒是把什么都想好了"），结束后再按一次才开始砍。
>   - 挖矿引导：进矿洞走到**发光矿脉旁**按交互才弹（不在矿脉旁不弹），同样 7 句，结束后再按一次开采。
>   - 爷爷笔记已移到庄园左上角 (1,6)，不再挡树；若在树旁没弹砍树引导而是弹笔记，属于旧版缓存，强刷后即正常。

## 3. 判定标准（沿用移动端方案 v1.0）

| 级别 | 定义 | 例子 |
|------|------|------|
| **P0 阻断** | 无法继续核心流程 | 黑屏、坏档、触屏无法操作、新事件导致教程/主线断链 |
| **P1 问题** | 影响体验但可绕过 | 布局遮挡、按钮太小、随机句重复枯燥、台词出戏 |
