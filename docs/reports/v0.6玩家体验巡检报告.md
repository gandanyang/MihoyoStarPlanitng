## 一、新玩家前 30 分钟流程巡检

流程链：开场 → 到庄园 → 认识夏雅 → 种植 → 第一次收获 → 第一次赚钱 → 第一次探索

| 环节 | 玩家行为 | 引导机制 | 反馈 | 情绪 | 判定 |
|---|---|---|---|---|---|
| 开场 | title 按 Enter → 车站序章 | 序章对话（可跳过）；跳过后可移动 | 打字机对话 + 立绘 + 音效 | 被开除的挫败 → 新开始的希望 | ✅ 稳定（BUG-035 已修：跳过不再跳剧情） |
| 到庄园 | 出站自动进 gate → 开门 → farm | 教程提示条逐段显示 | 夏雅对话 → 钥匙 → 大门消失 | 庄园大门的神秘感 | ✅ 良好 |
| 认识夏雅 | 靠近按 E 对话 ×13 行 | 「→ 按 [B] 键打开背包，选择钥匙使用」 | 钥匙入包 + 开门剧情（7 行） | 陌生人的善意关心 | ✅ 良好 |
| 种植 | 锄地×3 → 播种×3 → 浇水×3 | 逐段提示（PC: 按 E/R / 移动端: 交互按钮） | 飘字「锄地/浇水」+ 水花粒子 + 播种 +1 种子 | 从荒芜到开垦的掌控感 | ✅ 良好（BUG-026 无效操作红闪+飘字兜底） |

## 二、核心循环断点

循环：劳动 → 环境改变 → NPC 回应 → 获得成长 → 继续探索

- **劳动**：锄地/播种/浇水/收获/砍树/挖矿/花园三阶段清理 ✅
- **环境改变**：作物 3 阶段（planted/watered/grown）、庄园恢复（倒木→破花架→花丛）、浇水水花、蝴蝶光斑 ✅
- **NPC 回应**：夏雅清晨（XIYA_DAWN）/傍晚（XIYA_EVENING）/花园见证（生活记忆对白）/主线后 NPC 闲谈 ✅
- **获得成长**：金币、XP、每日任务钻石、归星岛复苏报告（B-1）✅
- **继续探索**：新场景（森林/矿洞/小镇）、每日任务刷新、主线推进 ✅

### 断点 1【P0】机器人前置认知缺失（你点名的检查项）

**现状**：自动化机器人是 v0.6 核心卖点"减少重复劳动"，但：

1. **正式获取途径不存在**。[ShopPanel.ts](file:///c:/Users/Gdy/Documents/trae_projects/mihoyoStarPlanting/src/ui/ShopPanel.ts#L48-L49) 注释明确：`auto_farmer_robot 未来商城 100 钻石出售，本阶段不实现钻石支付；获取途径：暂无（待商城）`。目前只有 debug 命令 `giveRobot`（[main.ts](file:///c:/Users/Gdy/Documents/trae_projects/mihoyoStarPlanting/src/main.ts#L169)）能拿到。
2. **无认知铺垫**：玩家第一天种田、第二天浇水时，没有任何剧情/任务/台词铺垫"如果有台自动浇水机器就好了"。
3. 图标仍为 emoji 🤖（[Inventory.ts](file:///c:/Users/Gdy/Documents/trae_projects/mihoyoStarPlanting/src/data/Inventory.ts#L40)），未接像素图标。

**影响**：玩家正式流程**遇不到机器人** → v0.6 核心卖点空心化；机器人功能（放置/每日自动浇水收获）已实现但玩家无法感知其价值。

**建议（供制作人拍板，本报告不改代码）**：
- A. 商城实现前，先加剧情铺垫：夏雅/村长在玩家第 2 天连续浇水后提一句"听说有种自动浇水的装置……"（需制作人定稿台词，剧情权限）
- B. 或走任务链赠送：主线交付碎片后村长赠第一台机器人（引导"放在农田旁试试"），后续商城再卖
- C. 图标换像素风（见《美术资产替换清单》）

### 断点 2【P1】赚钱闭环引导缺失

- 收获时只有飘字「+1 🥕」，**没有"去商店卖掉"的下一步引导**（最早 day3 才能收，届时教程提示条早已消失）
- 农场商店摊位（v0.6 新增）是纯图形柜台（[MapScene.ts](file:///c:/Users/Gdy/Documents/trae_projects/mihoyoStarPlanting/src/scenes/MapScene.ts#L2461-L2493)），**无"靠近按 E 打开商店"浮动提示**，玩家可能不知道它可交互
- 钱不够时购买按钮仅置灰禁用（[ShopPanel.ts](file:///c:/Users/Gdy/Documents/trae_projects/mihoyoStarPlanting/src/ui/ShopPanel.ts#L250-L256)），无"卖作物赚钱"解释（但"没有种子，去商店看看吧"飘字做得好）

## 三、新手保护

| 保护项 | 现状 | 判定 |
|---|---|---|
| 误操作 | 无效操作红闪 + 飘字（「不能在这里」「还需要一点时间」） | ✅ |
| 没种子 | 飘字「没有种子，去商店看看吧」 | ✅ |
| 钱不够 | 购买按钮 disabled（灰 + not-allowed），无解释 | ⚠️ 可增强 |
| 不知道按键 | 首次提示「按 J 打开任务 · 按 B 打开背包」（使用后本局关闭）+ 教程条 PC/移动分版 | ✅ |
| 任务卡死 | ①引导任务（挖矿/砍树）未完成跨天保留；②晚间 NPC 回家不生成 talk 任务；③talk 任务 NPC 已回家 → 面板提示"明天再去找"；④教程未完成不注入挖矿/砍树引导；⑤跳过开场不再跳剧情（BUG-035） | ✅ 完善 |
