# 第一部分：当前问题分析

## 1. 玩家行动目标不明确

- 序章前段唯一指令是"前往星黎庄园"（移动教学），但"去了干什么"不清晰：林澈只说"处理一下庄园"，目标含糊
- 教程目标（锄 3 地/种 3 颗/浇 3 次）是**系统目标**，不是**剧情目标**；缺少"爷爷的信/旧锄头"这类情感牵引
- 影响：玩家第一分钟不知道"我为什么在做这件事"

## 2. 过度像小说

- 车站五连内心独白（最重灾区，纯阅读无输入）
- 观星夜两段连续环境描写（静默镜头意图正确，但节奏偏散文）
- 宣言式台词（"屏幕外的东西确实不太一样"——作者在总结主题，不是人物在说话）

## 3. 信息一次性灌输

- 开场通知四重信息（已定稿两页化：裁员+感谢 / 选择；科技快讯与 AI 卡移出开场）
- 初遇夏雅一口气交代四件事：爷爷去世 / 镇上议论 / 荒废多年 / 家人离开
- 观星夜收束处信息量大（信 + 碎片 + 少女 + 星图）

## 4. 中国乡村语境不足

- "庄园"口语泛滥（src 中 69 次），NPC 口语也大量使用
- 夏雅"镇上最漂亮的庄园"书面感强
- 缺少生活细节：邻居、院子、农具、节气、串门
- 称呼尚无"林先生"问题，但可更乡土（小林/林家那孩子）

## 5. 爷爷祖孙情感不足

- 爷爷主要通过"信"和"笔记"出现，文本偏哲思（"机器比我们聪明"是主题句，不是祖孙情感）
- 缺少生活化记忆：爷爷怎么叫林澈？小时候的事？"别饿着""地荒了怪可惜的"
- 爷爷与玩家之间缺一条"可触摸的记忆线"（旧锄头/旧笔记本/老物件）

## 6. AI 时代背景尖锐度

- 原版"岗位职责重新分配"偏被动裁员叙事；已定稿两页方案先冲击后选择，方向正确
- 残余风险：车站独白"跑得快就不会被追上"带怨气——可保留疲惫，但不要抱怨 AI
- 原则：AI 不是反派，时代只是变化（剧情规范 + 开发规范内核原则）

# 第二部分：修改后的剧情流程

> 教程结构（锄地→播种→浇水→睡觉）**不变**，只优化剧本呈现；所有建议文案落地需制作人拍板

## 节 1：列车到站

- **时间/地点**：清晨，列车站台
- **玩家行为**：观看开场（黑屏 → 列车声 → 手机通知）
- **剧情事件**：手机弹出**两页通知**（第 1 页裁员+感谢；第 2 页职业转换选择）
- **NPC 对白**：（通知文本，见任务卡 §2 修订批）
- **玩家获得的信息**：① 林澈被裁了，但可以选择 ② 他的贡献进了智能系统训练库
- **留下的悬念**：他会选什么？

## 节 2：车站独白 + 移动

- **时间/地点**：站台 → 出站口
- **玩家行为**：首次移动（前往老院子）
- **剧情事件**：独白精简为 2 句，移动触发式碎语
- **NPC 对白**：
  - 路过站台："五年了。……至少这次，是我自己选的离开。"
  - 接近出口："爷爷说，如果不知道往哪走，就回来看看。"
- **玩家获得的信息**：林澈是**主动选择**回来，不是被赶回来
- **留下的悬念**：爷爷为什么留下这座岛？

## 节 3：初遇夏雅

- **时间/地点**：老院门口
- **玩家行为**：走近 → 对话
- **剧情事件**：夏雅在门口清理杂草；递钥匙（**不一口气交代**）
- **NPC 对白**：
  - 夏雅："你就是林澈吧？终于来了。"
  - 林澈："你认识我？"
  - 夏雅："镇上就你一个姓林的年轻人。……大家都以为，不会有人回来了。"
  - （荒废多年/家人离开 → 进门后由环境展示，不在此交代）
- **玩家获得的信息**：① 镇上有人记得爷爷 ② 大家以为没人会回来
- **留下的悬念**：夏雅为什么在等？爷爷留了什么？

## 节 4：开门进院

- **时间/地点**：大门 → 院子
- **玩家行为**：使用钥匙开门 → 走进院子
- **剧情事件**：推开大门，荒废的院子；夏雅递旧锄头（**祖孙情感锚点**）
- **NPC 对白**：
  - 林澈（环视）："……比我以为的还要荒。"
  - 夏雅："旧了点，但还能用。你爷爷当年就是用这把锄头，把这片地一锄一锄开出来的。"
  - 林澈（拿起锄头）："他从来没跟我说过这些。"
  - 夏雅："有些事，要等你自己回来了，才会知道。"
- **玩家获得的信息**：爷爷与土地的关系；锄头是爷爷的
- **留下的悬念**：爷爷还有哪些"没说过的事"？

## 节 5：教程核心循环（锄地×3 → 播种×3 → 浇水×3）

- **时间/地点**：农田
- **玩家行为**：锄地 / 播种 / 浇水（系统教程，结构不变）
- **剧情事件**：每阶段一句生活化引导（不说教）
- **NPC 对白**：
  - 锄地："先开三块地。地要翻过，种子才肯住下。"
  - 播种："种下去，就得天天来看它。你爷爷说，庄稼最怕被忘记。"
  - 浇水："水别浇太多，也别太少。跟待人一样。"
- **玩家获得的信息**：爷爷的种地观（生活智慧）
- **留下的悬念**：这块地在等什么？

## 节 6：第一夜 · 睡前

- **时间/地点**：屋内，睡前
- **玩家行为**：进屋睡觉（教程收尾）→ 睡前整理发现爷爷旧笔记本
- **剧情事件**：一个生活化细节，埋祖孙记忆线
- **NPC 对白**：
  - 林澈（翻旧笔记本）："……爷爷连种地都要记笔记。"
  - （笔记本写着：）"今年番茄长得很好。植物似乎会记住照顾它的人。"（待任务卡落地）
  - 林澈："……好像有哪里不对劲，又说不上来。"
- **玩家获得的信息**：爷爷在记录生活；某处"不对劲"
- **留下的悬念**：爷爷在记录什么？（后续回收点）

## 节 7：第一章衔接（次日清晨）

- 保持现状（E1 夏雅清晨事件等）
