# 《归星物语》世界观叙事原则 v0.1

> 来源：制作人/GPT 讨论 ｜ 归档：Codex 2026-08-04 ｜ 状态：📋 已归档（含落地评估，待拍板）
> 主题方向：**被错过的美好可能性**

---

## 一、核心概念

乡村不是"天然落后、等待主角拯救的地方"，而是"**曾经拥有真实美好可能，但被时代遗忘的地方**"。玩家不是创造原本不存在的价值，而是**重新发现、修复、连接那些曾经存在过的价值**。

## 二、核心情绪

- ❌ 单纯怀旧："过去很好，但已经失去了"（停留在伤感）
- ✅ 寻找可能性："过去曾经美好，所以未来也有可能重新美好"——**过去不是终点，过去留下的东西可以成为未来的基础**

## 三、地方设计原则

**先展示美好，再展示衰败**——不要一开始告诉玩家"村庄落后/人口流失/产业衰退"，先让玩家感受到"这里曾经值得被喜欢"：

- 老宅里的生活痕迹
- 大树下曾经热闹的记忆
- 夜晚美丽的星空
- 老人讲述过去的故事

让玩家产生："原来这里以前是这样的。"

## 四、地方价值来源（具体原因，非抽象"这里很好"）

1. **自然优势**：山清水秀 / 土地肥沃 / 独特生态 / 优秀观星环境
2. **人文优势**：老一辈技艺 / 独特生活方式 / 地方传统 / 人与土地的关系
3. **精神价值**：人们曾共同生活 / 承载很多人的梦想 / 连接人与人的关系

## 五、衰败原因设计原则

- ❌ "一个坏人毁掉了一切"（脸谱化）
- ✅ 多种因素叠加：时代变化 / 年轻人离开 / 产业转型 / 发展方向错误 / 人与土地关系逐渐断裂
- 重点不是寻找敌人，而是理解"一个地方为什么慢慢失去活力"

## 六、与核心意象结合

| 意象 | 承载 |
|---|---|
| 老宅 | 曾经存在过的生活（老照片/旧家具/手记/生活用品）——修复的不只是房屋，是一段生活方式 |
| 大树 | 时间的见证者（过去：孩子玩耍/村民聚集/节日；现在：安静；未来：重新聚集） |
| 星空 | 未完成的梦想（不是逃离现实，而是普通土地上保持仰望未来的能力） |

## 七、可落地剧情方向

1. **旧观星台**：过去曾因观星环境吸引很多人 → 废弃 → 玩家修复 → 夜晚重新有人看星星（恢复一种曾经存在的梦想）
2. **老树下的过去**：大树下曾是公共空间（孩子玩耍/大人聊天）→ 只剩一棵树 → 通过 NPC 故事了解 → 重新有人聚集
3. **旧物中的过去**：爷爷留下的普通旧物 → 记录了一个地方曾经的故事（普通物品因时间和经历获得价值）

## 八、最终表达

> 《归星物语》不是讲"一个人改变一个落后的地方"，而是讲：
> **一个被时代遗忘的人，回到一个被时代遗忘的地方，在彼此重新连接的过程中，发现那些没有消失的价值。**

## 九、设计检查问题

以后设计任何 NPC/地图/建筑/剧情事件，都询问：

1. 这个地方过去有什么值得被记住？
2. 这个东西为什么曾经重要？
3. 玩家为什么希望它重新焕发生命？
4. 它连接了过去、现在还是未来？

> 如果无法回答，说明它可能只是功能，而不是世界的一部分。
