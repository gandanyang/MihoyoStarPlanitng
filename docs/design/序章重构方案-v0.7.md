> 依据：序章剧情流程优化方案 + 制作人 5 项反馈
> 前置并入：《任务-序章世界观伏笔补强方案》§2 两页通知方案

## 0. 制作人五项拍板（v0.7 定稿）

1. **星黎庄园官方名保留**；NPC 口语混用：老宅 / 老院子 / 林家的地
2. **AI 时代背景降对抗**：避免"纳入训练库"引发劳动剥夺联想，改为中性表达
3. **林澈程序员克制**：不使用过度文学化独白
4. **夏雅减少等待感**：不塑造成"等了多年的开场引导者"
5. **保留第一夜观星记忆点**：一句，不解释（不揭爷爷秘密、不扯宇宙力量）

## 1. 最终剧情流程（七节）

### 节 1：列车到站

- **时间/地点**：清晨，列车站台
- **玩家行为**：观看开场（黑屏 → 列车声 → 手机通知）
- **剧情事件**：手机弹出**两页通知**（第 1 页裁员 + 中性感谢；第 2 页选择）
- **NPC 对白**：见 §2.1
- **玩家获得的信息**：① 林澈被裁了，但可以选择 ② 时代在变化
- **留下的悬念**：他会选什么？

### 节 2：车站独白 + 移动

- **时间/地点**：站台 → 出站口
- **玩家行为**：首次移动
- **剧情事件**：独白 4 短句（程序员克制版），移动触发式
- **NPC 对白**：见 §2.2
- **玩家获得的信息**：林澈是**主动选择**回来，不是被赶回来
- **留下的悬念**：爷爷为什么留下这座岛？

### 节 3：初遇夏雅

- **时间/地点**：老院门口
- **玩家行为**：走近 → 对话
- **剧情事件**：夏雅在门口清理杂草；递钥匙（**不一口气交代背景**）
- **NPC 对白**：见 §2.3
- **玩家获得的信息**：① 爷爷以前提过林澈 ② 大家都以为不会有人回来
- **留下的悬念**：爷爷留了什么？为什么夏雅记得他？

### 节 4：开门进院（祖孙情感锚点）

- **时间/地点**：大门 → 院子
- **玩家行为**：使用钥匙开门 → 走进院子 → **拿起旧锄头**
- **剧情事件**：推开大门见荒废院子；夏雅递旧锄头
- **NPC 对白**：见 §2.4
- **玩家获得的信息**：爷爷与土地的关系；锄头是爷爷的
- **留下的悬念**：爷爷还有哪些"没说过的事"？

### 节 5：教程核心循环（锄地×3 → 播种×3 → 浇水×3）

- **时间/地点**：农田
- **玩家行为**：锄地 / 播种 / 浇水（结构不变）
- **剧情事件**：每阶段一句生活化引导（不说教）
- **NPC 对白**：见 §2.5
- **玩家获得的信息**：爷爷的种地观（生活智慧）
- **留下的悬念**：这块地在等什么？

### 节 6：第一夜 · 睡前

- **时间/地点**：屋内，睡前
- **玩家行为**：进屋睡觉（教程收尾）→ 睡前整理发现旧笔记本
- **剧情事件**：一个生活化细节，埋祖孙记忆线
- **NPC 对白**：见 §2.6
- **玩家获得的信息**：爷爷在记录生活；某处"不对劲"
- **留下的悬念**：爷爷在记录什么？（后续回收点）

### 节 7：第一章衔接

- 保持现状（E1 清晨事件）；**观星夜保留**为品牌记忆点：林澈第一次发现"这里的天空不一样"，一句不解释（见 §2.7，已埋）

## 2. 关键文本定稿

### 2.1 两页通知（`StationScene.ts`）

**第 1 页**（裁员 + 中性感谢）：

```
人事通知

因业务流程智能化调整，您的岗位职责将进行重新分配。
您参与开发的相关成果，将继续服务于智能化系统升级。

          （点击翻页）
```

**第 2 页**（选择）：

```
人事通知 · 职业转换支持计划

随着智能化系统升级，公司将对部分岗位进行调整。
根据员工意愿，您可以选择：

1. 转入 AI 协作相关岗位（智能生态部门），继续参与公司业务
2. 接受职业转换支持计划（含离职补偿），自行安排后续

请您于 7 个工作日内回复意向。

          （点击关闭）
```

### 2.2 车站独白（程序员克制版，`StorySystem.ts` STATION_DIALOGUE）

```
（手机屏幕还亮着。HR 的话停在最后一句：）
"林先生，根据评估，你完全可以加入智能生态部门。"
（收起手机。）
五年了。
……换个环境，也许也不错。
（抬头，远处晨雾里的老院子。）
爷爷说，如果不知道往哪走，就回来看看。
至少这次，是我自己选的离开。
```

### 2.3 初遇夏雅（减少等待感）

```
夏雅："你就是林澈？"
林澈："你认识我？"
夏雅："林爷爷以前提过你。……大家都以为，不会有人回来了。"
林澈："我也没想到自己会回来。本来只是想看看爷爷留下的地方。"
夏雅：（递钥匙）"那就先从这扇门开始吧。"
```

> 荒废多年 / 家人离开 → 由进门后的环境展示，不在此交代

### 2.4 开门进院（旧锄头）

```
林澈（环视）："……比我以为的还要荒。"
夏雅："旧了点，但还能用。你爷爷当年就是用这把锄头，把这片地一锄一锄开出来的。"
林澈（拿起锄头）："他从来没跟我说过这些。"
夏雅："有些事，要等你自己回来了，才会知道。"
```

### 2.5 教程三句（生活化引导）

```
锄地："先开三块地。地要翻过，种子才肯住下。"
播种："种下去，就得天天来看它。你爷爷说，庄稼最怕被忘记。"
浇水："水别浇太多，也别太少。跟待人一样。"
```

### 2.6 第一夜 · 睡前

```
林澈（翻旧笔记本）："……爷爷连种地都要记笔记。"
（笔记本：）"今年番茄长得很好。植物似乎会记住照顾它的人。"（待任务卡落地）
林澈："……好像有哪里不对劲，又说不上来。"
```

### 2.7 观星夜（保留，一句不解释）

```
林澈："城市里，很久没见过这样的星星了。"
```

> 不解释爷爷秘密 / 星痕 / 宇宙力量；作为《归星物语》品牌记忆点
