## 2. 验收维度与判据

### 2.1 风格一致性（硬标准）

- [ ] v2 严格像素风：逐像素、无抗锯齿/渐变/平滑
- [ ] 三色调（base/mid/shadow）+ 少量高光；左上光源、右下投影
- [ ] 调色板从 `gen_sprite_assets.py` 的 `C` 类 `T_*` 色导入，**禁止新造 RGB**
- [ ] 地块瓦片**无外描边**（无缝平铺）；作物精灵可有 1px 描边 RGB(18,14,22)

### 2.2 状态可读性

- [ ] 五态（耕地/播种/浇水/生长/成熟）在 16×16 实际显示下**一眼区分**
- [ ] 浇水态与耕地态差异明显（湿润/深色感）
- [ ] 播种态可见种子痕迹；生长态可见嫩芽

### 2.3 作物辨识度（核心升级判据）

- [ ] **四种作物成熟态一眼可分**（形状/色彩/特征：萝卜、番茄、玉米、草莓）
- [ ] 作物与地块叠放协调：图层顺序正确（作物在地块之上）、无穿帮
- [ ] **成熟态不再统一萝卜**：非萝卜作物成熟时显示对应作物
- [ ] 每作物三阶段（发芽/生长/成熟）递进可感知，且与地块状态匹配

### 2.4 显示与平铺

- [ ] 16×16 实际显示清晰不糊、可读
- [ ] 4×4 平铺测试无接缝、无刺眼重复
- [ ] 与相邻瓦片（草地/土路/水边）色彩体系协调，不割裂

### 2.5 性能与兼容

- [ ] 移动端真机 farm 场景 ≥30fps（新增精灵不显著增负）
- [ ] 存档兼容：旧档作物状态恢复后显示正确；**不新增存档字段**
- [ ] 纹理 key 变更（若有）探针同步；`test-tutorial` / `probe-farm-restore` 全绿

### 2.6 工具链与流程

- [ ] 资源可由既有/AI 管线**确定性复现**（脚本无 random 抖动）
- [ ] AI 生成部分走批准门禁（生图前费用估算 + 制作人批准）
- [ ] 产出物落 `public/assets/sprites/`，旧资源保留可回滚

## 3. 验收方法

1. **A/B 对比图**：新旧并排（16×16 放大显示），制作人验收
2. **4×4 平铺测试图**：地块无缝检查
3. **游戏内全链路截图**：教程锄地 → 播种 → 浇水 → 跨天成熟（四种作物各截一张）
4. **真机**：安卓 farm 场景帧率 + 实际观感
5. **探针**：`test-tutorial` + `probe-farm-restore`（+ 新增作物断言探针，若批次包含）

## 4. 验收流程

```
试产 1 作物（萝卜）→ 制作人验收风格基线
    ↓ 通过
批量其余 3 作物（番茄/玉米/草莓）→ 全量验收
    ↓ 不通过
登记问题追踪 → 返回设计/管线调整 → 重验
```

- 风格基线未通过前，**不进入批量**（防返工）
- 不达标项登记 `问题追踪.md`，不在验收文档内"顺手改"

## 5. 红线

- 不改 gid 语义 / 碰撞编号 / 存档字段
- **不扩展设计**：本文件只验收；新设计（配色/造型/氛围）另走拍板流程
- 遵守制作人控制台：Batch D 启动前不碰美术（当前 Sprint 禁止修改：机器人/美术/宇宙线）；启动后仅限本批次范围
- 创作比例 70% 生活真实 / 30% 浪漫（不把农田做成插画）
