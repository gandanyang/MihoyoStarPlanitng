# 《归星物语》第一章本地化修订 v0.8

> 状态：**制作人批准执行**（2026-08-03）｜ 用途：OpenCode 施工图
> 执行分工：**Codex 出方案 → OpenCode 执行 → Trae 验证**（Codex 不改代码）
> 原则：**只改台词和信息顺序，不动主线**（任务结构/存档/剧情节点零改动）
> 总纲：灵魂不要被台词说出来——让玩家感受到"这个地方有人生活过"，而不是"游戏在告诉我它想表达什么"
> **创作比例：70% 生活真实 / 30% 浪漫**——本作仍是二游，不是《乡村生活观察》；诗意句（如爷爷笔记"星星……是不是也想回家？"）必须保留

## 1. P0 修订（必改）

### 1.1 村长委托：拆信息、老人化（`ELDER_QUEST_DIALOGUE`）

**问题**：① "看星星看得最久的人"像 RPG 村长介绍传奇；② 星之碎片背景一次给完（爷爷秘密 + 碎片 + 森林 + 主线目标）。

**改后**：

```
村长：你就是林澈吧？星黎庄园的新主人。
林澈：您好，您是……
村长：我是星火镇的镇长。你爷爷啊，年轻时候就喜欢晚上坐在那块石头上看天。
林澈：……他真的喜欢看星星？
村长：喜欢。他以前也经常往森林跑。
林澈：去做什么？
村长：（笑了笑）他说那里有些东西，值得看看。
（村长看向远处的森林，没有再说下去。）
林澈：……那我去看看吧。
主线任务已接受：去爷爷以前常去的森林看看。
```

- 碎片是什么 → 由森林发现（FOREST_SHARD_DIALOGUE）承担，"后面发现"
- **配套（制作人定稿）**：HUD 目标文案同步软化（`QuestSystem.getQuestObjective` accepted 态："前往森林采集星之碎片" → **"去爷爷以前常去的森林看看"**；已接对白"去森林找到发光的星之碎片吧，孩子" → **"去你爷爷以前常去的森林看看吧"**）
- 链路：爷爷线 → 探索线 → 星辰线（顺）

### 1.2 夏雅减少解释（`MINE_TIP_DIALOGUE`）

**改后**：

```
林澈：那些发光的矿石……
夏雅：老张年轻时候就在矿洞里讨生活，说那些石头、铜矿都能卖钱。
林澈：（点点头）那我挖一点回去试试。
夏雅：别逞强，你爷爷以前也是，忙起来连饭都忘了吃。
林澈（内心）：以前加班熬到半夜，也没人跟我说"累了就歇着"。
```

- 功能信息保留一行，爷爷线承接关心

### 1.3 E9 傍晚：简单关心（`XIYA_EVENING_DIALOGUE`）

**问题**："没有KPI，没有周报""土地都会记得"——作者借角色说主题 + 现代职场梗破坏温暖感。

**改后**：

```
（傍晚的庄园染上一层金色。夏雅坐在栅栏边，看着远处的海。）
夏雅：累吗？
林澈：挺累的。
夏雅：以前你也是这样？
林澈：嗯。
夏雅：那以后记得早点休息。
```

### 1.4 E2 收获：生活化（`FIRST_HARVEST_DIALOGUE`）

**问题**："比屏幕里的，要实在一点吧"——方向对但太主题化。

**改后**：

```
（夏雅不知什么时候走了过来，看着你手里的收获。）
夏雅：第一次自己种出来？
林澈：嗯。
夏雅：感觉怎么样？
林澈：比想象中重。
```

### 1.5 爷爷信：加祖孙生活铺垫（`DEMO_ENDING_DIALOGUE` 信段）

**改后**（前置铺垫 + 核心问题）：

```
信：小澈，你小时候总问我，为什么每天都要给花浇水。
信：爷爷想了很久。后来发现，人做很多事情，不一定都是为了结果。
信：如果有一天机器比我们更聪明，你觉得人还需要留下些什么？
```
