# 车站场景修改计划（v0.1 设计）

> 作者：Codex ｜ 日期：2026-08-04 ｜ 状态：📋 设计计划，待制作人拍板后实施
> 定位：低成本增强"**认识林澈的观察窗口**"；**不改主线 / 教程流程 / 存档**
> 取代：圣经 §7.7 原「电脑包」调查物设计（本计划为准——私人道具不做车站交互物）

---

## 0. 设计原则

> **玩家能看到的东西，必须是这个空间里合理存在的东西。**

- 车站交互物**全部来自车站环境**（时刻表/椅子/窗口/公告栏），不来自林澈私人道具
- 数量 **≤3**（核心三件：时刻表 / 候车椅 / 售票窗口；公告栏为可选第 4）
- 车站剧情的核心**不是悲伤**，而是：**林澈第一次看到一个需要修复的东西**

## 1. 交互物设计

### 1.1 旧时刻表（世界节奏）

- **调查**：墙上的时刻表已经褪色。上面写着：「前往归星岛」「每日一班」
- **林澈**："一天一班……看来这里和城市完全不是一个节奏。"
- **作用**：表现归星岛的节奏

### 1.2 候车椅（人物观察 / 职业习惯）

- **调查**：这排椅子很旧。螺丝已经生锈。
- **林澈**："维护记录……停了好多年。" ／ "不过结构还挺结实。"
- **作用**：他看破旧的东西，不是只觉得破，而是分析"**还能不能修**"——呼应后面修庄园

### 1.3 旧售票窗口（主题）

- **调查**：窗口里的设备还亮着。但是显示屏上的日期停留在很多年前。
- **林澈**："连这里都没人维护了吗。"（停顿）"不过还能用。"
- **作用**：最"林澈"的一处——分析 + 留有余地

### 1.4 旧公告栏（爷爷伏笔 · 可选第 4）

- **调查**：「归星岛生态修复志愿活动……」日期很久以前
- **林澈**："爷爷以前参加过这种？"
- **作用**：地方曾经有人认真生活过；**不说爷爷多伟大**

## 2. 砍掉清单

❌ 手机 / 电脑包作为车站调查物（私人道具，玩家会问"为什么点主角自己的东西"）
❌ 夏雅提前出现在车站
❌ 过度内心独白（林澈不坐那儿哲学——只观察、分析）

## 3. 与成长线连接

```
隐藏起点："我的能力已经没用了。"
  ↓
交互物传递："这里有很多东西需要有人去修。"
  ↓
林澈的能力重新找到出口（修庄园线）
```

## 4. 实现范围（低成本）

- 仅 `StationScene.ts`：新增 3（~4）个车站环境交互物（物件 + 靠近按 E 调查对白）
- **不改**：主线 / 教程流程 / 存档 / 手机通知两页
- 交互物为**可选调查**：不阻塞流程，玩家可忽略

## 5. 探针影响

- 车站新增交互物需确认不卡流程：`probe-mobile-text`（通知后对话）、`test-ch1-story`（车站段推进）不受新增物件影响（交互物被动触发）
- 可选新增 `probe-station-interact` 验证三件套触发与对白

## 6. 验收

- [ ] 三件套在车站空间**合理存在**（环境物件，非私人道具）
- [ ] 林澈对白符合行为规则：观察 / 分析 / 行动，不哲学、不热血
- [ ] 教程流程零改动；手机通知两页不变
- [ ] tsc + 既有车站相关探针全绿
