---

## 0. 设计原则

1. **两个动机叠加**（E-07）：现实动机（种地 = 恢复生活）+ 情感动机（爷爷），不修成"赚钱"
2. **闭环**（E-08）：为什么种 → 恢复庄园 → 需要资源 → 收获卖钱 → 慢慢补回来（不是 种萝卜→卖萝卜→买萝卜）
3. **不游戏化**：禁止出现"任务：修复庄园 0/100"式表达
4. **不教程化**：不提前塞"萝卜能卖钱"（首次种植结束才自然带出）

---

## 1. E-07：种田动机（开门进院，`GATE_OPENED_DIALOGUE`）

**插入位置**：现有"……比我以为的还要荒。"之后、旧锄头段之前。

**定稿（制作人拍板 ✅）**：

```
林澈：……比我以为的还要荒。
夏雅：这里以前不是这样的。
林澈：爷爷一个人打理这么大的地方？
夏雅：嗯。他说，只要还有人愿意住下来，这里就不会荒废。
（递旧锄头，原有"你爷爷当年就是用这把锄头……"保留）
```

- 效果：玩家先收到"这里有人生活过 → 该让它重新有人气"，再收到"爷爷一锄一锄开出来"——**现实动机 + 情感动机叠加**
- 文本量：+3 行

## 2. E-08：金币循环意义（首次种植结束，`WATER_CROPS_DIALOGUE`）

**插入位置**：现有"种下去，就得天天来看它。你爷爷说，庄稼最怕被忘记。"之后。

**定稿（制作人拍板修改版 ✅）**：

```
夏雅：种下去了，接下来就等它长大。
夏雅：庄园还有不少地方需要修，等收成以后，可以拿去镇上的店换些钱。
林澈：卖掉？
夏雅：嗯。留下需要的，换成需要的东西，这里才能慢慢恢复起来。
```

- 效果：先解决"为什么卖"（修庄园），再保留一点主题（不是赚钱，是恢复）；夏雅不说教
- 文本量：+4 行

**商店首次强化句：不加**（制作人拍板——E-08 已解决，避免与夏雅对白重复）

## 3. E-09：开场主动性（暂缓观察，不施工）

- 不强化"爷爷秘密召唤"（会把林澈从"累了的人回来"变成"被命运选中的少年"，破坏人设）
- 记录可选增强（后续批次评估）：手机通知后加爷爷未读消息「小澈，有空回来看看」（五年没回复，删掉）——比宇宙伏笔更有力量，但不强制
