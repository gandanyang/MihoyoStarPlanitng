# 《归星物语》世界成长与复兴循环设计原则 v0.1

> 类型：核心设计理念文档（**设计过滤器**）
> 状态：设计方向沉淀，**暂不开发**（2026-08-06）
> 来源：开罗游戏拆解讨论（制作人 / GPT）
> 用途：指导后续系统设计，避免系统碎片化；加任何系统前用它问一句

---

## 〇、核心一句话

> 玩家不是在经营一个岛，而是在**见证一个失去生命的地方重新拥有生命**。

---

## 一、设计背景

项目已有：农业 / 资源 / 建设 / NPC / 羁绊 / 剧情系统。

需避免：

```
农业 = 单独玩法
建设 = 单独玩法
NPC = 单独玩法
剧情 = 单独玩法
```

未来设计围绕统一循环：**"归星岛如何重新活起来"**。

## 二、核心幻想（Core Fantasy）

玩家真正体验的是：**一个逐渐荒废的地方，在自己的行动下重新恢复人与人的联系。**

玩家不是：岛主 / 老板 / 资本经营者

玩家是：**归乡者 / 修复者 / 连接过去与未来的人**

## 三、核心循环

### 原始循环（避免）

```
采集资源 → 出售 → 获得金币 → 升级
```

问题：金币成为所有行为的唯一目的。

### 推荐循环

```
玩家行动 → 环境变化 → 岛屿恢复 → 新的居民/机会出现
        → 新的能力与故事解锁 → 进一步改变岛屿
```

## 四、世界反馈原则

不要"玩家完成任务 → 获得奖励"；
要"玩家完成行动 → **世界产生变化**"。

例：种花

- 普通：花成熟 → 卖钱
- 复兴：花园恢复 → 夏雅产生回忆 → 居民注意到变化 → 新的角色/事件出现

## 五、NPC 设计原则

**NPC 不是功能按钮。**

- ❌ NPC 出现 → 解锁商店
- ✅ 岛屿变化 → 吸引某类人回来 → 这个人的能力与人生加入岛屿 → 产生新玩法

例：木匠 = "看到故乡重新建设，因此回来的人"（带来房屋升级、家具制作、过去故事）；铁匠 = "岛屿产业重新恢复的证明"（带来工具升级、矿石加工、历史线索）。

## 六、资源价值原则

资源不该只有"卖钱"，应有多种价值：

```
自我需求 → 建设需求 → 任务需求 → 关系需求 → 剩余出售
```

- 木材：修房 / 家具 / NPC 请求 / 出售
- 矿石：工具升级 / 建筑 / 科研 / 出售
- 食物：自己生活 / 分享居民 / 料理 / 出售

## 七、建设系统原则

建设不是增加建筑数量，而是改变：

- 空间状态
- 人的行为
- 故事可能性

例：修复花园 → 荒废区域恢复 → NPC 出现 → 记忆事件 → 新关系，而不是"建筑完成 +100 金币"。

## 八、避免的问题

1. **数值堆叠**：复兴等级+1 / 攻击力+5 / 金币+100 不作为主要反馈
2. **功能孤岛**：不要"农业系统 2.0 / 建设系统 2.0 / NPC 系统 3.0"互相无关
3. **无限扩张**：所有新系统必须回答——它是否让"岛重新活起来"更加明显？

## 九、未来系统设计检查问题（设计过滤器）

以后增加任何系统前，询问：

1. **Q1**：玩家做这个事情，世界有什么变化？
2. **Q2**：这个变化会影响哪些人？
3. **Q3**：这个变化是否产生新的可能？
4. **Q4**：如果删除金币，这个系统是否仍然有意义？

## 十、最终目标

《归星物语》的成长不是"小农场 → 大农场 → 超级农场"，而是：

```
荒岛 → 有人居住 → 小社区 → 故乡重新存在 → 连接过去与未来
```
