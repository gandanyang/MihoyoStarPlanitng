# 《归星岛复兴循环》v0.10 顶层方向

> 状态：✅ **制作人拍板**（2026-08-06）
> 一句话目标：**让玩家第一次感受到——我获得的东西，不只是卖钱，而是在改变这个地方。**

---

## 〇、核心理念

**《归星物语》不是"种田赚钱游戏"，而是"资源驱动的归星岛复兴游戏"。**

核心区别：
- 星露谷：经营自己的农场
- 归星物语：**经营一个逐渐重新有人的地方**

**先不要碰（冻结）**：
❌ 完整制作系统 ｜ ❌ 大量家具摆放 ｜ ❌ 复杂建造系统 ｜ ❌ 房屋自由装修 ｜ ❌ 材料加工链 ｜ ❌ NPC 需求经济模拟

---

## 一、三条复兴线（互相解锁，非平行推进）

### 1. 资源复兴（物质）

玩家做：种田、砍树、挖矿、收集材料

产生：**建设值 / 复兴进度**

### 2. 人的复兴（关系）

玩家做：聊天、帮忙、参与事件

产生：**居民信任**

### 3. 心的复兴（主线）

玩家探索：星之碎片、爷爷留下的东西、自己过去

产生：**林澈的变化**

---

## 二、核心循环：互相解锁

**关键原则**：三条线不是独立经验条，而是互相触发。

### 循环示例 A：建设 → 人际

```
收集木头
↓
修复花园
↓
小梅出现
↓
她开始在这里工作
↓
开放新的关系事件
↓
她告诉你关于爷爷的过去
```

### 循环示例 B：关系 → 建设

```
和夏雅关系提升
↓
她告诉你："村后有一片以前爷爷种过的地"
↓
解锁新土地
```

### 循环示例 C：探索 → 关系

```
找到星之碎片
↓
触发村长回忆
↓
解锁新对话选项
```

---

## 三、事件触发结构

**不要做复杂羁绊树，用：岛屿状态 × 关系状态 触发事件。**

### 建设项目触发

| 条件 | 触发事件 |
|------|----------|
| 花园修复完成 + 小梅认识度达标 | "小梅第一次在花园喝茶" |
| 老屋升级 + 夏雅关系达标 | "夏雅帮你整理爷爷的旧物" |
| 后山道路修复 + 村长信任达标 | "村长带你去看爷爷种的树" |

### 日常事件池

每天有概率触发：

| 类型 | 示例 |
|------|------|
| 村民邀请 | "今天天气好，一起去河边走走？" |
| 小对话 | 村长："最近你把后山清理得不错" |
| 小帮助 | 小梅："能帮我搬一下这些花盆吗？" |

---

## 四、NPC 主动介入

**不要让 NPC 每天等在那里，让他们主动介入。**

### 行为反馈示例

| 玩家行为 | NPC 反应 |
|----------|----------|
| 连续三天砍树 | 村长："最近你把后山清理得不错，不过也别忘了来村里坐坐。" |
| 连续五天不和夏雅说话 | 夏雅："最近是不是太累了？" |
| 频繁帮助小梅 | 小梅："你真是个好人，爷爷以前也经常帮我。" |

---

## 五、时间节奏设计

利用现有时间系统，一天分为三个阶段：

### 上午（06:00-12:00）

劳动：种田、采集、建设

### 下午（12:00-18:00）

处理事务：商店、村民、任务

### 晚上（18:00-22:00）

情感：聊天、事件、观星

## 六、v0.10 落地方案

### 组件 1：建设项目

扩展现有 `FarmRestore.ts`，新增 3 个建设点：

| # | 建设点 | 需求 | 效果 |
|---|--------|------|------|
| ① | 老屋修复 | 木材×30 + 石头×20 + 金币×100 | 视觉变化 + 剧情解锁 |
| ② | 花园恢复 | 木材×20 + 花种×5 | 小梅相关事件 |
| ③ | 后山道路修复 | 石头×50 + 金币×200 | 森林区域变化 |

### 组件 2：NPC 反馈

每个项目完成后，至少一个 NPC 有变化：

| 建设完成 | NPC 变化 |
|----------|----------|
| 花园恢复 | 小梅出现在花园，开放新对话 |
| 老屋修复 | 夏雅帮忙整理，解锁回忆事件 |
| 道路修复 | 村长信任提升，开放新任务 |

### 组件 3：日常事件池

每天有 30% 概率触发一个随机事件：

```ts
interface DailyEvent {
  id: string;
  condition: () => boolean;  // 触发条件
  dialogue: DialogueLine[];  // 事件对话
  effect: () => void;        // 事件效果（加好感/解锁等）
}
```

## 八、与现有系统的关系

| 系统 | 关系 |
|------|------|
| FarmRestore.ts | 扩展 RESTORE_KEYS，复用存档结构 |
| QuestSystem.ts | 建设项目作为独立事件链，不塞进主线状态机 |
| NPCSystem.ts | NPC 反馈基于位置+时间，复用现有架构 |
| TimeSystem.ts | 时间节奏利用现有系统，不新增 |

## 九、Feature 任务卡

### 目标

让玩家获得资源后拥有建设岛屿的意义。

### 必须（范围）

- [ ] 木材/石材用于建设
- [ ] 三个修复项目（老屋/花园/后山道路）
- [ ] 存档支持（扩展 farm.restore，兼容旧档）
- [ ] 地图状态变化（恢复后视觉变化）
- [ ] 每个项目完成后 NPC 反馈
- [ ] 日常事件池（每天随机事件）

### 可选

- [ ] NPC 主动行为反馈（连续行为触发对话）
- [ ] 时间节奏优化（上/下午/晚上分阶段）

### 不做

- [ ] 制作系统 ｜ 家具系统 ｜ 料理系统 ｜ 材料加工链

## 十、设计目标

玩家体验应该是：

> 我今天种田，不只是为了钱。
> 我今天修房子，不只是升级。
> 我今天去聊天，也不是刷好感。
> 我做的每件事，都在让这个地方重新活起来。

**归星岛复兴循环 = 核心玩法框架**
