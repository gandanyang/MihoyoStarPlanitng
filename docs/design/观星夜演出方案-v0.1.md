# 观星夜演出方案 v0.1（星空 / 镜头 / 结尾）

> 立项：制作人 2026-08-04（发布清单 A 演出）｜状态：📋 方案，待制作人确认后施工
> 权限：观星夜是**全游戏情绪顶点**——只加演出，不改对白/选项/世界观

## 一、现状盘点（已核实）

| 层 | 现状 |
|---|---|
| 触发 | farm 右下观星点（双层光圈+✦ 标记，呼吸闪烁）→ 主线完成 + 夜晚 20:00 + 靠近按 E |
| 剧情 | DEMO_ENDING_DIALOGUE（夏雅→信→林澈）→ 三选项 → 分支 → FINALE（次日清晨） |
| 结算 | EndingPanel 归星岛复苏报告（已有） |
| 音乐 | stargaze_night 已接入（夜晚 farm 自动切） |
| 缺口 | **无真实星空**（夜空是静态暗色）｜**无镜头调度**（对话平铺）｜**结尾无收束演出**（直接弹结算） |

## 二、情绪节奏设计（演出要服务的四拍）

```
① 进入观星点：静谧（星星亮起，音乐起，镜头缓推）
② 夏雅+信：克制（镜头特写人物/信，星空作为背景呼吸）
③ 三选项：留白（镜头拉远，星空全开，给玩家时间）
④ 结算：收束（星光洒落 → 晨曦过渡 → 复苏报告 → 字幕结语）
```

## 三、方案（按层）

### 1. 星空系统（核心 MVP）

- **静态星野底**：程序化生成一张星空纹理（Phaser 离屏 canvas 或预生成 PNG），深蓝渐变 + 数百星点 + 银河带，无运行时随机（确定性）
- **动态层**：20~40 颗星点闪烁（alpha 正弦，错相位）+ 2~3 颗偶发流星/星屑（粒子）
- **性能**：移动端 ≤30fps 约束——静态底图零开销，动态层粒子数控制在 50 以内；星空仅观星夜/夜晚 farm 启用
- 与现有光圈/✦ 标记共存（标记弱化为引导，不抢星空）

### 2. 镜头调度（核心 MVP）

进入观星点触发后，用 `camera.pan/zoom` 缓动（Phaser 原生，不动存档）：

| 段落 | 镜头 |
|---|---|
| 开场 | 从玩家位置缓推至观星点上空（2~3s，星光点亮） |
| 夏雅对话 | 缓推至夏雅特写（轻微 zoom 1.1） |
| 读信 | 平移至天空（星空为主，信为文字） |
| 三选项 | 拉远全景（星空全开，停留给选择） |
| 结算 | 缓拉回地面 → 晨曦 |

- 对白推进中镜头只缓动不打断；移动端 zoom 幅度克制（避免晕）

### 3. 结尾收束（增强，可分级）

- **星光收束**：观星完成瞬间，星屑粒子向天空聚拢（1s）
- **晨曦过渡**：天色从深蓝渐变暖橙（tint 或 overlay 透明度缓动，2s）→ 切次日清晨 FINALE
- **结算字幕**：EndingPanel 复苏报告后加一行结语字幕（可复用已有文案，如"这座岛，从此有人住着了"）——**新文案走叙事版本 L1**
- 回到自由模式后星空层关闭（白天不显示）

## 四、实施分级

| 级 | 内容 | 量级 |
|---|---|---|
| **MVP** | 星空静态底 + 星点闪烁 + 开场/对话/选项镜头 + 晨曦过渡 | 中（单场景内） |
| **增强** | 银河带、流星粒子、信特写、星光收束、结算字幕 | 小增量 |
| **可选** | 星空性能优化（粒子池）、观星点进入走位引导 | 低优先 |

## 五、技术约束

- Phaser 3 现有场景内实现：`camera.pan/zoom`、粒子、程序化纹理——**不新增系统、不引入插件**
- 存档零改动（观星完成状态已有）；对白/选项/世界观零改动
- 移动端帧率回退验收（≥30fps）

## 六、验收点

- 观星夜推进有清晰镜头节奏（进入→对话→读信→选项→结算），无黑屏/跳变
- 夜空有明显星空（星点/银河/流星），移动端不掉帧
- 结算有收束感（星光→晨曦→报告→字幕），情绪闭环
- 白天/非观星场景星空层不显示；tsc + probe-stargaze 回归
