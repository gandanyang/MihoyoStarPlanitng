## 〇、脑暴核心提炼

脑暴给出了夏雅缺的"那个东西"——**灯**。三个要点：

1. **位置**：夏雅不是带林澈"回家/冒险"的人，而是黑暗里说"你可以往这里走"的人 → 与 v1.3「归星岛的第一束光」一脉相承
2. **来源**：她曾是"小小的点灯人"——童年林澈迷路，她一句"那就跟着灯回来"
3. **代价**：灯照亮别人会消耗自己——全村都找夏雅，没人问"夏雅累不累" → 产生"林澈反过来照亮夏雅"的剧情空间

**三角意象**（世界观级资产）：阿风=风（去看看世界）／夏雅=灯（别忘了回来）／林澈=星（找到自己的方向）
