# 《归星物语》本地化规范

> 版本：v1.0（2026-08-03，由 docs/世界观设定/世界本地化规范.md 迁移为 docs/design/ 设计规范体系）
> 状态：制作人定稿方向 · 文案写作与审校规范——所有 AI 写完剧情/对白，先过本规范一遍再提交
> 问题背景：很多国产独立游戏与二游"中文写出来了，但说话方式、称呼、生活方式还是欧美/JRPG"；玩家说不清哪里怪，但会觉得"有点怪"。

---

## 0. 核心开发原则（最高优先级）

> **任何一句 NPC 台词，都要问自己一句："现实中的中国乡村，真的会有人这么说吗？"**

这条原则能筛掉大量 AI 写出来的"翻译腔"。宁可朴素，不可违和。

**目标**：《归星物语》不做"中国皮、日本魂、欧美骨架"。玩法可以参考星露谷，美术可以参考二游，但**人与人的相处、称呼、生活细节**，要让玩家觉得："这就是我小时候回老家会遇到的人。"

### 0.1 项目内核原则（与《开发规范.md》一致）

> **外在审美可以有日式 ACG 影响（二游立绘 / 日式 UI / 动画演出都可以）；但世界观、价值观、人与人的关系，一定要是中国语境。**

- 学习对象不是"日本怎么写农村"，而是"中国人怎么看农村"
- 一句话特色：**用二次元的美术语言，讲一个发生在中国乡村、属于中国情感和中国生活方式的故事**
- **创作比例（制作人定稿 2026-08-03）：70% 生活真实 / 30% 浪漫**——《归星物语》仍是二游，不是《乡村生活观察》；生活化改造时保留诗意句（如爷爷笔记"星星……是不是也想回家？"）

## 1. 五类检查清单 + 人情味

### ① 称呼与空间："庄园"的本地化

- ❌ NPC："欢迎来到庄园。" / 爷爷："替我经营庄园。"
- ✅ NPC："你回来收拾林家的老院子了？" / 爷爷："家里的地，别荒了。"
- ✅ 候选词：老宅 / 老院子 / 老家 / 林家院 / 林家的地 / 那片地
- ⚠️ 正式地名（如"星黎庄园"）作为专有名词可保留；**口语对白必须本地化**——庄园是老宅，不是欧洲庄园

### ② NPC 称呼

- ❌ "林先生。" / "主角。" / "欢迎回来。"
- ✅ 老人：小林 / 林家那孩子 / 林爷爷家的孙子
- ✅ 年轻人：林哥 / 阿澈 / 林澈
- 注：公司 HR 等城市职场语境下"林先生"合理，**乡村语境禁用**

### ③ 爷爷说话方式（中国老人）

- ❌ "我相信你终将找到人生意义。"
- ✅ "别饿着。" / "屋顶漏雨记得修。" / "地荒了怪可惜的。"
- 原则：话很平常，关心都在话外——玩家能感受到"他在关心你"

### ④ NPC 闲聊（生活感）

- ❌ "今天真是美好的一天。"
- ✅ "今天太阳毒得很。" / "晚上可能要下雨。" / "今年稻子长得不错。"
- 原则：聊天气、聊收成、聊村里的事，不聊感想

### ⑤ 建筑/店名（本地化命名）

- ❌ 酒馆 / 铁匠铺 / 杂货店
- ✅ 王叔杂货 / 刘婶小卖部 / 老赵铁匠铺
- 原则：人名 + 业态，生活味立刻出来

### ⑥ 中国乡村人情味（额外重点）

- 国外 NPC："你好。"
- 中国 NPC："吃饭没？" / "回来啦？" / "你爷爷以前老坐门口晒太阳。"
- 一句话，世界就活了

## 2. 禁区速查

| 禁区 | 典型反面 | 正确方向 |
|---|---|---|
| 翻译腔 | "这真是令人印象深刻。" | "这活儿干得真不赖。" |
| 日式二游台词 | "果然……是命运让我们相遇了呢。" | 按身份说话：村口大爷不会这么讲 |
| 欧美生活方式 | 酒馆/城堡/骑士/农场主 | 老宅/小卖部/村口/自家地 |
| 书面语对白 | "因此，我决定重新开始。" | "我想回来住一阵。" |
| 感想式闲聊 | "今天真是美好的一天。" | "太阳毒得很，别晒着。" |

## 3. 应用流程

1. **写作**：按角色身份/年龄/关系写对白（先定称呼关系：谁叫他小林，谁叫他阿澈）
2. **自查**：每句过一遍核心原则（中国乡村会有人这么说吗？）
3. **审校四件事**（每写完一个剧情必查）：
   - ① 中国人的说话方式（有没有翻译腔）
   - ② 中国人的家庭关系（爷爷、邻居、乡亲像不像现实）
   - ③ 中国乡村的生活方式（节气、赶集、串门、种地细节）
   - ④ 中国价值观表达（不喊口号，靠人物和事件自然体现）
4. **具体化检查**：有没有"口号化"？（"我们要乡村振兴" ❌ → 年轻人回来、老院子重新亮灯、节日热闹 ✅）
5. **落地**：修改 `StorySystem.ts` / 剧情数据 / 环境文案，同步受影响探针断言

### 3.1 中国式宇宙浪漫主义

宇宙是全人类共同的，但表达方式是中国的：

- 欧美科幻常见：征服宇宙 / 探索未知 / 开拓边疆
- 本项目：**仰望宇宙 / 顺应自然 / 人只是天地之间的一部分**
- 重点不是"征服"，而是"连接"——与乡村主题天然契合（详见《世界观长期规划-归星宇宙浪漫主义》）
