# 自动机器人完善设计 v0.1（商店钻石购买 + 升级）

> 立项：制作人 2026-08-04｜状态：📋 设计定稿，待制作人确认数值后施工

## 一、目标

1. **商店钻石购买**自动农业机器人（多台）
2. **机器人升级**（等级/效果提升）

## 二、现状（已核实）

- 获取：FEATURE-036 花园修复获得（背包 `auto_farmer_robot` → 部署）
- 部署/自动化：`AutomationSystem`——`RobotData{col,row,range}`，`addRobot()`/`getRobotCount()`/`runDailyAutomation()`（每日浇水/收获/播种报告）
- 存档：`farm.automation`（可选字段，旧档兼容；`getAutomationSave/restoreAutomation`）
- 钻石：`diamond` 货币（每日任务获得，文案"特殊商店兑换稀有物"）；ShopPanel 已有

## 三、设计

### 1. 商店钻石购买

- **入口**：ShopPanel 新增"特殊商店"分区（钻石兑换），商品 = 自动农业机器人
- **定价（建议）**：20 钻/台（制作人可调 10~30）
- **保留免费获取**：FEATURE-036 花园修复仍给第一台（免费=教学路径），购买=多台/补货
- 购买后入背包（复用现有 use-robot 部署流程）

### 2. 机器人升级（全局等级，1→3）

- **等级存储**：`farm.automation.level`（旧档无字段 = Lv1，兼容）
- **升级入口**：商店特殊分区"升级机器人"按钮（或背包机器人卡片）
- **每级效果（建议）**：

| 等级 | 效果 | 升级钻耗 |
|---|---|---|
| Lv1 | 现状：自动浇水 + 收获（DEFAULT_RANGE） | — |
| Lv2 | 自动播种 + 范围 +1 | 30 钻 |
| Lv3 | 处理作物数 ×2 + 范围 +2 | 50 钻 |

- 等级作用于**所有已部署与新部署机器人**（全局加成，简单一致）

### 3. 自动化逻辑扩展

- `RobotData` 增加 `level`（部署时取全局等级快照或运行时时取）
- `runDailyAutomation()` 按全局等级扩展：Lv2 播种、Lv3 数量翻倍（复用现有 seeded/watered/harvested 报告）
- 多台机器人处理范围叠加（现状 addRobot 多台已支持，保持）

### 4. UI

- 商店特殊分区：机器人卡片（价格 + 购买）、升级卡片（当前 Lv → 下一 Lv + 钻耗 + 效果说明）
- 背包机器人图标显示 Lv（如 `Lv.2`）
- HUD 不新增（避免挤）

## 四、存档兼容（P0 红线）

- `farm.automation.level` 可选字段：旧档/无字段按 Lv1；保存/读取与现有 getAutomationSave/restoreAutomation 同模式
- 不破坏现有 robots 数组结构

## 五、实施清单

1. `AutomationSystem`：RobotData.level / 全局 level 读写（getAutomationSave/restore 扩展）
2. `runDailyAutomation`：按 level 扩展（播种/数量/范围）
3. `ShopPanel`：特殊商店分区（钻石购买 + 升级）
4. 背包：机器人 Lv 显示；部署流程复用
5. 探针：probe-automation 扩展（Lv1/2/3 + 旧档兼容）

## 六、验证

- 钻石购买成功/余额不足提示；升级后自动化能力提升（播种/数量/范围）
- 旧档（无 level 字段）读取正常按 Lv1；tsc + probe-automation + 存档兼容探针

## 七、红线

- 不破坏 FEATURE-036 获取/部署；存档兼容旧档；不动战斗/抽卡；探针同步
