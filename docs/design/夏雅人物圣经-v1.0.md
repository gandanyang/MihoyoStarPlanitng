## 〇、核心定位

### 「归星岛的第一束光」· 副标题：「归星岛第一个向林澈伸出手的人」

- **生活入口，不是冒险入口**：她不是带林澈进入"归星岛的冒险"，而是带林澈进入"重新生活"
- **不是教程 NPC**：她的任务不是告诉玩家怎么玩，而是让玩家愿意留在这个世界
- 她不是照亮世界的人——她是在**林澈最低谷的时候，让他重新感觉自己被需要**的人

### 最终一句话定位

> **夏雅，是归星岛第一个相信林澈还能重新开始的人。**

> 她不是带林澈寻找星星的人，她是让林澈重新抬头看星星的人。

## 一、基础设定

- **姓名**：夏雅
- **年龄**：20 岁（顶层设计当前值；提案 19~21，⚠️ 待制作人统一）
- **身份**：青禾镇镇长助理 / 岛上年轻一代居民
- **副职业**：机械维修（生活技能，非"技术少女"）
- **关键词**：阳光、可靠、好奇、行动派、岛上的小太阳

## 二、性格核心（表层 + 内层）

### 表层 ☀️ 元气

- 说话快、行动力强、喜欢分享、容易兴奋

### 内层 🌙 温柔的孤独

- 她也害怕：岛越来越冷清、年轻人离开、爷爷那一代的故事没人记得
- 所以她喜欢林澈回来——不是因为恋爱，而是：

> "原来真的还有人愿意回来。"

### 核心缺陷（不完美）

> **「太习惯留下来，所以不知道离开是什么感觉。」**

- 林澈：不知道哪里值得留下（城市人）
- 夏雅：从来没想过离开（岛上人）
- 两人互补——她不是人生导师，她也是一个普通女孩

```
林澈：你没想过去外面看看？
夏雅：看过啊。网上看过很多地方。
林澈：我是说，真的出去。
夏雅：……其实没有。
```

## 三、机械维修：生活技能定位

不做"技术少女"（禁"我的机械知识告诉我……"）。是生活技能：

```
林澈：你怎么什么都会？
夏雅：不会啊。只是坏了没人修的话，它就一直坏在那里。所以只能学一点。
```

## 四、与爷爷的关系（双向）

- 小时候：爷爷是她眼中的"大人"
- 后来：爷爷离开、庄园荒废——她也有遗憾
- 林澈回来：对她也是一次"重新开始"

> 不是"她帮助林澈"——而是**两个人一起修复过去**。

## 五、与林澈：第一章关系曲线（不恋爱，建立羁绊）

| 节点 | 夏雅眼中的林澈 |
|---|---|
| 初遇 | "爷爷认识的人" |
| 开门 | "这个人可能真的不知道怎么生活" |
| 种田 | "他虽然笨，但是认真" |
| 森林 | "他看待世界的方式很特别" |
| 观星 | "这个人终于开始留下来了" |

第一章不做恋爱线，只建立羁绊（好感度轻量版 v0.7 后置）。

## 六、标志性角色资产：旧工具包

- 她永远背着一个旧工具包
- 里面：**爷爷留下的小扳手 / 老式零件 / 修理笔记**
- 定位：角色记忆点 + **未来剧情物**（可承载爷爷线回收）

## 七、台词风格规范

**禁止**：

❌ "根据岛屿历史记载……" ／ "星辰之力正在觉醒……" ／ "这是命运选择了你。" ／ "我的机械知识告诉我……"

**推荐**：

✅ "等等，你看！" ／ "这个以前爷爷经常用。" ／ "虽然旧了点，不过还能修。" ／ "慢慢来嘛。" ／ "坏了没人修的话，它就一直坏在那里。"

## 八、游戏功能映射（生活入口）

| 剧情功能 | 表现 |
|---|---|
| 教程引导 | 带玩家入门（**不是教程 NPC**——引导靠行为而非讲解） |
| 情感入口 | 她认识爷爷 |
| 生活氛围 | 参与庄园复苏、修设备、清院子 |
| 探索推动 | 她发现异常（好奇外化） |
| 世界介绍 | 她带林澈认识小镇（生活视角） |
