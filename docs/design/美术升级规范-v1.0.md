# 美术升级规范 v1.0（Batch D 方案储备）

> 作者：Codex ｜ 日期：2026-08-03 ｜ 状态：📋 方案储备（Batch C 之后执行）
> 定位：Batch D 美术升级的作业规范——林澈 32×32 / 作物精灵 / 商店 / 地图

---

## 1. 总原则

- 复用《美术统一规范》：v2 像素风 / 三色调 / 1px 描边（地块除外）/ 调色板从 C 类导入
- 管线：**gpt-image-2（AI 定形象）→ 脚本像素化（调色板量化/降采样）→ 探针验收**
- 每次生图须制作人批准（批准门禁）
- 角色一致性：以人物圣经锚点为基准（林澈方向 B / 夏雅待定）

## 2. 升级项与流程

### 2.1 林澈 32×32 精灵（最高优先）

- 流程：AI 单帧概念（方向 B 人设锚点）→ 调色板量化 → 32×32 → **脚本扩帧**（4 方向×4 帧，不用 AI 出 16 帧防抖动）
- 验收：16×16 显示可读 / 一眼是林澈（深棕发/眼镜/蓝格纹）/ 动画循环不抖

### 2.2 作物精灵（解决"成熟态统一萝卜"）

- 范围：萝卜/番茄/玉米/草莓 × 3 阶段（发芽/生长/成熟），32×32
- 流程：每作物 1 张 AI 概念 → 切片/调色板量化 → 32×32 → 替换 crops.png 帧
- 验收：四种作物一眼可分 / 与农田五态地块协调 / 成熟态不再统一萝卜

### 2.3 商店

- 店名本地化（候选：王叔杂货/刘婶小卖部，待制作人拍板）
- 摊位视觉升级（当前为农田右下摊）
- 一键出售功能按钮位（Batch A 后）

### 2.4 地图细节（生活感）

- 农田/小镇补生活物件（农具/晾衣绳/杂物），70% 生活真实 / 30% 浪漫
- 不改变 gid 语义与碰撞编号

## 3. 验收通用标准

- A/B 对比图（新旧并排）→ 制作人验收
- 相邻资产风格统一（不割裂）
- 移动端真机 ≥30fps
- 探针同步（纹理 key 变更）

## 4. 红线

- 不改存档字段；不改变 gid 语义/碰撞
- 不批量替换未验收资源（先试点后推广）
- 机器人/美术升级遵守制作人控制台"禁止修改"项（当前禁止改机器人美术）
