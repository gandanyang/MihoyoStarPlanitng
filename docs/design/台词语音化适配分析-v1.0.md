# 台词语音化适配分析 v1.0

> 分析日期：2026-08-04 ｜ 分析范围：`src/systems/StorySystem.ts` 全部 21 个对话常量
> 用途：为制作人提供语音化（TTS / 真人配音）前的台词筛选与特殊处理清单

---

## 一、标记类型说明

| 标记 | 含义 | 建议处理方式 |
|------|------|-------------|
| ✅ 适合语音化 | 可直接朗读的对白 | 正常录制 |
| ❌ 旁白/舞台指示 | `（...）` 括号内的视觉描写 | 跳过不念，转为环境音效 |
| ❌ 系统/UI 文本 | 操作提示、物品获得、任务通知 | 跳过不念 |
| ⚠️ 语气标注 | `（笑）` `（点点头）` 等 | 转为对应语气/笑声，不念文字 |
| ⚠️ 特殊音色 | 爷爷笔记/信件、神秘女声等 | 需指定音色或后期处理 |
| ⚠️ 内心独白 | `inner: true` 的林澈想法 | 需混响/回声效果区分 |
