# 《归星物语》智能出售系统升级方案 v0.1

> 状态：✅ 制作人确认方向（2026-08-06，来源：制作人 / GPT）｜ 优先级：P1（v0.10+）
> 定位：一键出售 → **智能出售（出售预览）**——为"资源多用途"打基础，非新增玩法

---

## 一、当前问题（已核实现状）

现有一键出售（`Economy.sellAllSellable()` + 背包/商店"全部出售"按钮）：

- 出售条件 = `SELLABLE_ITEMS` 白名单（作物/木材/石头/铜铁等有价物品）
- 星之碎片 / 钻石 / 钥匙 / 工具 / 机器人已在白名单外（不可售）✅

问题：随着资源多用途扩展（木材→建房/家具/NPC 需求；矿石→升级/建筑），无脑出售会：

- 误卖建设材料
- 误卖任务/关系物品
- 玩家不知道物品价值

## 二、设计目标

不是"帮玩家卖东西"，而是**帮玩家处理"明确没有其他用途"的盈余资源**：

1. 不误卖重要资源
2. 保留整理背包的爽感
3. 支撑"资源 → 建设 → 羁绊 → 出售"循环
4. 不增加太重 UI 复杂度

## 三、出售规则

### ItemDef 增加出售优先级

```ts
interface ItemDef {
  id: string;
  name: string;
  sellPrice: number;
  sellPriority: 'normal' | 'reserve' | 'forbidden';
  tags: string[];
}
```

### 三级

| 级别 | 含义 | 处理 | 示例 |
|---|---|---|---|
| normal | 可出售盈余 | 一键出售 | 作物 |
| reserve | 建议保留（可手动卖） | 一键出售**跳过 + 提示** | 木材（建筑/家具）、铁矿（升级）、石头（建筑） |
| forbidden | 禁止自动出售 | 跳过，提示"无法通过一键出售处理" | 星之碎片、剧情物品、任务关键道具 |

## 四、一键出售流程（升级）

```
点击一键出售
  ↓
出售预览窗口：
  预计获得：850 金币
  出售：萝卜×10 / 番茄×5 / 普通矿石×3
  保留：木材×20 / 铁矿×5 / 星之碎片×1
  [确认出售]
```

## 五、锁定功能

背包物品增加"锁定 🔒"按钮（手动标记保留）：

- 锁定后任何出售方式不处理
- 存档新增 `lockedItems: string[]`（可选字段，旧档默认空）

典型用途：第一颗收获的草莓 / 爷爷留下的工具 / 特殊矿石。

## 六、未来兼容（预留接口）

物品用途查询（点击物品显示）：

```
木材
用途：✓ 出售  ✓ 房屋升级  ✓ 家具制作  ✓ NPC 请求
```

让玩家理解"为什么我要留"。本版先预留数据结构，UI 后置。

## 七、数据改造范围（与现状对齐）

| 位置 | 现状 | 改造 |
|---|---|---|
| `Inventory.ts` ItemDef | id/name/desc/icon | + `sellPriority`（+ tags 预留） |
| `Economy.ts` SELLABLE_ITEMS | 白名单价格表 | 保留为价格源；三级标签由 ITEM_DEFS 驱动 |
| `BackpackPanel` / `ShopPanel` | 一键出售 + ConfirmDialog | 出售前弹**预览面板**（SmartSellPreviewPanel） |
| `SaveData` | 无 lockedItems | + `lockedItems`（可选，旧档默认空） |

红线：**不改经济数值**；**不重构背包系统**（增量修改）。

## 八、开发拆分

| Task | 内容 | 优先级 |
|---|---|---|
| 1 | 物品标签系统（sellPriority 落到 ITEM_DEFS） | P0 |
| 2 | 智能出售算法（forbidden 过滤 + locked 过滤 + reserve 跳过提示） | P0 |
| 3 | 出售预览 UI（SmartSellPreviewPanel） | P0 |
| 4 | 锁定功能（背包按钮 + lockedItems 存档） | P1 |

## 九、验收标准

- ✅ 一键出售不误卖剧情/任务物品（forbidden）
- ✅ 建设材料（reserve）不无提示清空（预览中列出"保留"）
- ✅ 锁定物品任何方式不售出
- ✅ 玩家仍可自由整理/手动出售
- ✅ 旧存档兼容（无 lockedItems 正常运行）
- ✅ 经济数值不变、背包系统未重构

## 十、给施工的一句话

> 请在不改变现有经济系统的前提下，将一键出售升级为"智能出售系统"：增加物品出售优先级、关键资源保护、出售预览、物品锁定机制，并保证旧存档兼容。不要重构背包系统，只做增量修改。
