# 《归星物语》美术统一规范

> 版本：v1.0（2026-08-03，整合《美术规范.md》+ skills/10-art-direction + AI 生图工作流）
> 状态：制作人定稿方向 · 所有美术资源（含 AI 生成）必读
> 说明：底层管线细节以根目录《美术规范.md》为准；本文件是设计层统一规范（风格/尺寸/管线优先级）

---

## 1. 风格基准（v2 严格像素风）

- 逐像素绘制，禁止抗锯齿/渐变/平滑椭圆
- 左上光源、右下投影
- 1px 深色外描边：`RGB(18,14,22)`，不用纯黑
- 三色调 + 高光：每个色块 = base / mid / shadow（+少量 light）

> 例外：**地块/地形瓦片不加外描边**（无缝平铺需求，见 §4 平铺纪律）。

## 2. 尺寸规范

| 资源 | 尺寸 | 说明 |
|---|---|---|
| NPC / 玩家帧 | 32×32 | 场景内 setScale(0.5) → 16×16 |
| 地块瓦片（农田五态等） | 16×16 | 1×，无缝平铺 |
| 物品图标 | 16×16 | UI 16~28px |
| 瓦片 tileset | 16×16/格 | gid 语义与碰撞编号不得改 |
| 立绘 | 512×768 | 对话/剧情用（源图可 1024×1536 生成后缩放） |
| 对话头像 | 512×512 正方形 | 面部居中，方形裁切安全 |
| 场景物件 | 32×32 | setScale(0.5) |

## 3. 调色板纪律

- 统一从 `gen_sprite_assets.py` 的 `C` 类导入，**禁止重新发明 RGB**
- 角色专属色在各自脚本局部类扩展（`N` / `T` 类），命名 `{角色缩写}_{用途}`
- 三源价格/配色变更必须同步（现有遗留：CROP_DEFS / Economy / ShopPanel 三源）

## 4. 平铺纪律（地形/地块）

- 地块瓦片四边必须无缝：不加外描边、边缘连续
- 同一套资源：统一色温/光向/像素密度，不允许"四张独立插图"
- 验收：4×4 平铺测试无接缝/无刺眼重复

## 5. 立绘与头像

- 立绘：512×768 RGBA，2D 二次元风，可保留背景（圆角卡片展示）
- 对话头像：512×512 正方形，人物面部居中、占据画面足够大面积（方形裁切安全）
- 接线：StoryDialogue PORTRAIT_MAP + 对应探针

## 6. AI 生图管线（优先级固定）

> 高质量美术资源：**① gpt-image-2（默认）→ ② ComfyUI（本地备选）→ ③ 其他方式**

- 工具：`tools/gpt_image_gen.mjs`（批准门禁 + 费用估算）+ `tools/gpt_image_key.mjs`（DPAPI 密钥）
- 流程：写提示词（含 v2 约束 + 角色设定色）→ dry-run 预演 → **制作人批准** → 生成 → 后处理（切片/调色板映射/16×16 或 512×512）→ 入库接线 → 探针
- 每次生图必须批准；Key 不落明文、不进对话
- 细节见《开发规范.md》「AI 美术资源生成」

## 7. 角色一致性

- 同一角色多张图：固定角色描述词（发型/服装/配色）+ 跨视角一致性约束（所有角度同一人）
- 林澈：以《林澈人物圣经》§6 核心约束为准（反英雄 + 一致性 + 二游男主非乙游）
- 禁止风格/配色随机漂移；新立绘须与相邻角色并排验收
