# 《归星物语》支线任务扩充方案 v0.1（NPC 立体化）

> 状态：**试点已完成**（2026-08-06 制作人拍板方案 A；夏雅 + 村长两条已施工，probe-side-episodes 16/16），全量 6 条待启动
> 定位：P2 内容增强（NPC 剧情 / 小任务），服务"现有主要 NPC 更立体"，**不是新系统**
> 一句话：每个主 NPC 一个一次性支线小事件——一次共同经历 + 一段记忆，收尾用记忆卡，不碰主线、不碰好感数值、不新增地图

---

## 一、设计原则

1. **支线 = 共同经历，不是跑腿**：交付物只是引子，重点是"一起做了一件事 → 聊起过去"。
2. **奖励 = 记忆 + 新对白，不是数值**：完成后 NPC 后续普通对话多一句回响，让世界记住玩家做过的事（与邀约系统奖励原则一致）。
3. **可选、不阻塞主线**：任何支线不成为 Demo 通关前置。
4. **复用现有机制**：一次性事件标记（mapFlags）、记忆演出（MemoryFlashback / MemoryMoment）、交付检查（DailyQuestSystem 同款物品判定），零新大系统。
5. **文案全部锚定已定稿台词**：记忆卡文案尽量直接复用游戏中已有对白（如村长 N-1 拍板台词、夏雅花园句），新增连接性台词极少且需制作人确认——遵守剧情权限规则。

## 二、现状底座（2026-08-06 代码核实）

| 能力 | 位置 | 支线怎么用 |
| --- | --- | --- |
| 一次性事件标记 | `MapSceneFlags`（`MapScene.ts` ~102，存档 `mapFlags?` 可选字段） | 每条支线一个 flag，完成即永久记录 |
| 记忆闪回（沉浸式） | `playMemoryFlashback()`（`ui/MemoryFlashback.ts`） | 支线收尾演出 |
| 记忆浮层（轻量） | `showMemoryMoment()`（`ui/MemoryMoment.ts`） | 一句回响 |
| 交付判定 | `DailyQuestSystem`（collect/woodcut/mine 等目标） | 参考其物品扣除/进度判定写法 |
| NPC 交互对白 | `MapScene` 内联 dialogue 数组 + `NPCSystem.isNpcFindable`（时段判定） | 触发条件用"时段 + 场景 + flag" |
| 现有剧情钩子 | 小梅"我的水壶漏了，正愁呢"；阿风"我今天又发现一个没人去过的地方"；老张"矿洞里头凉快，来坐坐？"等 | 支线入口直接接这些已有台词 |

## 三、支线清单草案（6 条，各 1 个主 NPC）

> 每条 = 触发条件 + 流程 + 交付物 + 记忆卡。交付物只用现有物品（木材/铜矿/铁矿/作物等）；奖励为记忆卡 + NPC 后续回响对白。

### 1. 夏雅 ·「院子有人照顾」

- 触发：花园恢复完成（复用 M1-3 见证事件之后）或清晨农庄偶遇。
- 流程：夏雅提到爷爷以前总在花园坐很久 → 请林澈一起清理花田旧藤架 → 交付木材 ×3（修藤架）→ 夏雅讲小时候在花园等爷爷。
- 记忆卡：「他说，院子有人照顾，就不会冷清。」（已有台词）
- 回响：之后白天在农庄见到夏雅，小概率多一句"花田那边，一直有人打理着。"

### 2. 村长 ·「看星星的地方」

- 触发：主线观星引导已出现（N-1 已拍板文案）后，夜晚去农田边空地。
- 流程：村长托林澈带一壶茶去空地（交付任务，无实际物品或用水壶道具）→ 空地触发 → 村长讲爷爷每晚来这儿。
- 记忆卡：「那里安静，能看见很远的星星。」（N-1 拍板台词）
- 回响：村长之后会说"你爷爷要是知道你还记得那块空地，会高兴的。"

### 3. 小梅 ·「漏水的水壶」

- 触发：教程完成后任意白天，与小梅对话（接已有台词"我的水壶漏了，正愁呢"）。
- 流程：小梅请林澈帮忙 → 交付铁矿 ×2（或铜矿，数值制作人定）→ 她修好水壶 → 送一株花苗（视觉装饰：花园/门前多一株花，非物品）。
- 记忆卡：「种花和种菜一样，都得用心。」（已有台词）
- 回响：小梅之后说"水壶修好了，浇花都轻快多了。"

### 4. 老张 ·「矿洞旧事」

- 触发：首次进矿洞后，白天在矿洞/镇上与老张对话。
- 流程：老张说矿洞深处有块他年轻时发现的"星星石头" → 交付铜矿 ×2 → 他讲年轻时挖矿、晚上看星星。
- 记忆卡：「挖矿这活儿，年轻时觉得苦，现在倒觉得踏实。」（已有台词）
- 回响：老张之后说"有空再来矿洞坐坐，凉快。"

### 5. 阿风 ·「没人去过的地方」

- 触发：森林解锁后，白天与阿风对话。
- 流程：阿风说发现一个"没人去过的地方"（森林内指定点，不新增地图）→ 陪他去 → 结果是风吹旧风车/爷爷留下的旧物（纯发现，无解谜）→ 阿风嘴硬"我早就知道这里"。
- 记忆卡：「这座岛比我想象的大，还有好多地方没去过。」（已有台词）
- 回响：阿风之后说"下次再有新发现，第一个叫你。"

### 6. 商店老板 ·「镇子热闹了」

- 触发：首次在商店卖出作物后，白天与老板对话。
- 流程：老板请林澈送一篮作物给村长（连接两个 NPC）→ 村长收下并说镇上好久没这么热闹 → 回商店复命。
- 记忆卡：「你来了之后，感觉不一样了。」（已有台词）
- 回响：老板之后说"店里的货，越来越有人买了。"

## 四、技术方案（两档，建议先 A 试点）

### 方案 A：零存档结构改动（试点 2~3 条，推荐）

- 全部用 `mapFlags` 新增 flag（如 `side_xiya_garden`、`side_elder_star`…），存档兼容旧档（可选字段默认 false）。
- 每条支线 = MapScene 内联：触发判定（时段 + 场景 + flag + 交付判定）→ 对话 → flag 置位 → 记忆卡。
- 无新文件、无新 UI、无新存档字段；改动集中在 `MapScene.ts` + `data/MemoryFlashbacks.ts`（新增支线闪回数据）。

### 方案 B：轻量支线模块（全量 6 条时启用）

- `SaveData.sideQuests?: string[]`（可选字段，旧档默认空，版本号不递增）
- `src/systems/SideQuestSystem.ts`：只负责 `canStart / checkDeliver / complete`（flag 记录 + 回响对白选择），不重复对话/闪回机制。
- 涉及：`SaveSystem.ts`（可选字段 sanitize）、`MapScene.ts`、`data/MemoryFlashbacks.ts`、`DailyQuestSystem.ts`（如需统一交付判定）。

## 五、红线与冻结

❌ 不新增好感数值 / 关系网 / 恋爱
❌ 不新增物品类型（交付只用现有物品；花苗=视觉装饰不是物品）
❌ 不新增地图 / 玩法系统 / 任务 UI（第一版无任务列表，纯事件）
❌ 不触碰主角成长、世界观真相、关键剧情节点（记忆卡文案锚定已定稿台词）
❌ 支线不阻塞主线，任何一条都可在 Demo 内 5 分钟内完成

---

## 六、验收标准

- ✅ 每个支线可触发、可完成、完成后不重复触发
- ✅ 完成有记忆卡收尾，NPC 后续对白出现回响
- ✅ 存档读档后已完成支线不重置（flag 持久）
- ✅ 主线流程零改动，支线缺失不影响通关
- ✅ `tsc` 0 错 + 探针（probe-side-episodes）通过
