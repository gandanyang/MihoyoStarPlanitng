## 决策 1：浮字分层方案

### 设计原则

```
首次事件 = 记忆节点（仪式感）
重复事件 = 生活反馈（轻量）
```

### 首次事件表现

不是飘字，是：

1. 画面微调（淡入/聚焦）
2. 文字展示（不是"+1 成就"，是人生感悟）
3. 标记获得（「第一次收获」）

### 首次事件清单

| 事件 | 文案（制作人定稿） | 表现 |
|------|-----------|------|
| 第一次种植 | "城市里的人已经很久没有亲手种下一颗种子了。" | 画面淡入+文字 |
| 第一次收获 | "小时候爷爷告诉我，土地不会辜负认真照料它的人。" | 画面淡入+文字 |
| 第一次恢复花园 | "爷爷曾经走过的路，今天又有人继续走下去了。" | 画面淡入+文字 |
| 第一次帮助居民 | "有些门，不是打不开，只是需要一个人先敲响。" | 画面淡入+文字 |
| 第一次看星空 | "这片星空，和爷爷记忆里的一样。" | 画面淡入+文字 |

### 后续事件表现

普通飘字即可（`showFloatText`），不冻结玩家。

## 决策 3：林澈人设绑定——隐性表达

### 不要

> "这里没有 AI 能替代你的工作。"

太像作者说教，破坏沉浸。

### 要

归星记录评价段，隐含表达：

```
⭐ 评价

「初见希望」

你修复了一片荒废的土地。

过去，你习惯让机器替你完成一切。

但今天，你发现：

有些事情，
只有亲手完成才有意义。
```

### 核心区别

- ❌ 不是"反 AI"
- ✅ 是"AI 可以替代劳动，但不能替代人的意义"

这个区别定义了《归星物语》的灵魂。

## 制作人核心洞察

> 归星记录不应该只是总结系统。
> 它应该成为：第一章结束时的情感高潮。

### 第一章叙事弧线

```
城市失业
  ↓
回岛
  ↓
爷爷花园
  ↓
修复土地
  ↓
帮助居民
  ↓
发现自己还能创造价值
```

> "林澈为什么留下？"

📖 归星记录 · 第一章

现在，它也开始属于你。
