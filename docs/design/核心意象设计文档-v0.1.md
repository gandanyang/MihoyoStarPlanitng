# 《归星物语》核心意象设计文档 v0.1

> 定位：游戏世界的精神支柱——后续地图/NPC/剧情/建筑/事件的立项判据之一

## 一、设计目标

创造"玩家进入后，感觉'这里曾经有人生活过，也许自己也曾经属于这里'"的地方。游戏世界通过具体物件、场景、空间承载抽象主题：**归属 / 记忆 / 时间 / 梦想 / 人与土地的连接**。

## 二、核心意象体系

### 意象一：老宅（根 / 归来 / 传承）

- 精神：一个人与过去重新建立连接的地方；承载祖辈生活痕迹、家族记忆、主角重新寻找归属的过程
- 原则：不是普通基地（升级建筑/解锁功能）；要让玩家感觉"这个地方正在重新恢复生命"
- 内容：老照片 / 旧工具 / 旧家具 / 手写记录 / 老人的生活痕迹——不是装饰，是"过去曾经真实存在"的证明

### 意象二：大树（时间 / 生命 / 根）

- 精神：树比人存在更久，天然是"见证者"——见证爷爷年轻时候、主角小时候、村庄变化、新故事开始
- 原则：不是场景装饰，应成为**玩家记忆地点**
- 内容：初期树下杂草 → 中期 NPC 提到过去 / 树上刻痕 / 小时候的痕迹 → 后期重要剧情地点

### 意象三：星空（远方 / 梦想 / 未知）

- 精神：人对超越自身生活范围的向往；与老宅对照——**脚下是土地，头顶是宇宙，人处于天地之间**
- 原则：星空不能只是背景，应成为主题表达载体
- 内容：不同日期星空变化 / 特殊星象 / 老一辈观测记录 / 与主线秘密关联——"这个梦想一直存在，只是等待有人继续"

### 意象四：童年秘密基地（暂定名）

- 方向：不用传统"学校教室"（固定联想限制想象）；用老宅附近小屋 / 废弃仓房 / 老树旁小亭子 / 旧观景点 / 小时候搭建的秘密空间
- 精神：成年人在现实压力中，重新寻找小时候那个相信世界很大的自己

## 三、三个核心意象关系

```
           星空（梦想与未来）
              |
             人
              |
       老宅与大树（过去与生命根源）
              ↕
       童年秘密基地（记忆与初心）
```

三个意象回答三问：**我从哪里来（老宅）/ 我曾经是谁（童年秘密基地）/ 我要向哪里去（星空）**

## 四、后续设计判断标准

以后增加任何地图/NPC/剧情/建筑/事件，都需询问：**是否强化了至少一个？**

1. 老宅的归属感
2. 星空的梦想感
3. 童年秘密基地的记忆感

> 如果只是增加功能，没有增加情感意义，需要谨慎。

## 五、核心设计原则

- 不追求"大量内容制造世界"，追求"**少量内容形成记忆**"
- 不让玩家觉得"这里有很多东西"，而让玩家觉得"这里有一些东西，对我很重要"

## 六、阶段目标

当前阶段不扩大地图，优先提升已有空间的精神密度：

- 给老宅增加故事痕迹
- 增加大树作为记忆地点
- 设计童年秘密基地
- 强化夜晚星空体验
