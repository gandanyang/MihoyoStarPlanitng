# 《归星岛》岛屿复兴循环系统设计方案 v0.1

> 状态：📋 **设计方向入库（制作人 2026-08-06：先入库，不马上开工）**
> 定位：不是"新增系统"，而是 **复兴循环（Revival Loop）重构方案**——把现有农业/建设/NPC/羁绊/剧情串起来的长期主干方向
> 参考：开罗游戏"建设→吸引居民→解锁功能→继续建设"正反馈循环
> 原则：**不新增孤立系统，整合已有系统**

---

## 〇、核心一句话

> 《归星物语》的目标不是让玩家经营一个农场，而是让玩家**见证一个被遗忘的地方重新拥有人的故事**。

---

## 一、核心设计目标

### 当前问题

现有：种田 / 收获 / 出售 / 建设 / NPC 互动——但玩家行为之间缺少**更强的因果关系**：

```
种田 → 赚钱 → 升级 → 结束
```

玩家疑问："为什么赚钱？""建设以后有什么变化？""这个岛为什么越来越好？"

### 目标循环

```
玩家行动 → 岛屿恢复 → 居民回归 → 功能增加 → 新目标 → 继续恢复
```

> 我不是在刷资源，我是在让一个地方重新活过来。

---

## 二、核心概念：归星岛复兴度（不是传统等级）

| 等级 | 状态 | 触发条件 | 居民/解锁 |
|---|---|---|---|
| Lv0 荒废 | 杂草丛生、建筑破败、居民离开 | 初始 | 夏雅、村长 |
| Lv1 初步恢复 | 农场恢复、房屋可住 | 完成第一章 + 农场恢复 + 房屋修复 | 木匠回归；基础建设、房屋修复 |
| Lv2 小型社区 | 农业稳定、公共区域修复 | 多人任务完成 | 铁匠/花匠/商人；工具升级、制作、花园 |
| Lv3 归星村 | 多区域恢复 | — | 更多居民；节日、集体活动、复杂关系事件 |
| Lv4 星辰连接 | 后期 | — | 星象研究、机器人升级、宇宙探索线 |

---

## 三、NPC 回归机制（核心）

**NPC 不是功能 NPC——NPC = 世界恢复的证明。**

| NPC | 回归条件 | 功能 | 剧情 |
|---|---|---|---|
| 木匠 | 修复房屋/仓库/基础设施 | 房屋升级、家具制作、岛屿设施 | "没想到这里还有人在修。你爷爷以前也是这样……" |
| 铁匠 | 矿洞恢复 | 工具升级、矿石加工 | 了解岛过去产业 |
| 花匠（小梅，已有） | 花园恢复 | 花卉种植、景观建设 | 连接夏雅童年、岛屿记忆 |
| 技术员 | 后期 | 自动化系统升级 | 证明林澈过去的能力不是没有价值 |

---

## 四、资源系统重构

资源优先级（不是"获得→卖钱"）：

```
获得资源 → 满足自身需求 → 帮助建设 → 完成关系任务 → 剩余出售
```

- 木头：修房子 → 家具 → NPC 任务 → 出售
- 矿石：工具升级 → 建筑材料 → 科研 → 出售
- 食物：自己使用 → NPC 分享 → 料理 → 出售

---

## 五、与羁绊系统结合

每个 NPC 不仅提供功能，还提供关系成长路线：

| NPC | 关系方向 |
|---|---|
| 夏雅 | 爱情/陪伴 |
| 阿风 | 友情/伙伴 |
| 花匠 | 灵魂共鸣 |
| 爷爷 | 传承与理解 |

玩家建设岛屿 = 理解这些人的过程。

## 六、与金币系统关系

金币不是终点，只是推动复兴的工具：

```
劳动 → 资源 → 建设 → 居民增加 → 能力增加 → 效率提升 → 更大建设
```

## 七、开发原则

- ❌ 大量建筑摆放模拟 / 复杂城市经营 / 数值堆叠
- ✅ 少量关键设施 / 每个设施绑定 NPC / 每次建设带来世界变化

## 八、分阶段落地

- **v0.10（轻量，未拍板是否纳入）**：复兴度隐藏变量 + 1~2 个 NPC 回归事件 + 建设完成反馈
- **v0.11+**：更多居民、功能建筑、剧情
- **正式版**：完整岛屿复兴循环

## 九、与现有系统的对齐（Codex 核对，2026-08-06）

| 本方案 | 现有系统 | 关系 |
|---|---|---|
| 复兴度等级 | FEATURE-037 建设点 + `worldRestore`（oldHouse/garden/forestRoad） | ✅ **直接衔接**：worldRestore 的完成度可作为复兴度派生依据；Lv1（木匠）可挂在 oldHouse 完成后 |
| 建设完成反馈 | 归星记录 GuiXingRecordSystem（restore_garden 等标签）+ FEATURE-037 统一对白批次 | ✅ 已有反馈机制，复兴度在此基础上加"长期进度感" |
| 木匠（新 NPC） | 现有 NPC：夏雅/村长/小梅/老张(矿工)/阿风/商店老板/神秘少女 | 🆕 唯一真正的新增角色（v0.11+）；铁匠位可由矿工老张承接，避免重复 NPC |
| 花匠回归 | 小梅已存在（花园恢复后小梅相关剧情，FEATURE-037 可选对白） | ✅ 已部分具备，本方案给"回归仪式感" |
| 技术员 | 林澈程序员身份（归星助手方向 v0.1） | ✅ 后期结合，与"连接者"定位一致 |
| 羁绊成长 | 关系记录系统（好感 Phase 1，v0.10 后）+ 邀约系统（v1.0） | ✅ 本方案是关系系统的**长期叙事框架** |
| 星之碎片 | 星之碎片叙事方向 v0.1（碎片=情绪） | ✅ 复兴循环=玩法长期驱动力，碎片=叙事钩子，两者互补 |

**关系总结**：本方案不是抢 FEATURE-037 的工作，而是给 FEATURE-037（建设闭环）+ 归星记录 + 关系系统的未来扩展提供统一方向（"建设→居民回归→继续建设"）。
