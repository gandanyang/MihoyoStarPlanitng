## 一、风格方向

**星露谷田园（悠闲民谣）+ 原神抒情（叙事感/五声点缀）**

- 悠闲：温暖和弦进行（G-Em-C-D / C-Am-F-G / Am-F-C-G）、流动分解和弦、不快不赶
- 叙事感：旋律"起承转合"（ABA 结构）、短语-应答、结尾淡出收束
- 原神味：竖琴/五声音阶点缀、抒情长乐句（不用力过度）
- **红线：不诡异**——避免稀疏/不协和/尖锐；低音与高音点缀克制

## 三、管线

```
gen_music.py（纯 stdlib：作曲数据 → 标准 .mid + WAV 简单合成）
  → ffmpeg 转 MP3（试听）
  → 正式音源重渲染（SoundFont/DAW，.mid 保留，旋律不用重写）
```

- 工具：tools/gen_music.py（无第三方依赖，可加曲目/改旋律）
- 试听产物：tmp/music/（gitignored，不入库）
- 正式版：风格确认后归档 public/assets/audio/music/ + 游戏播放接入

## 四、验收

- [ ] 听感：悠闲 + 叙事感，**不诡异**（无稀疏/刺耳/不协和）
- [ ] 与场景匹配（主题/白天/夜晚情绪正确）
- [ ] 循环可用（正式版需无缝 loop 点）
- [ ] 移动端性能（MP3 体积可控、加载不卡）

## 五、红线

- 不做交响级 OST（低成本优先，MIDI 试听先行）
- 正式立项待风格确认；确认前不接入游戏
- 环境音（AmbienceSystem）与 BGM 不冲突（播放分层待正式版设计）
