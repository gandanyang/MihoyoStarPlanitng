# 《归星物语》可变探索空间方案 v0.1

> 作者：Codex（按制作人/GPT 方案归档并细化）｜ 日期：2026-08-04 ｜ 状态：📋 方案储备，待拍板后立项
> 一句话给执行方：**不增加新系统，用现有 TileMap + 存档状态，实现"玩家行为改变地图"的动态探索空间。优先设计农场一个可恢复区域，作为"复苏主题"的核心表现。**

---

## 0. 核心理念

地图从"背景"变成"**玩家行动的结果**"：

```
第一天：荒废庄园（杂草/坏屋/封闭区域）
  ↓ 玩家种田/生活推进
十天后：花开了 / 路修好了 / 新区域打开
玩家："这是我改变的地方。"
```

> 这个情绪比增加一个小游戏更重要。

## 1. 技术实现原则

**禁止**：大型开放地图 / 无缝世界 / 复杂建筑编辑 / 3D 地形

**采用**（按已验证模式，不推荐多 JSON 地图切换）：

- ✅ **场景内动态变化**（复用 M1-3 花园恢复模式：Tile 替换 + 装饰层 + 可选存档字段）
- ✅ 隐藏区域开启（条件满足后解锁进入）
- ✅ 事件触发变化（行为 → 世界变化 → 归星记录）

> ⚠️ **技术修正**：提案的 `farm_day1.json / farm_restore_1.json` 多地图版本切换有 gid/存档关联风险；项目已验证更轻的模式 = 场景内 Tile 替换 + 装饰精灵（M1-3 花园恢复即此模式，`restore.garden` 可选字段先例）。**推荐复用该模式，不做多 JSON 切换。**

## 2. 第一个落地点：农场可恢复区域（M1）

> 目标：一个区域，完整走通"发现 → 条件 → 开放 → 地图变化 → 归星记录"。

### 建议选型：后院花园（区域 A：后院杂草区）

- 初始：封闭（树木挡路 / 石头堵住），玩家第一次看到时夏雅一句："这里以前是爷爷种花的地方。"
- 条件（待拍板细化）：收获 N 次作物 ／ 修复庄园第一次（与现有进度挂钩）
- 开放后变化：杂草/封闭 → 小花园（花 / 长椅 / 小路）
- 意义：不是奖励，是"**爷爷留下的地方正在回来**"

### 与 M1-3 旧花园的关系

- M1-3（爷爷旧花园）已验证同模式——本 M1 是**第二个恢复区域**，复用其技术路线（三阶段清理/动态装饰/夏雅见证/存档可选字段），风险最低
- 区分：M1-3 是"完成即恢复"；本 M1 是"**长期条件解锁**"（收获/修复进度），呈现"慢慢回来"的递进感

## 4. 归星记录联动

- 区域开放/恢复完成时触发归星记录（记忆时刻），让"地图变化"被世界确认
- 示例记录/记忆时刻文案方向："爷爷留下的地方正在回来。"

## 5. 与林澈人设结合

地图直接回答林澈的价值问题：

```
林澈：我以前写代码的时候，经常觉得自己只是完成别人安排的东西。
      但是这里不一样。我做了一点事情，它真的留下来了。
```

> 比任何独白都有效——"你的行动有意义"由地图说出。
