# 《归星物语》剧情规范

> 版本：v1.0（2026-08-03，由根目录《剧情开发规范-v1.0.md》迁移为 docs/design/ 设计规范体系）
> 状态：制作人定稿 · 永久生效
> 适用范围：所有参与《归星物语》剧情的 AI（Codex / DeepSeek / Gemini 等）与人类协作者；**写作前必读，提交前必过**
> 优先级：与《顶层设计.md》冲突时以顶层设计为准；与《本地化规范》《世界观长期规划》《林澈人物圣经》配套使用

## 八条铁律

1. **世界观不要靠 NPC 讲解，优先通过事件和环境展示。**
2. **NPC 说话符合中国人的表达习惯，禁止翻译腔。**
3. **爷爷的人设以"温暖、克制、留有余地"为原则，不说教。**
4. **中国乡村以生活细节体现，不通过口号表达。**
5. **每段剧情必须回答："玩家做了什么？"**
6. **每段剧情最多引入一个新设定，避免信息堆积。**
7. **所有专有名词（建筑、地点、称呼）优先采用符合中国语境的表达。**
8. **保留二次元美术风格，但世界观、人物关系和价值观坚持中国语境。**

## 执行说明

**写作前**：先读本规范 + 《本地化规范》 + 《林澈人物圣经》 + 对应角色/世界观文档。

**提交前**：逐条过 8 条铁律 + 生活感五问；每处修改必须说明"玩家会体验到什么"，而不是"我觉得这样好"。

**落地**：修改 `StorySystem.ts` / 剧情数据 → 同步受影响探针断言 → 按 TEST_RULES.md 分级测试。

**审校四件事**（与《开发规范.md》内核原则一致）：

1. 中国人的说话方式（翻译腔？）
2. 中国人的家庭关系（爷爷/邻居/乡亲像不像现实）
3. 中国乡村的生活方式（节气/赶集/串门/种地细节）
4. 中国价值观表达（不喊口号，靠人物和事件自然体现）

## 生活感叙事准则 v0.1（与"工程化四要素"同等级的制作原则）

> 核心一句：**让玩家看见事物背后的过程，而不是只看到结果。**
> 定位：工程化四要素管"能不能做"；本准则管"该不该这样做、像不像《归星物语》"。所有文本、任务、系统、演出过本准则，不限制创作，只约束表达。

### 一、过程感原则（核心）

任何重要资源、物品、地点、行为，都不应该只作为"功能存在"，而应体现它背后的来源。

审核问题：**玩家是否知道这个东西从哪里来？**

❌ 普通写法：获得番茄×5 → 出售获得金币（玩家只看到结果）。

✅ 归星物语写法：种下种子 → 等待成长 → 第一次收获 → 出售 → 镇上有人使用这些资源（玩家理解这是一个过程）。

### 二、生活连接原则

不要把世界写成"系统"，让玩家感受到：**这些东西原本服务于人的生活**。

审核问题：**如果删掉数字和奖励，这个内容还有没有意义？** 没有 → 太系统化。

❌ 矿洞 = 铜矿资源点，产出铜矿（游戏地图）。

✅ 老张："以前镇上的工具、灯具很多都来自这里。"（生活）。

### 三、微小行动原则

不用伟大的行动改变世界，而是**通过重复的小事恢复世界**。

不要"完成救世任务 → 世界恢复"；而是"修一盏灯 / 种一片花 / 整理一本旧相册 → 世界产生一点变化"。与归星岛复兴系统天然匹配。

### 四、避免"何不食肉糜"原则

不否定现代便利，而是**让玩家重新理解便利背后的成本和过程**；不做"城市好 / 农村好"的二元对立，不说教。

❌ "城里人不懂农业。"

✅ "城里的生活很方便。只是偶尔，我们会忘记一颗米、一份菜经历了什么。"

### 五、NPC 表达原则

每个 NPC 不负责讲道理，只表达自己的生活经验。

| NPC | 关键词 |
| --- | --- |
| 村长 | 时间 / 土地 / 记忆 |
| 夏雅 | 变化 / 重新发现 |
| 老张 | 过去 / 手艺 / 痕迹 |
| 小梅 | 生长 / 生命 |

审核问题：**这句话像不像一个人在说自己的经历？** 不像，就改。

### 制作人内容审核五问（对白 / 任务 / 系统说明通用）

1. 玩家看到的是结果，还是过程？
2. 这个东西有没有连接人的生活？
3. 是否通过小行动产生变化？
4. 是否避免简单价值判断？
5. NPC 是在分享经历，还是在发表观点？

> 精神内核：**不要忘记你享受的一切，都曾经有人认真创造过。**
