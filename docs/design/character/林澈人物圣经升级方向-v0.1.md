# 林澈人物圣经升级方向 v0.1（设计提案）

> 状态：📋 **设计阶段，待制作人确认**｜ 日期：2026-08-04

> 原则：**不推翻现有序章/第一章结构**，以低成本方式增强角色共鸣
> 与现圣经关系：并入《林澈人物圣经-v1.0.md》需制作人确认后执行（本文件为提案层）

## 一、当前问题：林澈缺的不是背景，是"人生感"

现有设定（大城市程序员 / 被 AI 替代 / 回乡继承庄园 / 对未来迷茫）像**角色简历**，不是**角色人生**：

- 玩家知道"他发生了什么"
- 还不知道"**为什么这件事会刺痛他**"

## 二、核心人设升级

原定位：

> 被 AI 时代淘汰的城市青年，回到乡村继承庄园。

升级为：

> **一个曾经相信效率、技术和努力可以解决一切，却突然发现自己不知道为什么努力的人，在一片慢下来的土地上重新找到价值的人。**

## 三、核心矛盾

- **表层**：城市失业 → 回乡
- **深层**："如果我的能力可以被轻易替代，那我的价值在哪里？"
- 他真正失去的不是工作，而是：对未来的确定感 / 对自身价值的认可 / 努力能换来结果的信念

## 四、不逃回乡村（禁止方向）

❌ 因为城市太卷所以逃离 ／ ❌ 被动接受爷爷留下的一切 ／ ❌ 等夏雅带他融入乡村

✅ 最开始只是寻找一个喘息的地方；接触庄园/小镇/人之后逐渐产生"这里也许值得我投入"

> 最终：**我不是被迫留下，而是我自己选择留下。**

（与 v0.7 车站独白"至少这次，是我自己选的离开"一致——延续而非推翻）

## 五、核心成长曲线（三阶段）

| 阶段 | 关键词 | 表现 |
|---|---|---|
| 一 | 失去方向 | 对未来没规划、不主动谈梦想、对乡村保持距离 |
| 二 | 重新产生兴趣 | 通过小事（修门/整理土地/发现爷爷旧物）——不是突然热血 |
| 三 | 主动投入 | "既然没人管，那我来试试。"（不是任务/使命） |

## 六、关键人物特质：旧职业习惯

程序员经历影响行为方式——**遇到问题习惯拆解、分析、解决**：

```
夏雅：这个门坏好多年了。
林澈：不是坏，是轴承磨损。
夏雅：你还懂这个？
林澈：以前修电脑的时候，习惯了。
```

作用：证明林澈**不是废柴，只是失去了方向**。

## 七、第一个主动选择节点（建议加入）

```
夏雅：如果觉得这里太麻烦，其实可以卖掉庄园。
林澈：（沉默）……不了。
夏雅：为什么？
林澈：我也不知道。但是今天整理院子的时候，我发现……这里不是没人要，只是太久没人管了。
```

意义：从"继承者"变成"**参与者**"。

## 八、种田体验中的人物成长

第一次收获（与 E-08 已落地对白衔接）：

```
林澈：……挺奇怪的。
夏雅：为什么？
林澈：以前做项目的时候，完成以后东西属于公司。但是这个……它是我的。
```

核心：第一次感受到"**自己的投入 → 产生真实结果**"。

## 九、车站场景优化方向（低成本，不增大量剧情）

### 调查物 1：旧候车牌

```
"归星岛方向列车，一日一班。"
林澈：以前这里应该很热闹吧。
夏雅：嗯。以前很多人从这里回来。
```

作用：这里不是没有价值，只是被遗忘。

### 调查物 2：林澈的行李/电脑

```
"五年。每天打开它。现在突然不知道下一次打开它还能做什么。"
```

作用：他不是逃跑，他是在寻找新的答案。

## 十、与夏雅关系定位（互相影响）

- 夏雅：不是拯救林澈的人；林澈：也不是被夏雅改变的人
- 夏雅让林澈重新看到生活；林澈让夏雅重新思考自己为什么留下

> 共同主题：**一个不知道为什么留下的人，遇见一个从没想过离开的人。**

（与夏雅圣经 v1.3「互相影响/共同修复过去」一致）

## 十一、落地优先级

| 优先级 | 内容 |

## 最终一句话定位

> **林澈不是一个逃离城市的人。他是一个曾经不知道自己为什么努力的人，在归星岛重新找到"值得投入"的东西。**
