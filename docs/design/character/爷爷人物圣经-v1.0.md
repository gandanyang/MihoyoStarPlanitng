# 爷爷人物圣经 v1.2

> 状态：✅ 制作人拍板（2026-08-04）｜**v1.2：N-2 落地——姓名林远山 + 笔记池生活化（叙事版本登记）**｜落地：剧情权限，任何新台词/事件须制作人确认
> 定位级别：**精神锚点**——爷爷是《归星物语》的"根"，夏雅是"留下来的理由"，爷爷是"愿意留下来的根"

## 一、一句话定位

> **他不是告诉林澈人生答案的人，而是留下一个地方，让林澈自己找到答案的人。**

夏雅代表"现在正在建立的连接"，爷爷代表"过去留下来的连接"。

## 二、角色圣经六问（制作人命题，先答这六题）

### 1. 爷爷这一生最大的遗憾是什么？

> **有些话没来得及说。**

他年轻时也有过离开的机会（招工/进城），他选择了留下。他不后悔留下——后悔的是**从没跟人解释过为什么留下**，包括对家人。老伴走得早，他一肚子话最后都写进了笔记，而不是当面说出来。晚年他试着用土法让机器记住土地，也没人懂他在做什么——他不介意没人懂，只是遗憾没能当面说给家人听。

落点：观星笔记 = 他没说出口的一生。

### 2. 爷爷最骄傲的事情是什么？

> **这片地还在，这些孩子我都看着长大。**

不是地种得多好，而是：老宅前的树是他年轻时种的、比林澈年纪大；村里每个孩子小时候的事他都记得，他教过他们认字、看星星；每年都会修补老宅。

落点：村长台词已埋线——"你爷爷啊，年轻时候就喜欢晚上坐在那块石头上看天"；村民眼里的他是"那个老林啊，种了一辈子地"，但细看全是生活痕迹。

### 3. 爷爷为什么选择守护这个地方？

> **"只要还有人愿意住下来，这里就不会荒废。"**（游戏已有台词，作为他的信条）

不是地值钱，而是"这里有人生活过，不能让它荒了"。他守护的不是房子，是**记忆本身**——怕人走了，故事就没了。

### 4. 爷爷最害怕林澈变成什么样的人？

> **一个再也不抬头看天的人。**

不是怕林澈"不回来"，是怕他变成"没有根的人"——在城市里一直跑，却不知道自己为什么跑；把"慢下来"当成认输，把"留下"当成失败。

### 5. 爷爷希望林澈最终明白什么？

> **价值不是效率，不是有用；是愿意为某个地方、某个人、某段时间投入自己。**

与林澈的错误认知（"只要足够努力就有价值"）正好相反：价值来自**你愿意为什么留下**。星星没有消失，只是抬头的时间少了。

### 6. 如果爷爷还能和林澈说一句话，会说什么？

> **"小澈，累了就回来。家里的地，给你留着呢。"**

生活、克制、不说教——这是遗嘱，不是遗产。

## 四、与"星"的关系：民间浪漫主义（不是科幻）

红线：**不许**"爷爷发现外星文明 / 星痕研究 / 科学观测"。

可以：

- 年轻时喜欢看星星，说：**"城市里的人总说星星消失了，其实不是星星少了，是我们抬头的时间少了。"**
- 留一本**观星笔记**：哪一天看到什么星、哪颗星代表什么季节、哪年村里有什么变化——玩家后期发现，这本笔记记的是**爷爷的一生**。
- 神秘感只保留一条（现有笔记池的星辰周期观察），其余全部生活化。

## 五、有文化、有内涵（不是文盲，也不是科学家）

- 年轻时**读过书、当过几年小学代课老师**，后来回村种地，又做过林业员
- 一辈子爱读书、爱琢磨、爱记笔记——笔记不是写给谁看的，是他跟自己说话的方式
- 谈吐有见识但不掉书袋：他讲道理用的是"那棵树""那年冬天"，不是术语
- 村里孩子眼里的他："老林什么都懂一点，就是不爱说。"

## 六、神秘启发与 AI 尝试（民间土法）

**受到过神秘事件的启发**：

- 年轻时在森林里见过无法解释的光（现有笔记池已埋："那些发光的碎片，醒来时像在看我"）
- 他没有研究它、没有解开它——他**相信**它。这份相信让他记了一辈子星星、季节、植物的规律，总觉得"这座岛在回应什么"

**做过一些 AI 方面的尝试（土法，不是科研）**：

- 他把观察到的规律写成一页页"土算法"（哪天下种、什么时候浇水、植物喜欢什么照料）
- 他手搓过一台**旧农业机器人**（FEATURE-036 游戏内已有）——用捡来的零件拼的，想让机器"记住照顾它的人"
- 他不会写代码、不懂现代 AI，但他的尝试和现代 AI 是同一件事：**让机器学会照顾人留下的东西**

> 民间浪漫主义版本：不是"爷爷发明了 AI"，是"爷爷用自己的方式，先想通了 AI 时代之后很多年人们才想通的事——技术应该记住人，而不是替代人。"

## 七、与林澈的传承闭环（AI 时代主题的锚）

- 林澈：被 AI 替代、失去价值的程序员
- 爷爷：用一辈子土法，让机器记住土地的人
- 旧机器人修复（FEATURE-036）= 林澈用**现代技术**续上爷爷的**土法尝试**——"爷爷不会写代码，但他早就想明白代码该用来干什么"
- 林澈成长线闭环：从"我的能力被替代了" → "技术不是爷爷的，是生活教会爷爷的" → "我可以用技术，让这个地方继续有人住"

## 八、为什么把宅子留给林澈

**不是"回来继承财产"，是"如果累了，就回来看看"。**

- 林澈小时候每年暑假来；长大去了城市。
- 爷爷看得出这个孩子越来越迷失（越来越像自己年轻时，或越来越不像）。
- 遗嘱不是一纸公文，是一句话。它解释了**一个城市青年为什么会回来**——不是被动继承，是他自己选的离开城市（与序章"至少这次，是我自己选的离开"闭环）。

## 九、与林澈的冲突（不许写成完美圣人）

- 爷爷年轻时也为"留下"放弃过机会——他也有过不甘心。
- 林澈小时候觉得："爷爷只是一个守着旧房子的老人。"
- 长大后理解：爷爷其实也在寻找自己的答案——他只是找到了，用了一辈子。

## 十、留下的不是遗产，是"未完成的事情"（任务挂载点）

| 载体 | 玩家发现 | 含义 |

| 修复旧菜园 | 爷爷年轻时种过同样的植物 | 生活痕迹的延续 |
| 修复观星台 | 爷爷曾和小时候的林澈一起看过星星 | 记忆的恢复 |

这些全部可转化为 NPC 事件，但**当前阶段只作方向储备，不扩主线**（v0.9 发布清单 C 类边界）。

## 十一、台词风格规则（AI 写对白必守）

爷爷**不会**：

- 说大道理、念诗、突然哲学
- 自称"老夫"、喊口号
- 解释世界观、科普星星

爷爷**会**：

- 用"小澈"称呼；自称"爷爷我"
- 关心藏在生活细节里："别饿着""屋顶漏雨记得修""地荒了怪可惜的"
- 话说一半，留白；情绪藏在动作里（修门、浇水、看天）

例：

- ✅ "小澈，地荒了怪可惜的。"
- ✅ "我年轻那会儿，也想过要不要走。"
- ❌ "孩子，宇宙的奥秘就在我们头顶！"

## 十二、设计红线

1. **不科学家化 / 不英雄化**：神秘只保留一条（星辰周期观察）
2. **不剧透宇宙线**：星之碎片真相、星痕、归星秘密——全部冻结，圣经不碰
3. **剧情权限**：任何新台词/新事件落地前须制作人确认
4. 与现有锚点一致：旧锄头 / 信 / 笔记池 / 花园 / 村长台词（不许推倒重来）

## 十三、与夏雅/林澈的三角

- 夏雅：让林澈"愿意留下来"（当下的连接）
- 爷爷：让林澈"知道为什么值得留下"（过去的根）
- 林澈：从"不知道为什么努力" → "愿意为这里投入"（两者之间的桥）
