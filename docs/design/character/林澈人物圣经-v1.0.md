## 1.5 主题定义升级（v1.1，制作人定稿）

林澈的核心身份从"程序员"升级为：

> **一个被未来抛弃，却仍然相信未来的人。**

- 他不是反 AI，他甚至喜欢 AI："我知道它会取代我，但我还是喜欢研究它"——被裁通知的电脑里，还留着他自己训练 AI 的笔记
- 与鲸鱼娘形成镜像：**林澈（被 AI 淘汰的人）× 鲸鱼娘（即将被人类抛弃的 AI）**——一个害怕自己没有价值，一个害怕自己没有存在意义；他们共同证明"价值不是由效率决定的"

## 1. 角色卡

- **姓名**：林澈
- **年龄**：27 岁（2026 年近未来背景，全项目统一值）
- **身份**：被 AI 淘汰的程序员，回到祖父留下的岛屿庄园
- **叙事功能**：玩家情绪载体，"慢下来"的转变
- **核心矛盾**：想逃离被定义的人生，又害怕自己失去价值
- **外在**：冷静、幽默、可靠；**内在**：疲惫、不确定、渴望重新连接世界
- **说话方式**：不炫耀 / 偶尔冷幽默 / 不轻易表达脆弱
- **台词禁区**：不说霸总台词 / 不无脑撩人 / 不救世主化

## 2. 视觉身份锚点（v1.0 定稿）

- 深棕色短发（利落）
- 细黑框眼镜
- 蓝色格纹衬衫
- 胸前挂旧工牌
- 佩戴智能手表
- 气质：温和克制、略带城市疲惫感，但眼神仍有希望
- 一句话：**他不是英雄，而是一个重新寻找人生意义的普通年轻人**

---

## 3. 三层视觉关键词

| 层 | 关键词 | 说明 |
|---|---|---|
| 第一层：现代青年 | 眼镜 / 工牌 / 智能手表 / 简洁服装 | 一眼看出"这是 2026 年的年轻人"；这些不是装饰，是剧情符号 |
| 第二层：失败感（非颓废） | 干净 / 温柔 / 有一点疲惫 | 是"曾经努力过、被时代甩下来的年轻人"，不是社畜大叔 |
| 第三层：未来可成长 | 形象允许变化 | 初始形象为成长弧线留出空间（见 §5） |

## 3.5 角色闪光点（v1.1，制作人定稿）

1. **他不是反 AI，他甚至喜欢 AI**——被 AI 取代工作，但电脑里仍保存着自己训练 AI 的笔记（矛盾点：岗位被智能系统接替 vs 还在研究智能系统）
2. **27 岁的人，却有老人的生活习惯**——继承爷爷庄园后：修旧木门、研究爷爷留下的农具、记录天气、给植物命名；一个数字时代的人重新学习触摸真实世界（不是突然变成农夫，而是笨拙真诚地开始）
3. **专属标志物：爷爷时代的旧 AI 助手终端**——技术已落后：偶尔翻译错误、给出过时建议、一本正经讲冷笑话；连接"鲸鱼娘、AI 人格化"长线主题

> 外貌锚点不变：禁止白发少年 / 贵族少爷 / 战斗型主角；优势是"普通，但普通里面有细节"。

## 4. 明确禁忌（制作人定稿）

❌ **红夹克 + 金黄短发**——传递"冒险少年 / 热血主角 / RPG 英雄"模板，与"AI 时代程序员、被裁青年、回乡重新开始"叙事错位

❌ **二游 16~20 岁少年男主模板**——27 岁年轻成年人才撑得起 AI 时代 / 乡村振兴 / 人生重新开始三条命题

❌ **邋遢社畜 / 黑眼圈严重 / 胡子**

❌ **"二次元男主"等泛化描述作为生图约束**——必须使用 §6 核心约束

## 6. AI 生图核心约束（提示词基准，禁止改动）

> 中国未来近未来背景，一名 27 岁的程序员青年，因为 AI 取代工作回到祖父留下的岛屿庄园。他有深棕色短发，细黑框眼镜，蓝色格纹衬衫，胸前挂旧工牌，佩戴智能手表。气质温和克制，略带城市疲惫感，但眼神仍有希望。他不是英雄，而是一个重新寻找人生意义的普通年轻人。

所有林澈相关的 AI 生成（概念图 / 头像 / 立绘 / CG / 宣传图）必须以这段话为人物基础，再叠加画布与风格要求。

**强制附加约束（v1.0 补充，制作人定稿 2026-08-03）：**

1. **反英雄约束**：非英雄型主角设计，避免夸张战斗服饰，不要少年勇者感，强调普通青年与真实职业背景。避免"高品质二游角色设计"类措辞被模型美化成精致少年脸 / 王者气质 / 英雄感。
2. **跨视角一致性**：保持服装、发型、颜色完全一致，所有角度必须是同一个角色（同发型、同服装配色）——保证后续头像 / CG / 精灵 / 宣传图可复用。

## 7. 资产执行路线图

1. **Step 1 角色设定图**：正面 / 半身 / 全身 / 表情，先确认"这个人是不是林澈"
2. **Step 2 游戏头像**：对话头像、UI 头像、剧情窗口——玩家最高频看到的，收益最高
3. **Step 3 32×32 精灵**：表现层最后做；采用"AI 定形象 + 脚本扩帧"方式补齐动画，避免逐帧抖动

三个探索方向不是三选一，而是林澈的三个时间切片，与 §5 成长服装阶段一一对应：

| 切片 | 方向 | 叙事位置 | 用途 |
|---|---|---|---|
| 过去 | A 失业程序员（城市疲惫 / 旧工牌 / 未关机电脑 / 蓝光） | 序章 / 车站 / 被裁记忆 | 开场反差："昨天还属于城市" |
