## 1.5 主题定义升级（v1.1，制作人定稿）

林澈的核心身份从"程序员"升级为：

> **一个被未来抛弃，却仍然相信未来的人。**

- 他不是反 AI，他甚至喜欢 AI："我知道它会取代我，但我还是喜欢研究它"——被裁通知的电脑里，还留着他自己训练 AI 的笔记
- 与鲸鱼娘形成镜像：**林澈（被 AI 淘汰的人）× 鲸鱼娘（即将被人类抛弃的 AI）**——一个害怕自己没有价值，一个害怕自己没有存在意义；他们共同证明"价值不是由效率决定的"

## 1. 角色卡

- **姓名**：林澈
- **年龄**：27 岁（2026 年近未来背景，全项目统一值）
- **身份**：被 AI 淘汰的程序员，回到祖父留下的岛屿庄园
- **叙事功能**：玩家情绪载体，"慢下来"的转变
- **核心矛盾**：想逃离被定义的人生，又害怕自己失去价值
- **外在**：冷静、幽默、可靠；**内在**：疲惫、不确定、渴望重新连接世界
- **说话方式**：不炫耀 / 偶尔冷幽默 / 不轻易表达脆弱
- **台词禁区**：不说霸总台词 / 不无脑撩人 / 不救世主化

## 2. 视觉身份锚点（v1.0 定稿）

- 深棕色短发（利落）

- 一句话：**他不是英雄，而是一个重新寻找人生意义的普通年轻人**

## 3. 三层视觉关键词

| 层 | 关键词 | 说明 |
|---|---|---|
| 第一层：现代青年 | 眼镜 / 工牌 / 智能手表 / 简洁服装 | 一眼看出"这是 2026 年的年轻人"；这些不是装饰，是剧情符号 |
| 第二层：失败感（非颓废） | 干净 / 温柔 / 有一点疲惫 | 是"曾经努力过、被时代甩下来的年轻人"，不是社畜大叔 |
| 第三层：未来可成长 | 形象允许变化 | 初始形象为成长弧线留出空间（见 §5） |

## 3.5 角色闪光点（v1.1，制作人定稿）

1. **他不是反 AI，他甚至喜欢 AI**——被 AI 取代工作，但电脑里仍保存着自己训练 AI 的笔记（矛盾点：岗位被智能系统接替 vs 还在研究智能系统）
2. **27 岁的人，却有老人的生活习惯**——继承爷爷庄园后：修旧木门、研究爷爷留下的农具、记录天气、给植物命名；一个数字时代的人重新学习触摸真实世界（不是突然变成农夫，而是笨拙真诚地开始）
3. **专属标志物：爷爷时代的旧 AI 助手终端**——技术已落后：偶尔翻译错误、给出过时建议、一本正经讲冷笑话；连接"鲸鱼娘、AI 人格化"长线主题

> 外貌锚点不变：禁止白发少年 / 贵族少爷 / 战斗型主角；优势是"普通，但普通里面有细节"。

## 3.6 核心人设升级（v1.2 制作版）

> **一个曾经相信效率、技术和努力可以解决一切，却突然发现自己不知道为什么努力的人，在一片慢下来的土地上重新找到价值的人。**

最高层定位标签：**「重新选择人生的人」**

> **曾经看不见光，然后重新学会抬头看光的人**——这样"归星物语"这个名字才真正成立。

## 3.7 深层矛盾

- 表层：城市失业 → 回乡
- 深层：**"如果我的能力可以被轻易替代，那我的价值在哪里？"**
- 他真正失去的不是工作，而是：对未来的确定感 / 对自身价值的认可 / 努力能换来结果的信念

## 3.8 核心缺陷

> **习惯把所有事情当成问题，而不是生活。**

程序员思维在人和生活里成为缺点：分析 → 拆解 → 优化 → 解决，但人生很多东西没有答案。

```
夏雅：今天晚上星星很好看。
林澈：嗯，根据天气预报，今晚云量……
夏雅：……
```

不是搞笑角色，而是他太习惯寻找答案。

## 3.9 错误认知（成长起点）

> **"只要我足够努力，我就一定有价值。"**

故事告诉他：价值不是来自效率，不是来自别人需要你完成什么，而是**你愿意投入什么**。

成长层次：

```
开始："我要证明自己还有用。"
  ↓
中期："这个地方需要我。"
  ↓
最后："即使没人需要，我也愿意留下。"
```

## 3.10 行为规则（AI 写对白必守）

**表层关键词**：理性、克制、观察力强、不善表达
**内层关键词**：渴望被认可、希望证明自己有价值

林澈**不会**：

❌ 热血宣言 ／ ❌ "我要拯救这个岛" ／ ❌ 突然哲学

林澈**会**：

✅ 观察细节 ／ ✅ 默默解决问题 ／ ✅ 用行动表达

## 4. 明确禁忌（制作人定稿）

❌ **冒险少年 / 热血主角 / RPG 英雄模板**（如红夹克+金发、勇者套装）——与"AI 时代程序员、被裁青年、回乡重新开始"叙事错位（注：当前 `player.png` 实际为青绿外套+深蓝裤旧形象，非红夹克金发；升级目标仍为方向 B 蓝格纹衬衫）

❌ **二游 16~20 岁少年男主模板**——27 岁年轻成年人才撑得起 AI 时代 / 乡村振兴 / 人生重新开始三条命题

❌ **邋遢社畜 / 黑眼圈严重 / 胡子**

❌ **"二次元男主"等泛化描述作为生图约束**——必须使用 §6 核心约束

❌ **乙游男角色方向（v1.1 补充，制作人定稿 2026-08-03）**——林澈是**二游男主**（游戏主角、玩家情绪载体、人生镜像），不是乙游恋爱攻略对象；禁止向"撩人 / 高颜值攻略向 / 浪漫化 / 被观赏对象"方向漂移。他普通、有细节、可共情，是"玩家想成为/想理解的人"，不是"玩家想攻略的人"。

## 6. AI 生图核心约束（提示词基准，禁止改动）

> 中国未来近未来背景，一名 27 岁的程序员青年，因为 AI 取代工作回到祖父留下的岛屿庄园。他有深棕色短发，细黑框眼镜，蓝色格纹衬衫，胸前挂旧工牌，佩戴智能手表。气质温和克制，略带城市疲惫感，但眼神仍有希望。他不是英雄，而是一个重新寻找人生意义的普通年轻人。

所有林澈相关的 AI 生成（概念图 / 头像 / 立绘 / CG / 宣传图）必须以这段话为人物基础，再叠加画布与风格要求。

**强制附加约束（v1.0 补充，制作人定稿 2026-08-03）：**

1. **反英雄约束**：非英雄型主角设计，避免夸张战斗服饰，不要少年勇者感，强调普通青年与真实职业背景。避免"高品质二游角色设计"类措辞被模型美化成精致少年脸 / 王者气质 / 英雄感。
2. **跨视角一致性**：保持服装、发型、颜色完全一致，所有角度必须是同一个角色（同发型、同服装配色）——保证后续头像 / CG / 精灵 / 宣传图可复用。

## 7.7 车站调查物设计（P1 待立项，低成本）

> 原则：不破坏现有序章/测试；只加 1~2 个调查物 + 少量隐藏对白，不改主线。

**调查物 1：旧候车牌**

```
"归星岛方向列车，一日一班。"
林澈：以前这里应该很热闹吧。
夏雅：嗯。以前很多人从这里回来。
```

作用：这里不是没有价值，只是被遗忘。

**调查物 2：电脑包（旧笔记本）——表现"他曾经很努力"**

```
"五年。每天都带着。会议、代码、需求……好像只要不停往前跑，就不会被落下。"
停顿。
"结果还是被落下了。"
```

作用：他不是逃跑，他是在寻找新的答案；共鸣当代年轻玩家。

## 7.8 关键瞬间：第一次"喜欢这里"（建议加入，待拍板）

必须有一个"为什么他突然觉得这里不错"的具体小事件，否则成长像作者安排。

```
第一天下雨，林澈发现漏水 → 修好屋檐。
晚上雨停，他坐在门口——雨水落在修好的屋檐上，很安静。
以前城市里下雨，他只想着：堵车、延期、麻烦。
夏雅：怎么样？
林澈：……感觉……还挺好的。
```

这个小瞬间比任何大道理都有效。
