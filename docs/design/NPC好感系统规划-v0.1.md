# 《归星物语》NPC 关系记录系统规划 v0.1（定稿方向）

> 来源：制作人/GPT 讨论 ｜ 归档：Codex 2026-08-04 ｜ 状态：✅ **定稿方向**（制作人 2026-08-04：改为"关系记录系统"，非"好感度系统"）
> 一句话：**先做"人与人的连接"，不要做"养角色"。**

---

## 〇、定位调整（关键）

**不叫"好感度系统"，叫"关系记录系统"**——因为项目差异点不是种田，而是：

> 一个离开城市的人，在乡村重新建立**人与人、人与土地、人与星空之间的连接**。

- ❌ UI 显示"夏雅好感度：63"（拉回传统二游/恋爱养成）
- ✅ 显示关系阶段 + 记忆："她开始愿意和你聊起小时候的事情。"

```
关系记录：
初次相遇
一起修复旧屋
夜晚观星
听她讲过去
```

## 一、设计目标

让玩家感觉"我和这个角色认识越来越深"——通过**共同经历**，不是每日签到。

## 二、数据结构（数值存在，但不展示）

```ts
interface NPCRelation {
  npcId: string;
  affinity: number;          // 内部数值，不展示
  stage: number;             // 关系阶段（0~3）
  unlockedEvents: string[];
  memories: string[];        // 记忆 = 真正的奖励
}
```

存档：

```json
{
  "relations": {
    "xiaYa": {
      "affinity": 20,
      "stage": "熟悉",
      "memories": ["first_meeting"]
    }
  }
}
```

## 三、关系阶段（改名，不恋爱化）

| 阶段 | 名称 | 说明 |
|---|---|---|
| 0 | **相识** | 普通聊天 / 基础任务 |
| 1 | **熟悉** | 角色小故事解锁 |
| 2 | **理解** | 个人事件解锁（如夜晚看星空） |
| 3 | **羁绊** | 专属剧情（≠恋爱，所有 NPC 适用：夏雅/老木匠/农场邻居/小镇老人/未来宇航员 NPC） |

## 四、关系来源（权重调整：共同经历为核心）

| 来源 | 规则 | 定位 |
|---|---|---|
| 普通聊天 | 第一次 +1；**连续每天不增长** | 维持关系（防每日签到化） |
| **事件** | 解锁**记忆**（记忆才是奖励，非数值） | 最高价值 |
| **共同经历** | 修复旧屋 / 一起看星星——核心 | 代表玩法 |

共同经历示例：

```
修复旧屋：夏雅"没想到这么多年过去，还有人愿意把这里重新整理。"
一起看星星：夏雅"你知道吗？小时候我觉得星星离我们很近。后来去了城市，才发现它们越来越远。"
```

## 五、二游化路径（角色本身就是内容）

```
NPC → 关系 → 记忆 → 剧情 → 角色魅力
```

而不是：NPC → 好感条 → 结婚。

## 六、技术最小版（Phase 1）

- `NPCRelation` 接口 + 存档 `relations` 字段（新增存档字段，制作人已拍板纳入）
- 对白按 affinity 分支：

```ts
if (xiaYa.affinity >= 30) { dialogue = '熟悉后的对白'; }
else { dialogue = '普通对白'; }
```

- 复用现有 NPCSystem / Dialogue / Save / Quest / Event，只差一个**中间层**

## 七、开发顺序（制作人拍板）

```
背包 → NPC 关系基础框架 → 事件系统 → 美术升级
```

**NPC 关系排商店之前**——商店是功能，关系系统是世界观基础设施（星之碎片剧情/小镇恢复/角色故事/活动剧情/节日都需要这个挂载点）。

## 八、v0.7 拍板范围
