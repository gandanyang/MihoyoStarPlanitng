> 状态：方向已确认（2026-08-06 制作人拍板），P1 立项可施工

---

## 一、总目标

```
地图 = 功能区域集合   →   地图 = 一个正在生活的小世界
```

优先级排序（结合 v0.10）：

- **P0 不动**：音频、真机、BUG 优先。
- **P1（最推荐，先做）**：青禾镇生活化升级——玩家第一眼看到的地方。
- **P2**：农场升级——"从荒废到复兴"。
- **P3**：老家升级——爷爷痕迹。

---

## 二、技术落地路线（Phaser + Tiled）

❌ 不换 TileSet / 不重做 7 张地图 / 不换引擎 / 不大量找新素材

✅ **Overlay 增强方案**：地图 JSON 不动，代码层叠加（Graphics / 已有 tileset frame / `__WHITE` 粒子），零资源或复用现有素材。

分层结构：

```
基础层（Tile 平铺）
  ↓
地形修饰层（碎石小路 / 草地边缘 / 水岸 / 树荫）
  ↓
生活装饰层（木柴 / 晾衣 / 花盆 / 水桶 / 箱子 / 小推车 / 路边石头 / 草丛）
  ↓
动态层（炊烟 / 窗灯 / 落叶 / 萤火虫 / 小动物 / 晨雾）
```

目标：进入青禾镇的第一眼有"有人住在这里"的生活痕迹。

内容：

1. **生活杂物层**（Graphics / tileset 帧）：木柴堆、晾衣架（可摆动）、花盆、水桶、箱子、小推车、扫帚、石凳、路边石头、草丛。
