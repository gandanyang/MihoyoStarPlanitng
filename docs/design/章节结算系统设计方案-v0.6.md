# 《归星记录》设计方案（v0.6 · 2026-08-03）

> 状态：✅ 设计定稿，制作人全部确认
> 依据：制作人 2026-08-03 三项拍板 + 五点细化 + 归星记录方向定稿
> 约束：零新存档字段 / 纯计算 / 叙事文案 = 制作人定稿
> 游戏内名称：**《归星记录》**（与《归星物语》绑定）

---

## 1. 设计定位

不是"结算"，是**记录**。

像爷爷留下来的笔记本——记录这个岛发生了什么变化。

核心主题统一：

| 维度 | 表达 |
|------|------|
| 人设 | 林澈 = 被时代淘汰的人，重新证明自己的价值 |
| 世界 | 岛 = 被遗忘的地方，因你而重新醒来 |
| 记录 | 归星记录 = 爷爷的笔记本风格，记录变化 |

第一章结束的仪式感不是"恭喜完成"，而是：

> "曾经有人告诉你，你已经没有价值了。"
> "但是今天，一片荒废的土地因为你重新开花。"

---

## 2. 设计原则：「制作人寄语」

这是给开发者看的约束，不是给玩家看的。

> **《归星记录》的核心目标不是评价玩家效率，而是记录玩家对归星岛造成的改变。**

| 允许 | 禁止 |
|------|------|
| 恢复农田 × 12 | 农作物产量排行榜 |
| 第一次收获 | 金币收益统计 |
| 他们开始相信你了 | 完成率百分比 |
| 这座庄园重新有了灯 | 满星评价系统 |

原因：《归星物语》卖的是归属感，不是经营模拟。数值是手段，不是目的。

## 3. 五段结构（制作人定稿）

### 游戏内呈现

```

  恢复农田 × 12
  收获作物 × 28

🌸 记忆

有些地方，并不是坏掉了。
只是等待有人重新走进去。

  完成：爷爷的旧花园
  解锁：夏雅的记忆

🏡 庄园

这座沉睡许久的庄园，终于有了第一盏灯。

👥 羁绊

他们开始相信，这个突然出现的年轻人，
也许真的能改变这里。

⭐ 评价

「初见希望」

但你让一个地方重新有了开始的可能。
```

### 代码结构

```typescript
interface GuiXingRecord {
  day: number;              // 第几天
  sections: GuiXingSection[];
  impression: {
    title: string;      // "初见希望" / "新的开始" / "归星之地" / 动态生成
    desc: string;       // 一段说明
  };
  changeHighlight?: {       // 昨日→今日变化（可选，仅触发时显示）
    before: string;
    after: string;
    summary: string;
  };
  proverbe?: string;        // 制作人寄语（隐藏，仅特定条件下显示）
}

interface GuiXingSection {
  title: string;        // "土地" / "记忆" / "庄园" / "羁绊"
  icon: string;         // 🌱 / 🌸 / 🏡 / 👥
  narrative: string;    // 叙事段落（爷爷的记录风格）
  entries: string[];    // 记录条目（不是评分，是自然获得的）
}
```

### 段标题（制作人确认）

## 4. 第一次事件优先级（情绪 > 数值）

关键情绪事件永远优先于数值事件。

### 高优先级（必展示）

| 事件 | 触发条件 | 文案 |
|------|---------|------|
| 第一次种植 | 任何作物首次种下 | "你弯下腰，把一颗种子放进了土里。" |
| 第一次收获 | 任何作物首次收获 | "原来等待，并不是没有意义。" |
| 第一次恢复区域 | gardenRestored 首次 = true | "爷爷曾经走过的路，今天又有人继续走下去了。" |
| 第一次收到居民主动感谢 | talk_npc 任务首次 claimed | "有些门，不是打不开，只是需要一个人先敲响。" |
| 第一次夜晚看星空 | 首次在夜间停留在户外 | "这片星空，和爷爷记忆里的一样。" |

### 低优先级（不展示）

- ❌ 收获 100 个作物
- ❌ 获得 1000 金币
- ❌ 升级工具 5 次

### 事件标签系统（替代数值权重）

不用"农业 30% 剧情 30%"这种权重。用事件标签：

```typescript
type GuiXingTag =
  | 'first_plant'
  | 'first_harvest'
  | 'restore_garden'
  | 'help_resident'
  | 'stargaze_night'
  | '...'  // 未来扩展
```

标签由游戏行为自然触发，归星记录按标签展示条目。扩展新事件只需加标签，不改权重。

## 5. 昨日→今日变化展示

章节结束时强化"你真的改变了这里"。

### 触发时机

睡觉后，次日清晨弹出归星记录时，先显示变化对比：

```
归星记录

第 7 天

昨日：🌱 荒废花园
今日：🌸 花园重新开放

+1 处空间恢复
+1 位居民记住这里
```

### 代码逻辑

```typescript
function buildChangeHighlight(): GuiXingRecord['changeHighlight'] {
  // 对比 yesterday snapshot vs today snapshot
  // 只在有显著变化时显示（新恢复区域 / 新帮助居民 / 新解锁记忆）
  // 无变化则不显示此字段
}
```

### 设计意图

玩家在睡觉时已有"一天结束了"的心理预期。此时展示"昨天做了什么→今天变成了什么"，强化：

> "我昨天做的事情真的留下痕迹。"

## 6. 归星印象（动态生成空间）

三档基础印象保持不变，但预留扩展空间。

### 基础三档

| 印象 | 触发条件 | 说明 |
|------|---------|------|
| 初见希望 | 默认 | "你还没有改变世界，但你让一个地方重新有了开始的可能。" |
| 新的开始 | 花园恢复 OR 耕种过半 | "沉睡的岛屿开始回应你的努力。" |
| 归星之地 | 花园恢复 + 帮助居民 + 耕种过半 | "这里不再只是爷爷留下的庄园，而是属于新的家园。" |

### 动态生成（后期扩展）

根据玩家行为生成不同记录：

| 行为倾向 | 印象 | 说明 |
|---------|------|------|
| 种很多花 | 「花开的地方」 | "这座岛重新拥有了颜色。" |
| 喜欢帮助 NPC | 「归来的灯火」 | "人与人的联系，让这里重新温暖。" |
| 喜欢探索 | 「寻找星辰的人」 | "你寻找的不只是资源，而是这个岛过去的故事。" |

后期可按 tag 组合生成，不需要预设所有可能。

### 代码逻辑

```typescript
function getGuiXingImpression(tags: GuiXingTag[]): { title: string; desc: string } {
  const gardenRestored = tags.includes('restore_garden');
  const farmProgress = getTilledCount() / 12;
  const npcHelped = tags.includes('help_resident');

  // 基础三档
  if (gardenRestored && npcHelped && farmProgress >= 0.5) {
    return { title: '归星之地', desc: '...' };
  }
  if (gardenRestored || farmProgress >= 0.5) {
    return { title: '新的开始', desc: '...' };
  }

  // 动态生成（后期扩展）
  // if (tags.filter(t => t.startsWith('flower_')).length > 3) {
  //   return { title: '花开的地方', desc: '...' };
  // }

  return { title: '初见希望', desc: '...' };
}
```

## 7. 林澈人设绑定

归星记录不只是统计面板，是林澈人物弧线的叙事锚点。

### 第一章隐藏主题

> "过去，公司认为你没有价值。"
> "现在，一片土地因为你恢复了生命。"

### 第一章归星记录末尾

```
备注：

"这里没有 AI 能替代你的工作。"
```

这一句同时做了三件事：
1. 回应林澈被时代淘汰的背景
2. 呼应 AI 时代主题
3. 让玩家感受到"我的存在有意义"

### 与林澈人设统一

| 林澈的过去 | 归星记录的回应 |
|-----------|--------------|
| 被公司裁员 | "这里没有 AI 能替代你的工作。" |
| 被认为没有价值 | "一片土地因为你重新开花。" |
| 失去方向 | "你让一个地方重新有了开始的可能。" |

归星记录是林澈重新证明自己价值的过程记录。

## 8. 制作人寄语（隐藏设计）

不是展示给玩家的，而是**设计约束**。

> **核心目标不是评价效率，而是记录改变。**
>
> **不要做成：**
> - 农作物数量排行榜
> - 金币收益统计
> - 完成率百分比
>
> **要做成：**
> - "这座沉睡许久的庄园，终于有了第一盏灯。"
> - "他们开始相信，这个突然出现的年轻人，也许真的能改变这里。"

---

## 9. 不做的事（红线）

- ❌ 不新增存档字段
- ❌ 不改触发逻辑（观星完成=第一章结束）
- ❌ 不做数值炫耀（数字是"记录条目"，不是"+500 金币"）
- ❌ 叙事文案不自行扩写（制作人定稿）
- ❌ 不做"继续下一章"按钮（保持"继续自由游玩"）
- ❌ 不用 S/A/B/C 评分
- ❌ 不做排行榜/百分比/效率评价
