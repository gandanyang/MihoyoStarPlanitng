## 一、定位与现状

### 1.1 定位

NPC 闲聊 = **不服务任务、不推进剧情的日常对话**。目的是让 NPC 像真实居民：
玩家不是为了"下一步做什么"才说话，而是会想"去听听他今天又念叨什么"。

### 1.2 现状盘点（2026-08-07 代码核实）

- **已有雏形**（v0.5.3 剧情密度）：`NPCSystem.ts` 的 `NPC_DAILY_LINES` 每日随机台词池 +
  `getDailyNpcLine(npcId, day)`（seed = day + npcId hash，同一天同 NPC 固定同一句，读档不跳变）
- **触发方式**（`MapScene.ts` 对话处）：每次与 NPC 对话时，若当天未说过则把「每日一句」追加到固定对话末尾；用内存标记 `npcDailySaid`（Map<npcId, day>）控制"每天每 NPC 至多 1 句"，**不进入存档**
- **覆盖**：6 个 NPC 有池（村长/商店老板/矿工老张/花匠小梅/阿风/木匠老周）；**神秘少女无池**（她的台词全部服务剧情/异常点，刻意不加闲聊）
- **配音**：现有每日台词均无配音（纯文本）；仅阿风 L4 灯意象彩蛋有注释说明

### 1.3 本设计解决的问题

1. 池子无条件区分（时段/天气/剧情状态不参与选句，读档日复一日重复感强）
2. 无正式内容规范（新增池子容易踩"网络梗/任务感"红线）
3. 无配音边界（闲聊全量配音成本高，需明确默认静音）

---

## 二、设计原则（遵守冻结期约束）

1. **零新系统**：完全复用 `NPC_DAILY_LINES` + `getDailyNpcLine` + `npcDailySaid` 机制，只扩数据与选句条件
2. **不新增存档字段**：闲聊无状态（seed 只依赖天数）；"已听"标记保持内存级
3. **不加内容量**：施工时**替换/增强现有池子**，不做"每 NPC 几十条"的规模扩张
4. **闲聊永远可跳过、不阻塞**：闲聊永远排在任务/状态对话之后；对话窗口一次 1 句，不连篇

## 三、扩展设计

### 3.1 选句条件（目标状态）

把 `getDailyNpcLine` 的签名从 `(npcId, day)` 扩展为带条件：

```ts
getDailyNpcLine(npcId, ctx: {
  day: number;      // 种子（保持无状态）
  hour: number;     // 时段选择
  isRaining: boolean;  // 天气选择
  storyFlags?: {...};  // 剧情状态（观星完成/复兴完成等，只读不入档）
})
```

选句优先级（同池内取第一条命中的条件段）：

1. **剧情状态句**（如观星完成后、复兴 N 点后、阿风欢迎后）——数量最少，最有"世界变化感"
2. **天气句**（雨天专属 1~2 条/NPC，配合 BUG-048 雨天层）
3. **时段句**（清晨 / 白天 / 傍晚 / 夜晚 四档，每 NPC 每档至少 1 条）
4. **通用句**（现有池子归入此类，兜底）

### 3.2 覆盖与规模（保持精简）

| NPC | 现状池 | 施工建议 | 备注 |
|---|---|---|---|
| 村长 | 6 通用 | +天气1 +时段2（晨/夜）+观星后1 | 观星后句承接"星星的事你慢慢来" |
| 商店老板 | 6 通用 | +天气1 +时段2（晨/晚） | 承接 T3.5 回响「店里货越来越有人买」（若 T3.5 已做） |
| 矿工老张 | 7 通用 | +天气1（雨：矿洞避雨）+时段1 | — |
| 花匠小梅 | 7 通用 | +天气1（雨：花怕水/喜欢水）+时段1 | — |
| 阿风 | 10 通用 | +天气1（雨：路难走）+时段1 | 承接 #28 欢迎剧情后态度变化（可 1 条） |
| 木匠老周 | 6 通用 | +复兴后1（老屋完成后：木工房重新响动） | 承接 FEATURE-041 回归 |
| 神秘少女 | 无 | **保持无池** | 身份未揭底前不闲聊（异常点台词已够） |

> 总量从 42 条 → 约 55~60 条，仍属"替换/增强"而非扩张。

### 3.3 触发与频率

- 维持"每天每 NPC 至多 1 句"（`npcDailySaid` 不变）
- 新增**条件句不额外计数**：同一天内若剧情状态变化（如今天刚完成观星），下次对话仍可补 1 句剧情状态句（用独立的"状态句已读"内存标记，仍不入档）

### 3.4 配音边界

- **默认静音**：闲聊台词全部为纯文本（与现状一致），不自动配音
- **例外（制作人逐条拍板）**：剧情状态句（观星后/复兴后/阿风欢迎后）每条可申请 MiniMax 配音——它们是"世界变化"的听觉锚点，价值高于通用闲聊
- 配音接入沿用现有 voicebank.data.ts 映射 + VoiceBank 运行时 ogg 映射，无新机制

### 3.5 内容红线（引用幽默系统 + NPC 设计规范）

- 生活观察 > 网络梗；不做段子手
- 不与主线/任务对白冲突（不剧透、不抢戏）
- 温暖底色；关键剧情禁幽默区不适用（闲聊本身非关键剧情）
- 各角色口吻以人物圣经为准（如林澈冷幽默但克制、夏雅平静纠偏）

## 四、示例台词（施工可选用，需过叙事版本管理）

**时段句**：
- 村长（清晨）：「今天露水重，地里的活儿可以晚点干。」
- 商店老板（傍晚）：「快收摊了，要点什么趁现在说。」
- 阿风（夜晚）：「晚上山路黑，要探险明天赶早。」

**天气句**：
- 矿工老张（雨）：「下雨天矿洞里闷，正好上来喝口热茶。」
- 花匠小梅（雨）：「这场雨下完，花能精神好几天。」

**剧情状态句**：
- 木匠老周（老屋完成后）：「你爷爷的木工房，又能听见刨木头的声音了。」
- 阿风（欢迎剧情后）：「下次进岛，记得先跟我打个招呼。」

## 五、验收标准（施工后）

| 项 | 标准 |
|---|---|
| 触发 | 每天每 NPC 首句对话必带 1 句闲聊（若有条件命中），之后不再重复 |
| 条件 | 雨天/时段/剧情状态下，对应条件句优先于通用句（探针断言） |
| 无状态 | 读档/重开不跳变；存档结构零新增字段 |
| 音量 | 全部纯文本默认静音；配音句仅制作人拍板的例外 |
| 回归 | tsc 0 错；NPC 对话相关探针全绿（如 probe-npc-* / 主线流程探针） |
