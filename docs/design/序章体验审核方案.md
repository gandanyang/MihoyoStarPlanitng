# 序章体验审核方案（方案储备）

> 作者：Codex ｜ 日期：2026-08-03 ｜ 状态：📋 方案储备（待 Batch C 前执行）
> 定位：执行「任务-序章体验审核」的作业框架——先定方法，再跑审核

---

## 1. 目标

站在**第一次玩《归星物语》的玩家**角度体验序章，找出"会迷惑 / 会无聊 / 会出戏"的点。**不看代码，只看体验。**

## 2. 审核维度（6 问）

1. 玩家是否有明确行动目标？（每节点知道"我为什么在做这件事"）
2. 哪里无聊？（无输入/纯阅读/重复）
3. 哪里解释太多？（信息堆积）
4. 哪里情绪不够？（该有温度的地方冷掉）
5. 哪里像小说？（不是游戏节奏）
6. 玩家什么时候最想继续玩？（记录 hook 点）

## 3. 执行方法

1. **新档完整流程**：`?reset=1` 启动 → 车站 → 大门 → 教程（锄/种/浇）→ 第一夜 → 次日清晨
2. **逐节点记录**：每个剧情节点停下，记录玩家视角的"知道什么 / 想做什么 / 情绪"
3. **对照清单**：已修项（v0.7/v0.8/E-07/E-08）不再重复挑；只找**剩余**问题
4. **区分**：P0 迷惑（玩家不知道干嘛）/ P1 体验（情绪/节奏）/ P2 建议

## 4. 输出格式

| 节点 | 时间点 | 玩家行为 | 玩家情绪 | 问题 | 级别 | 修改建议（不改主线） |
|---|---|---|---|---|---|---|

- 附：修改建议落点（哪个文件/哪段对白），但**不实施**
