# 语音接入与验收说明 v0.1

> 状态：✅ 接入代码已提交（`8d4b88b`）｜验收：⏳ 待制作人跑游戏听感验收

## 一、管线总览

```
台词文本（配音台词文本-序章第一章）→ 选角表（音色 id/参考）→ VoxCPM 批量生成
→ F0 音高自检（男 70-180Hz / 女 170-320Hz，漂移重跑 ≤3 次）
→ public/audio/voice/<角色>/<场景>_<序号>.wav
→ gen_mainline_voice.py --emit-voicebank 生成 VoiceBank 映射
→ StoryDialogue 按 (speaker, text) 播放
```

## 二、接入机制

- `src/audio/VoiceBank.ts`：播放器封装（`play(speaker, text, inner)` / `stop()`），按 `voicebank.data.ts` 精确匹配说话人+台词；找不到音频静默跳过，不阻塞对话；`inner`（内心独白）单独标记。
- `src/audio/voicebank.data.ts`：103 条映射（文件→角色→归一化台词），由脚本自动生成，勿手改。
- `src/ui/StoryDialogue.ts`：每行对白显示时播放，切行/关闭停止。
- 立绘接线同文件：夏雅→`xiya_ai_avatar.png`、爷爷/爷爷的笔记/信→`grandpa_ai.png`。

## 五、配音收尾必做：音频内容抽查（防 P0 串词）

> 教训：BUG-040——小梅"只要用心…"语音内容播成"顺我者昌逆我者亡"（映射/文本对账全过，但**音频内容本身串词**）。A2 对账只覆盖"映射↔文本"，**不覆盖"音频内容↔文本"**。

**收尾规则（每条配音批必须执行）：**

1. **听感抽查**：每角色至少 2~3 条（含 1 条短句 + 1 条长句），确认音频内容 = 台词文本
2. **批量转写抽查**（可选增强）：对生成批量做一次语音转写（SenseVoice 可用），文本↔音频自动比对，发现串词即重录
3. 发现错配 → 按 BUG-040 流程：重录该条 + 抽查同角色其余条
