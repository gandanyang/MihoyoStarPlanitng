# 神秘少女 · 月之少女气质设定草案

> **状态**：草案（方案 A · 制作人 2026-08-03 拍板）
> **定位**：气质补充，**不推翻**已定稿身份「星轨守护者」（顶层设计 §5.4-③）
> **红线**：Demo 不揭底；v0.6 不开发；不改角色身份定稿

## 一、结论摘要

神秘少女的**真实身份仍是星轨守护者**（已有定稿，玩家不知）。「月之少女」是其**表层气质**的补充方向：
- 让玩家在 Demo 里感知到"这个人不像住在岛上""她与月亮/星空有某种联系"
- 不为解释身份，只为制造谜感（先留下谜，再让玩家产生想知道的欲望）

## 二、为什么做"气质"而不是"身份"

| | 身份（方案 B，已否决） | 气质（方案 A，已确认） |
|---|---|---|
| 冲突 | 推翻星轨守护者定稿，需同步 3 处文档 | 完全兼容现有定稿 |
| 玩家感知 | 直接告诉玩家她是谁 | 只留下"异常感" |
| 风险 | 破坏世界观平衡（小岛出现"神"跨度大） | 低 |
| 与二游钩子逻辑 | 提前揭底，无悬念 | "先谜后知"，更高级 |

## 三、气质关键词

| 关键词 | 体现 |
|--------|------|
| 月 | 台词以"月亮/月光"作为重复意象 |
| 星辰 | 与现有「星之碎片」「观星」呼应（星光含月光） |
| 森林 | 常驻森林树影下，与世隔绝感 |
| 时间 | "对少女来说，那是很久以前的事"（非人时间感） |

## 四、气质具体化（Demo 可落地的低风险台词方向）

> ⚠️ 以下仅作方向示例，**改动已定稿对白需制作人逐条批准**，当前版本不实施。

- "今晚的月亮，比以前更接近了。"（月 + 异常时间感）
- "你捡到的那片碎片……它也曾是月光。"（月 + 星之碎片关联，不解释）
- "我不认识你。但月亮认识很久了。"（表层异常，不揭身份）

## 五、与已有设定的衔接点

| 已有设定 | 月之少女气质如何衔接 |
|---------|---------------------|
| 星轨守护者（顶层设计 §5.4-③） | 守护的星光里包含月光；"月之少女"是玩家感知到的表象 |
| 第二章「星辰的秘密」（剧情.md） | 爷爷研究星图 → 遇见少女；"星轨秘密"钩子可叠加月光意象 |
| 第三章「归位」 | 碎片集齐 → 岛屿苏醒，"月归位"可与星归位并行意象 |
| 现对白（NPCSystem.ts MYSTERY_DIALOGUES） | 现有"你身上……有那颗星的味道""快归位了"已够，无需改 |

## 六、版权边界（致敬 ≠ 搬运）

参考气质：神秘 / 非人感 / 圣洁感 / 距离感（如某二游「少女」类角色）。
**禁止**：同名 / 同造型 / 同身份 / "她就是 XX" / 直接影射。

## 七、当前版本明确不做

- ❌ 不新增剧情角色（红线）
- ❌ 不改身份定稿（顶层设计 §5.4-③ 保持）
- ❌ 不扩写第二章/第三章剧情
- ❌ 不改现有对白（除非制作人逐条批准）
