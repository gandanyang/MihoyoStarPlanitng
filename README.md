# 星露谷二游 — Web 小游戏 Demo

Phaser 3 + TypeScript + Vite 像素风农场 RPG 浏览器游戏。

## 版本

**v0.2-farm-growth** — 商店经济循环 + 农场等级经验系统

## 快速开始

```bash
npm install
npm run dev      # 开发服务器 → http://localhost:5173
npm run build    # 生产构建 → dist/
npm run preview  # 本地预览构建产物
```

## 玩法

```
种萝卜 → 浇水 → 收获 → 卖钱(15G) → 买种子(10G) → 净赚 5G → 再种
                    ↓
            完成任务 → 获得经验 → 升级(Lv.1~5)
```

| 操作 | 键位 (PC) | 触屏 (移动端) |
|---|---|---|
| 移动 | WASD / 方向键 | 虚拟摇杆 |
| 交互 | E / 空格 / 回车 | 交互按钮 |
| 商店 | 靠近商人按 E | 靠近商人点交互按钮 |
| 关闭商店 | Esc / E / 关闭按钮 | 关闭按钮 |

│   ├── Inventory.ts         # 背包
│   ├── TimeSystem.ts        # 日夜循环
│   └── exits.ts             # 场景出口配置
├── systems/
│   ├── InputManager.ts      # 输入抽象层

## 部署

构建产物为纯静态文件，可部署到任意静态托管服务：

```bash
npm run build   # 输出到 dist/
```

`vite.config.ts` 已配置 `base: './'`，支持相对路径部署（子目录/任意域名均可）。
