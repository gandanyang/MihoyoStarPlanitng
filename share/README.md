# 归星物语 - 宣发素材库

> 用于视频制作、社交媒体分享、媒体采访等场景

## 文件夹结构

```
share/
├── 视频素材/          # 录制的游戏画面、开发过程等
├── 截图/              # 游戏截图、场景截图
├── 角色立绘/          # 角色立绘素材
├── 音乐素材/          # BGM、音效
└── 设计文档/          # 视频脚本、封面设计、文案等
```

## 当前项目

### 第一期视频
**标题：** 《AI时代，一个普通游戏玩家为什么选择慢慢做一款关于回乡的反潮流游戏？》

**脚本：** `设计文档/视频脚本-AI时代的反潮流游戏.md`

**时长：** 约10分钟

## 素材清单

### 角色立绘
- 林澈 - 主角，回乡的年轻人
- 夏雅 - 便利店店主，留下来的力量
- 村长 - 青禾镇镇长
- 爷爷 - 林澈的爷爷（已故）
- 阿风 - 冒险家，自由的象征

### BGM
- 主界面 (title.ogg) - 开场、菜单
- 田园晨曦 (farm_day.ogg) - 日常农场
- 田间夜晚 (stargaze_night.ogg) - 夜晚氛围
- 归星物语 (stargaze_final.ogg) - 观星、结尾

## 使用说明

1. **视频制作**：参考 `设计文档/视频脚本-AI时代的反潮流游戏.md`
2. **截图使用**：直接从 `截图/` 文件夹获取
3. **音乐使用**：从 `音乐素材/` 文件夹获取（推荐ogg格式）
4. **角色介绍**：从 `角色立绘/` 文件夹获取立绘
