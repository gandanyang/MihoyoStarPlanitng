## BUG-046 登记（制作人 PC web 端反馈，暂不修复）
- 现象：PC web 端，游戏内按 Esc 弹系统菜单 → 点「回到主菜单」→ 进标题页 → 点「清除存档（重新开始）」二次确认后，localStorage 存档删不掉（"检测到存档"提示仍在、删档按钮反复出现）。
- 根因（读码确认）：删档链路 TitleScene.createClearSaveButton 二次确认 → deleteSave()（removeItem('return_star_save')）→ location.reload()；但 MapScene 在 create 注册的全局 beforeunload/pagehide 自动存档监听器（MapScene._beforeUnload，MapScene.ts:732/741-742）切到标题页时**未被移除**——SHUTDOWN（406-409）只清理 DOM/环境音/BGM，未清理 window 级监听器；且「回到主菜单」用 game.scene.start('title') 而非 this.scene.start，MapScene 未必 shutdown。reload 触发 beforeunload → 残留 _beforeUnload 执行 save() → 把残留游戏单例状态写回 localStorage → 存档复活、删档失效。
- 制作人明确要求**暂不修复**，仅登记（问题追踪.md 登记记录 BUG-046，P1）。另制作人提及「返回按钮还有其他问题」待补充复现。
- 修复方向（待实施，最小改动优先）：①删档 deleteSave() 后与 reload 前阻断自动存档（全局"正在删档"标志让 _beforeUnload 跳过 save）；②MapScene SHUTDOWN 显式 removeEventListener('_beforeUnload'/'_visibilityHandler')；③「回到主菜单」改用 this.scene.start('title') 并确保 MapScene 正确 shutdown。影响文件：TitleScene.ts、MapScene.ts、SaveSystem.ts、AndroidBackHandler.ts。
